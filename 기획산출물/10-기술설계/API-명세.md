# 1. 공통 규약

## 1-1. 스코프는 두 개뿐입니다

| 스코프 | 발급 시점 | 접근 범위 | 강제 방법 |
|---|---|---|---|
| `child` | 초대 링크 교환 성공 시 | `/child/*` | 🔒 **NFR-004** — `/parent/*` 호출 시 **403** |
| `parent` | 부모 로그인 | `/parent/*` | — |

🔒 **NFR-003** — 아이 오리진 번들에 `/parent/` 문자열 **0건**. **빌드 파이프라인 정적 스캔이 실패하면 배포를 막습니다.**

## 1-2. 멱등 — 별이 움직이면 반드시

**별 원장을 건드리는 모든 쓰기**는 멱등 키가 필수입니다. 키 단위는 §2~§4 각 행의 🔑에 적었습니다.

| 재전송이 일어나는 곳 | 흡수 방법 |
|---|---|
| 발행사 웹훅 재전송 | 🔑 승인번호 |
| 오프라인 큐 재동기화 | 🔑 클라이언트 생성 `idempotency_key` |
| 부모 중복 승인 | 🔑 `mission_id` |
| 하루 한도 안에서의 중복 요청 | 🔑 `child_id + date + slot` |

> 🔒 **NFR-022** 중복 지급 **0건** · 🔒 **NFR-020** 정합성 오류율 **0%** *(협상 불가)*

## 1-3. 시각 · 금액

- **시각** — ISO 8601 · KST. 오프라인 발생 건은 `client_ts`를 함께 보냅니다. 🔴 **주차 귀속은 `client_ts` 기준**(`server_ts`로 하면 재연결이 늦은 아이의 실천이 다음 주로 밀려 WPA가 왜곡됩니다)
- **금액** — **정수 · 원 단위.** 소수 없음
- 🔒 **NFR-050** — `child` 스코프 응답에 **`%`·비율 필드를 두지 않습니다.** 채움 게이지용 `filled / total`(분모 10 고정) 또는 정액 비례값으로 내려보냅니다

## 1-4. 규제 게이트는 **HTTP 상태로** 거부합니다

🔴 게이트 위반을 `200` + 에러 바디로 처리하면 **감사 로그에 남지 않습니다.** 반드시 상태 코드로 거부합니다.

| 상황 | 응답 | 적재 |
|---|:-:|---|
| 동의 미완 상태의 아이 진입 | **403** | 📝 `consent_gate_blocked` — 🔴 **1건이라도 나오면 즉시 알림 + 기능 자동 차단** |
| 동의 미완 상태의 초대 링크 발급 | **403** | 🔒 NFR-002 · 발급 로그 감사 |
| `child` 토큰의 부모 API 호출 | **403** | 🔒 NFR-004 · 감사 로그 |

## 1-5. 성능

표의 `[NFR-0xx]`는 **SRS §5.3의 잠정 상한**입니다. 🔴 **확정 SLO가 아니라 「이 값을 넘으면 AC가 성립하지 않는다」는 상한**이며, 프로토타입 실측 후 교체합니다.

## 1-6. 🤖 AI를 부르는 엔드포인트는 **하나뿐입니다**

`GET /parent/forest/summary`(**FR-042**)가 전부입니다. **나머지 38개는 LLM을 부르지 않습니다.**
계약은 SRS **§2.5.2 가드레일**에서 그대로 내려옵니다.

| 규약 | 내용 |
|---|---|
| 🤖 **호출 주체는 서버** | `G-1` — 클라이언트 번들에 **모델 엔드포인트·키가 존재하지 않습니다.** CSP + 번들 스캔으로 검증 |
| 🤖 **페이로드는 화이트리스트** | `G-2` · 🔒 **NFR-013** — 보낼 필드를 **열거**합니다. 집계 수치와 라벨 「아이」만. 🔴 **닉네임 · 자녀 id · 계획 카드의 「어디서」 · 미션 사진은 어떤 경우에도 넣지 않습니다** |
| 🤖 **아이 스코프에는 없습니다** | `G-3` · 🔒 **AC-042-4** — `child` 응답 어디에도 **런타임 생성 텍스트가 없습니다.** 퀴즈 해설·「이야기 다시 읽기」는 **문항에 딸린 정적 텍스트**입니다(NFR-014 사전 검수 100%) |
| 🤖 **국외로 나가지 않습니다** | `G-6` · 🔒 **NFR-009** — 추론은 **서울 리전**에서 끝나고 요청 데이터를 **모델 학습에 제공하지 않습니다** |
| 🔴 **끌 수 있어야 합니다** | 가드레일 1건이라도 못 지키면 **이 엔드포인트를 내리고 템플릿 문장으로 되돌립니다.** 다른 엔드포인트는 영향받지 않습니다 |

# 6. ⬜ 갈림길 3곳 — 병윤 님 결정 시 여기만 바뀝니다

> 🔵 **결정 전에도 나머지 API는 확정입니다.** 아래 표시된 곳만 「잠정」이며, 정해지는 대로 이 절을 갈아끼우면 됩니다.

## 6-1. 미션 사진 보관 *(원 미확정 10-1)*

**영향받는 엔드포인트 — 1개 변형 + 최대 2개 신설**

| 안 | `POST /child/missions/{id}/submit` | 추가로 생기는 것 | NFR-005 |
|:-:|---|---|:-:|
| **A** 아이 기기 보관 | JSON *(사진 없음)* | `GET /parent/missions/{id}/photo` → **202 대기**<br/>`POST /child/missions/{id}/photo` *(요청 시 업로드)* | 원문 유지 |
| **B** 짧은 TTL 임시 저장 | **multipart** | `GET /parent/missions/{id}/photo` → 서명 URL<br/>배치 `purge-mission-photos` | 🔴 **재작성 필요** |
| **C** 사진 없이 승인 | JSON *(텍스트 사유만)* | 없음 | 원문 유지 |

## 6-2. 이자 지급 실행 주체 *(원 미확정 10-2)*

| 안 | 배치 `savings-payout-remind` | 추가로 생기는 것 |
|:-:|---|---|
| **A** 부모 1탭 충전 | 주 1회 리마인드 | `POST /parent/wallet/topup` *(source=savings_interest)* |
| **B** 발행사 자동이체 | 불필요 | `POST /issuer/standing-order` — 🔴 **제휴 이후에만 실동작** |
| **C** 월 단위로 변경 | 월 1회 | 🔴 NFR-051 예외 필요 |

## 6-3. 탈퇴 · 환불 순서 *(원 미확정 10-4)*

| 안 | `DELETE /parent/account` 응답 | 추가로 생기는 것 |
|:-:|---|---|
| **A** 환불 완료까지 보류 | **202 Accepted** | `GET /parent/account/deletion` → 상태 조회 |

## 🔴 계약에서 물러설 수 없는 것 7가지

구현 방식은 자유지만 **이 일곱은 계약입니다.**

1. **스코프 2종 · 403 강제** (NFR-003 · 004) — 빌드 스캔 실패 시 배포 차단
2. **규제 게이트는 HTTP 상태로 거부** (§1-4) — `200` + 에러 바디 금지
3. **별이 움직이는 쓰기는 전부 멱등** (NFR-020 · 022)
4. **⭐ 판정은 스냅샷 고정 · 소급 재계산 없음** (DR-06)
5. **결제 원본·미션 이미지·위치 좌표를 스키마에 두지 않음** (DR-02 · DR-03 · DR-04)
6. **주차 귀속은 `client_ts`** — WPA 왜곡 방지
7. 🤖 **LLM을 부르는 엔드포인트는 1개 · 서버 경유 · 페이로드 화이트리스트** (§1-6 · NFR-009 · 013 · 014) — 🔴 **아이 스코프 응답에 런타임 생성 텍스트 0건**
