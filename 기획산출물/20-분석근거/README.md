## 이 폴더가 확정한 것

- **문제 정의** — 「돈 대신 별」이 아니라 **「돈이 못 하는 일을 별이 채운다」** 입니다. 리뷰(돈 보상 긍정 126건 vs 부작용 11건)와 학술 근거가 그렇게 말합니다.
- **근거 구조** — 아이 페인포인트는 **이론 · 산업 비교 · 팀 직접사용 3계층**이 받칩니다. 리뷰는 보조근거입니다 → [`조사/하영/01_리뷰분석/`](../../%EC%A1%B0%EC%82%AC/%ED%95%98%EC%98%81/01_%EB%A6%AC%EB%B7%B0%EB%B6%84%EC%84%9D/)

## ✅ 확인 범위

### 근거가 닿은 곳과 닿지 않은 곳

- 🔴 **실제 고객 인터뷰 0건입니다.** JTBD 인터뷰 응답은 **🧪 모의 응답**이며 Evidence가 아닙니다.
- 리뷰 **921건 전수분류** 결과 1차 페인포인트 본체에 해당하는 리뷰는 **10건(1.1%)** 이었습니다 *(아이 쪽만 보면 3건 · 0.3%)*. **리뷰가 결핍을 잡지 못하는 채널**이어서 근거를 3계층으로 다시 세웠습니다 — 방향을 바꾼 것이 아닙니다.
- **"돈은 학습동기가 안 된다" 는 쓸 수 없습니다** — 리뷰·학술 근거가 정반대입니다.
