## 한눈에 보는 대응표

| 기능(약속) | 왜 이 기술인가 | 사용자에게 보이는 방식 |
|---|---|---|
| 배운 것을 실천으로 옮기는 루프 | 서버(Node·Express)가 퀴즈 정답과 미션 승인을 하나의 흐름으로 묶어 처리 | 정답 → 별 지급 → 바로 이어지는 "실천하기" 카드 |
| 부모/아이 화면 완전 분리 | PWA 2개를 **다른 오리진**으로 배포 | 같은 서비스지만 부모는 부모 링크, 아이는 아이 링크로만 들어감 — 서로의 화면이 절대 섞이지 않음 |
| 인터넷이 끊겨도 별이 안전함 | 아이 앱에 Service Worker로 오프라인 큐를 둠 | 오프라인 표시만 뜨고, 재연결되면 자동으로 별이 반영됨(중복·누락 없이) |
| 별이 사라지거나 두 번 지급되지 않음 | PostgreSQL에 이중 기입 원장 + 일일 정산 배치 | 부모·아이 화면의 별 개수가 **항상 일치** |
| 미션 사진은 남기지 않음 | 서버가 부모 승인 직후 이미지를 즉시 파기, 승인 이력만 보관 | 미션 인증 사진은 "칭찬하기"를 누르는 순간까지만 보이고, 이후엔 승인 배지만 남음 |
| 아동 정보가 해외로 나가지 않음 | 전체 인프라를 AWS 서울 리전에 고정 | 사용자 입장에서는 보이지 않지만, 개인정보 처리방침에 "국내 서버"로 명시 가능 |
| 월간 성장 요약 | AI(AWS Bedrock, 서울 리전)를 **부모용 요약 문장 하나**에만 사용 | 월간 숲 화면에 "이번 달엔 저축을 3번 더 실천했어요" 같은 한 줄 요약이 뜸. AI가 꺼져도 숫자 지표는 그대로 보임 |
| 아이에게는 검수 안 된 AI 글을 보여주지 않음 | 학습 콘텐츠 저작은 오프라인 배치(Python·ChromaDB)로 미리 만들고 **사람이 검수한 뒤** 정적 배포 | 아이 화면에는 실시간 생성 텍스트가 없고, 이미 만들어진 이야기·퀴즈만 나타남 |

## 이야기로 풀면

### 1. "배운 걸 실제로 했는지"를 증명하는 기술

아이가 퀴즈를 풀어 별을 받는 순간, 서버는 그 정답과 **같은 주제의 실천 미션**을 곧바로 연결해 보여줍니다. 미션을 사진으로 인증하면 부모에게 승인 요청이 가고, 부모가 확인해야만 별이 최종 지급됩니다(72시간 무응답 시 자동 만료).

- **쓰는 기술**: 서버(Node·Express)가 학습 이벤트와 미션 이벤트를 하나의 흐름으로 묶고, 이 지급을 **원장(PostgreSQL) 이중 기입**으로 기록.
- **보여주는 방식**: "퀴즈 정답 → 별 1개 → 실천 카드 등장 → 사진 인증 → 부모 승인 → 별 확정 → 나무 성장"이 화면 안에서 끊기지 않고 이어짐. 승인용으로 받은 사진은 확인 즉시 서버에서 삭제되어, 화면에는 "승인됨" 표시만 남습니다.

### 2. 부모와 아이가 각자의 화면만 보게 하는 기술

부모 앱과 아이 앱은 겉보기엔 한 서비스지만, 실제로는 **서로 다른 주소(오리진)**로 배포된 별개의 PWA입니다.

- **쓰는 기술**: PWA 2개(부모/아이) + 오리진 분리, 아이 토큰으로는 부모 API를 아예 호출할 수 없게 서버가 막음.
- **보여주는 방식**: 부모는 초대 링크를 만들어 문자로 보내고, 아이는 그 링크로만 들어옵니다. 두 화면이 같은 코드베이스(Next.js)에서 나오지만, 사용자는 완전히 분리된 두 개의 앱처럼 경험합니다.

### 3. 인터넷이 끊겨도 성장 기록이 안전한 기술

아이가 오프라인 상태에서 미션을 완료해도 기록이 사라지지 않습니다.

- **쓰는 기술**: 아이 앱의 Service Worker가 오프라인 큐에 행동을 잠깐 저장해두고, 재연결되면 **고유 키(멱등 키)**로 서버에 전송해 중복 지급을 막음.
- **보여주는 방식**: 화면엔 "오프라인" 표시만 뜨고, 다시 연결되면 자동으로 별이 반영됩니다 — 아이가 따로 뭘 다시 누를 필요가 없습니다.

### 4. "이번 달 얼마나 자랐는지"를 말로 설명해주는 기술

숫자(별 개수·완료 미션 수)만 보여주는 대신, 한 줄 요약 문장으로 성장을 설명합니다.

- **쓰는 기술**: AWS Bedrock(Claude, 서울 리전)을 **이 기능 하나에만** 사용. 아동 식별 정보 없이 집계 수치만 넘김.
- **보여주는 방식**: 월간 숲 화면 상단에 "이번 달엔 저축을 3번 더 실천했어요" 같은 한 줄이 뜸. 이 기능이 꺼져 있어도 숫자·그래프 지표는 그대로 보이므로, AI는 **있으면 좋은 설명**이지 서비스의 전제가 아닙니다.

### 5. 아이에게는 미리 검수된 내용만 보여주는 기술

학습 지문·퀴즈는 아이가 보기 전에 이미 사람이 확인을 끝낸 콘텐츠입니다.

- **쓰는 기술**: 콘텐츠 제작은 서비스 운영과 분리된 별도 도구(Python·FastAPI·ChromaDB)로 오프라인에서 진행하고, 기존 문항과 겹치지 않는지 확인한 뒤 사람이 검수.
- **보여주는 방식**: 아이 화면에는 실시간으로 생성되는 글이 아니라, 이미 완성되어 배포된 이야기와 퀴즈만 나타납니다. 오답이어도 그 자리에서 AI가 설명을 새로 만들어주는 게 아니라, 정해진 "이야기 다시 읽기"로 안내합니다.

## 정리 — 스택은 취향이 아니라 약속의 결과

위 5가지 기술 선택 모두 같은 원칙을 따릅니다: **먼저 지켜야 할 약속(성장 증거를 보여준다·아동 정보를 보호한다·AI는 보조일 뿐이다)이 있고, 기술은 그 약속을 지키기 위해 역산해서 고른 것**입니다. 전체 스택 목록과 각 항목의 규제 근거는 `SRS_핀프렌즈_v1_0.md` §2.5, `wiki/10-제품/기술-스택.md`에 정리돼 있습니다.
