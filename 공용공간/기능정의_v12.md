# 1. 기존 퍼핀의 문제

> ### ① 아이의 금융 학습 현황을 볼 수 있지만, **성장을 체감할 수 없다**
> ### ② **학습이 실천으로 이어지지 않는다**

## 근거

| # | 근거 | 출처 |
|---|---|---|
| ① | 부모 학습현황 화면이 **누적일수·문제수·보상액 숫자 3개뿐** | 팀 직접 캡처 (혜원 E-11) |
| ① | 🔴 **퍼핀 자기 인정** — "의도와 다르게 작동하는 케이스가 있다", 아이들이 학습 목표를 **"스쳐 보기라도"** 하길 바란다 | 개발사 답변 (하영 E6) |
| ② | 실패 요인 **1위 "금융 행동으로 전이되지 않음"**, 2위 "성장 증거가 없음" | 유림 시장분석 |

> ⚠️ "성장을 **확인할 수 없다**"로 쓰면 반박당합니다. 퍼핀은 2024-10에 부모용 학습 내역 확인 기능을 이미 출시했습니다.

# 3. 🌳 나무 UI — **부모 화면 전용**

## 왜 부모 화면에만 두는가

| 화면 | 동기 장치 | 왜 |
|---|---|---|
| **아이** | 👕 **옷장** (별 누적 → 해금) | 7세에게 나무 4개 + 진도율 + 정답률은 **정보 과부하**. "별 몇 개 더 모으면 새 옷"이 훨씬 직관적 |
| **부모** | 🌳 **나무 4개** | 부모가 원하는 건 "얼마나 했나"가 아니라 **"어디까지 자랐나"** |

**아이는 옷장으로 움직이고, 부모는 나무로 확인합니다.** 역할이 겹치지 않습니다.

## 4개 영역, 4개 나무

```
   💰 벌기        🛒 잘 쓰기      🐷 모으기      🌱 키우기
    🌳             🌿              🌱             ⬜
   나무           새싹            씨앗           잠김
```

**4칸이 화면에 그대로 드러납니다.** 어느 영역이 자라고 어디가 멈췄는지 한눈에 보입니다.

## 성장 조건 — 3종을 모두 채워야 다음 단계

각 성장 단계마다 **학습 완주 횟수 · 퀴즈 정답 개수 · 행동 실천 횟수** 가 정해져 있습니다.

| 예시 | 조건 |
|---|---|
| **새싹 → 나무** | 학습 완주 **3회** + 퀴즈 정답 **5개** + **행동 실천 1회** |

## 🔄 나무는 **매달 초기화**됩니다

```
1월          2월          3월
🌳 나무  →  🌱 씨앗  →  🌿 새싹      (매달 다시 시작)
   ↓            ↓            ↓
📊 1월 리포트  📊 2월 리포트  📊 3월 리포트   ← 쌓인다
```

| 왜 초기화하나 | |
|---|---|
| **매달 새로 시작** | 지난달에 못했어도 부담 없이 재도전 |
| **월 리듬 = 구독 주기** | 구독이 월 단위이므로 **매달 리포트를 받을 이유**가 생김 |
| 장기 기록은 리포트가 담당 | 나무는 "이번 달", 리포트 누적은 "지금까지" |

> ⚠️ **초기화되는 건 나무뿐입니다.** ⭐ 별은 월이 바뀌어도 그대로 남습니다.

## 🔴 왜 이게 문제 정의를 정면으로 치는가

**성장 조건에 「행동 실천 횟수」가 들어 있습니다.**

```
퀴즈만 100개 풀어도  →  나무는 안 자란다
실천을 1번 해야      →  다음 단계로 간다
```

**퍼핀은 퀴즈 개수만 셉니다.** 우리는 **실천 없이는 나무가 멈추게** 설계했습니다.

### 그래서 부모가 나무를 신뢰할 수 있습니다

부모가 보는 나무는 **실천 없이는 자라지 않는 지표**입니다.
→ 나무가 자랐다 = **"우리 애가 배운 걸 실제로 했다"** 는 증거

**문제 정의 ①(부모가 성장을 체감할 수 없다)과 ②(학습이 실천으로 안 이어진다)를 한 화면이 동시에 답합니다.**

### 🔴 그럼 아이의 실천은 무엇이 유도하는가 — **별 2배 규칙**

나무가 아이 화면에 없으므로, **아이 쪽 실천 유도는 별 지급 규칙이 전담합니다.**

```
퀴즈만 풀면        ⭐ 1개
배우고 실천하면    ⭐ 2개   ← 2배
```

**→ 아이 화면에 「실천하면 별 2배」가 명확히 보여야 합니다.** 이게 유일한 실천 유도 장치입니다. (§4)

## 별과 나무의 역할 분담

### 📐 3층 구조

| 층 | 무엇 | 초기화 | 누가 보나 | 역할 |
|---|---|---|---|---|
| **1** ⭐ **별** | 벌면 늘고, 옷 사면 줄어드는 **잔액** | ❌ **없음 — 계속 이어짐** | **아이** | **즉각 보상** |
| **2** 🌳 **나무** | 이번 달 성장 단계 | ⭕ **매달 초기화** | **부모** | **이번 달 성취** |
| **3** 📊 **월간 리포트** | 그 달의 성과를 정리한 **단일 문서** | ❌ **쌓임** | **부모** | **장기 성장 증거** |

```
⭐ 별       계속 이어짐   →  몇 달 모아서 비싼 옷을 살 수 있다
🌳 나무     매달 초기화   →  매달 새로 도전한다
📊 리포트   쌓인다        →  1년치 성장이 보인다
```

**나무만 초기화됩니다.** 별이 초기화되면 여러 달 모아서 좋은 아이템을 사는 재미가 사라지므로, **별은 잔액처럼 계속 이어집니다.**

하영이 조사한 학술 근거와 대응합니다 — *"인센티브는 행동의 **양**, 내재동기는 **질**을 예측"* (183편·21만명).
별은 양(즉각 보상), 나무·리포트는 질(성장 증거)입니다.

# 4. ⭐ 별 — 지급 규칙이 실천을 유도합니다

| 언제 | 지급 |
|---|---|
| 퀴즈 정답 | **⭐ 1개** |
| **실천 행동** (미션 완료·참기·목표 달성 등) | **⭐ 1개 추가** |

```
퀴즈만 풀면        ⭐ 1개
배우고 실천하면    ⭐ 2개   ← 2배
```

**"배운 걸 실제로 했을 때 보상이 2배"** 가 숫자로 드러납니다. 설명이 필요 없어요.

## 🔄 별은 **차감형**입니다 (확정)

| | |
|---|---|
| 획득 | 퀴즈 정답 1개 · 실천 행동 1개 추가 |
| **소비** | **옷 구매 시 차감** |
| **월 초기화** | ❌ **없음.** 잔액처럼 계속 이어짐 |
| 총 획득량 기록 | 별 잔액에는 안 남음 → **월간 리포트에 기록되어 누적** |

**아이는 "여러 달 모아서 비싼 걸 사는" 재미를 갖고, 총 획득 기록은 부모 리포트가 담당합니다.**

> 💡 **별을 차감해도 규제 문제는 없습니다.** 별은 ① 돈으로 산 게 아니라 **금전적 가치가 아니고** ② 옷은 자사 앱 내 아이템이라 **제3자 거래도 아닙니다** — 전자금융거래법 제2조 제14호 요건 둘 다 미충족.
> 모든 모바일 게임이 게임 재화로 아이템을 구매하지만 선불업 등록을 하지 않는 것과 같습니다.

## 별에서 지켜야 할 선 3개

| 하면 안 되는 것 | 왜 |
|---|---|
| ❌ 현금으로 별 충전 | 대가 지급으로 취득 → 금전적 가치가 됨 |
| ❌ 별을 현금으로 환급 | 같은 이유 |
| ❌ 별 양도·거래·선물 | "이전 가능" 요건 충족 |

> **별과 저금통은 완전히 분리된 재화**이며 교차 지점이 없습니다. (P-21)
> 별로 살 수 있는 것은 **앱 내 꾸미기 아이템뿐**이며, 현물·현금·제휴처 사용 경로를 만들지 않습니다.

## 5-1. 📊 월간 리포트 — **하나의 문서**

**나무 4개마다 리포트를 따로 만들지 않습니다. 4칸 내용이 한 문서 안에 정리됩니다.**

```
┌─────────────────────────────────────────────┐
│  📊 2026년 3월 성장 리포트                    │
├─────────────────────────────────────────────┤
│                                             │
│  이번 달 한 줄                                │
│  "쓰기와 모으기가 함께 자랐습니다"              │
│                                             │
├─────────────────────────────────────────────┤
│  🌳 4개 영역 최종 단계                        │
│     벌기 🌳 나무   잘 쓰기 🌿 새싹             │
│     모으기 🌱 씨앗  키우기 ⬜ 잠김              │
├─────────────────────────────────────────────┤
│  📚 학습                                     │
│     완주 12회 · 퀴즈 정답률 78%               │
├─────────────────────────────────────────────┤
│  🏃 실천                                     │
│     미션 수행 8회 · 사려다 멈춤 5회             │
│     목표 저축 달성 1건                        │
├─────────────────────────────────────────────┤
│  💳 소비                                     │
│     총 지출 32,000원 · 저축 15,000원          │
├─────────────────────────────────────────────┤
│  📈 지난달과 비교                             │
│     사려다 멈춤   2회 → 5회                   │
│     가격 비교     0회 → 4회                   │
│     저축률       12% → 32%                   │
├─────────────────────────────────────────────┤
│  ⭐ 이번 달 획득 별  46개                      │
└─────────────────────────────────────────────┘
```

| 왜 하나로 묶나 | |
|---|---|
| 4개로 나누면 | 부모가 4번 봐야 하고, **영역 간 연결이 안 보임** |
| **하나로 묶으면** | *"쓰기를 배웠더니 저축이 늘었다"* 같은 **연결이 드러남** |

**「지난달과 비교」가 핵심입니다.** 유림 시장분석의 결론이 *"부모에게 필요한 건 활동량이 아니라 성장 증거"* 인데, **전월 대비 변화가 그 증거**입니다.

| | 보는 것 | 답하는 질문 |
|---|---|---|
| **아이** | 🐾 아바타 · 👕 옷장 · ⭐ 별 | **"뭘 더 하면 새 옷을 살 수 있나"** |
| **부모 (일일)** | 🌳 나무 4개 · 진도율·정답률·미션수행률 | **"이번 달 어디까지 왔나"** |
| **부모 (월간)** | 📊 월간 리포트 누적 | **"1년 동안 얼마나 자랐나"** |

문제 정의 ①이 **"부모와 아이가"** 성장을 체감할 수 없다는 것인데,
**아이는 옷장으로, 부모는 나무로** 각자에게 맞는 방식으로 해결합니다.

> 유림 시장분석: *"부모에게 필요한 건 활동량이 아니라 성장 증거"* → 나무가 그 증거이고, **구독 과금 근거**가 됩니다.

# 6. 🗣️ 아이 눈높이 용어

**개인정보 보호법 제22조의2 제3항** — 아동에게는 "이해하기 쉬운 양식과 명확하고 알기 쉬운 언어"를 사용해야 합니다. **법정 의무**이고, 퍼핀은 아동용 별도 고지가 없습니다.

| 부모·발표용 | **아이 화면** | 한 줄 설명 |
|---|---|---|
| 벌기 (소득) | **💰 벌기** | 일하면 돈이 생겨요 |
| 쓰기 (소비) | **🛒 잘 쓰기** | 진짜 필요한 걸까? |
| 모으기 (저축) | **🐷 모으기** | 안 쓰고 두면 쌓여요 |
| **불리기 (이자·복리)** | **🌱 키우기** | 모아두면 **저절로** 늘어나요 |

> **💰 돈이 생기고 → 🛒 잘 쓰면 → 🐷 모이고 → 🌱 저절로 자라요**

「불리기」는 7세가 모르는 말입니다. 「키우기」는 나무·동물 키우기와 이어져 서비스 전체 메타포가 됩니다.

| | 누가 |
|---|---|
| 선불업 등록 · **선불충전금 100% 별도관리**(신탁/예치/지급보증보험) | **제휴사** |

### PRD에 그대로 쓸 문장

> 선불전자지급수단의 발행 및 관리는 **선불업 등록을 보유한 제휴사가 수행**하며, 선불충전금의 100% 별도관리 의무도 제휴사에 있다.
> 핀프렌즈는 제휴사 인프라 위에서 **학습·실천 연결과 성장 가시화**를 담당한다.

## ⚠️ B안 리스크

| 리스크 | 내용 |
|---|---|
| **수수료 종속** | 제휴사 수수료율이 마진을 결정 → 유림 3중 수익모델의 「결제 수수료」 몫이 줄어듦 |
| 최소 물량 조건 | 초기 유저가 적으면 계약 자체가 안 될 수 있음 |
| 정책 통제 불가 | 이용한도·업종 제한이 제휴사 정책에 종속 (참고: 퍼핀은 14세 미만 50만원) |
| ⬜ 실제 조건 미확인 | 코나아이 사례는 검색 요약 수준 — **수수료·최소물량 문의 필요** |

| | |

**제외 근거** — 앱 밖 현금은 아이의 자율 영역이며, 수동 입력에 의존하면 데이터 신뢰도가 떨어져 성장 리포트의 정확성을 해칩니다.

> 「용돈 지급 수단 현금 48.9%」는 **커버리지 공백이 아닙니다.** 부모가 우리 앱을 쓰기로 하면 카드로 충전하므로, 그 통계는 「앱을 안 쓰는 가정」의 현황입니다.

# 9. 🔥 발표 포인트 3개

## ① 학습을 실천으로 잇는다 — **나무가 증거입니다**
> 퍼핀은 퀴즈와 카드가 따로 논다. 우리는 같은 4칸으로 묶는다.
> **부모가 보는 나무는 성장 조건에 「행동 실천 횟수」가 들어 있어, 퀴즈만 100개 풀어도 자라지 않는다.**
> 즉 나무가 자랐다는 것은 **"배운 걸 실제로 했다"** 는 증거다.
> 퍼핀 퀴즈는 **7과목 중 4개가 비금융**(한국사·시사·어휘·과학기술)이라 **구조적으로 못 따라온다.** 사자성어 퀴즈를 소비 행동과 연결할 수는 없다.

## ② 소비 앞과 뒤를 모두 잡는다
> 퍼핀은 **쓴 다음에** 기록한다. 우리는 **쓰기 전에 개입하고, 쓴 뒤에 회고한다.**
> 리테일이 10년간 써온 지오펜싱 마케팅을 정확히 반대로 쓴다 — "사세요"가 아니라 **"지금 사면 목표까지 3주 늦어져요."**
> 그리고 카드 결제 내역으로 **참았는지가 자동 확인된다.** 알림 → 판단 → 결과가 한 고리로 닫힌다.

## ③ 실천하면 보상이 2배다
> 퀴즈만 풀면 별 1개, **배우고 실천하면 2개.**
> 저축 격차 53%p — 부모가 원하는 것 1위 **저축 65.8%** ↔ 아이가 하는 것 꼴찌 **12.8%**.
> 아이가 저축을 안 하는 건 **이유가 없어서**다. 이자가 이유를 만든다.
> Greenlight는 이미 한다 — 부모가 이자율을 직접 설정하고 **평균 19.84%** 를 준다.

## 🔴 1번이 왜 중요한가

우리 주장 「금융 100%로 간다」는 **"부모가 금융만 하는 걸 원한다"** 를 전제합니다.
그런데 **금융 100%가 아니면 4칸 매핑 자체가 불가능**하므로, 이 가정이 §2 전체를 받치고 있습니다.

| 인터뷰 결과 | 대응 |
|---|---|
| (a) "금융만 했으면" | ✅ 그대로 진행 |
| (b) "별 상관없다" | ⚠️ 「금융 100%」를 차별점으로 내세우지 말고 **실천 연결만** 앞세움 |
| (c) "여러 과목이 좋다" | 🔴 포지션 변경 |
