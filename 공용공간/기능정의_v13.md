# 3. 🌳 일일 나무 · 🌲 월간 숲 — **부모 화면 전용**

## 왜 이름을 「리포트」에서 바꿨나

| | v12 | **v13** |
|---|---|---|
| 일일 | 일일 리포트 | 🌳 **일일 나무** |
| 월간 | 월간 리포트 | 🌲 **월간 숲** |

**나무가 매달 초기화되므로, 지나간 달의 나무들이 모여 숲이 됩니다.** 「리포트」는 서류의 이름이고, 「숲」은 자란 결과의 이름입니다.

> 🔄 v12에서는 4번째 칸을 「키우기」로 불러 **나무·숲 메타포와 이름이 이어졌습니다.** v13에서 「불리기」로 확정했으므로 그 연결은 끊기고, **나무·숲은 화면의 이름 · 불리기는 금융 행위의 이름**으로 분리됩니다 (§9).

## 왜 부모 화면에만 두는가

| 화면 | 동기 장치 | 왜 |
|---|---|---|
| **아이** | 👕 **옷장** (별 누적 → 해금) | 7세에게 나무 4개 + 진도율 + 정답률은 **정보 과부하**. "별 몇 개 더 모으면 새 옷"이 훨씬 직관적 |
| **부모** | 🌳 **나무 4개** | 부모가 원하는 건 "얼마나 했나"가 아니라 **"어디까지 자랐나"** |

**아이는 옷장으로 움직이고, 부모는 나무로 확인합니다.** 역할이 겹치지 않습니다.

## 3-1. 🌳 일일 나무 — 4개 영역, 4개 나무

```
   💰 벌기        🛒 잘 쓰기      🐷 모으기      🌱 불리기
    🌳             🌿              🌱             ⬜
   나무           새싹            씨앗           잠김
```

**함께 표시되는 실시간 지표** — 진도율 · 퀴즈 정답률 · 미션 수행률.
**4칸이 화면에 그대로 드러납니다.** 어느 영역이 자라고 어디가 멈췄는지 한눈에 보입니다.

### 성장 조건 — 3종을 모두 채워야 다음 단계

각 성장 단계마다 **학습 완주 횟수 · 퀴즈 정답 개수 · 행동 실천 횟수** 가 정해져 있습니다.

| 예시 | 조건 |
|---|---|
| **새싹 → 나무** | 학습 완주 **3회** + 퀴즈 정답 **5개** + **행동 실천 1회** |

### 🔄 나무는 **매달 초기화**됩니다

```
1월          2월          3월
🌳 나무  →  🌱 씨앗  →  🌿 새싹      (매달 다시 시작)
   ↓            ↓            ↓
🌲 1월 숲     🌲 2월 숲     🌲 3월 숲     ← 쌓인다
```

| 왜 초기화하나 | |
|---|---|
| **매달 새로 시작** | 지난달에 못했어도 부담 없이 재도전 |
| **월 리듬 = 습관 형성·회고 주기** | 한 달 단위로 목표를 새로 세우고, 부모·아이가 변화를 함께 돌아봄 |
| 장기 기록은 숲이 담당 | 나무는 "이번 달", 숲은 "지금까지" |

> ⚠️ **초기화되는 건 나무뿐입니다.** ⭐ 별은 월이 바뀌어도 그대로 남습니다.

## 🔴 왜 이게 문제 정의를 정면으로 치는가

**성장 조건에 「행동 실천 횟수」가 들어 있습니다.**

```
퀴즈만 100개 풀어도  →  나무는 안 자란다
실천을 1번 해야      →  다음 단계로 간다
```

**퍼핀은 퀴즈 개수만 셉니다.** 우리는 **실천 없이는 나무가 멈추게** 설계했습니다.
→ 나무가 자랐다 = **"우리 애가 배운 걸 실제로 했다"** 는 증거

**문제 정의 ①(부모가 성장을 체감할 수 없다)과 ②(학습이 실천으로 안 이어진다)를 한 화면이 동시에 답합니다.**

### 🔴 그럼 아이의 실천은 무엇이 유도하는가 — **실천 경로가 더 많다**

나무가 아이 화면에 없으므로, **아이 쪽 실천 유도는 별 지급 규칙이 전담합니다.**

```
학습에서 나오는 별    퀴즈 정답 · 온보딩 학습              →  경로 2개
실천에서 나오는 별    미션 승인 · 결제 회고 ·              →  경로 5개
                      위시리스트 3단계 · 예적금 가입·완주      + 완주 ⭐10
```

**→ 아이 화면에 「무엇을 하면 별을 받는지」가 목록으로 보여야 합니다.** 이게 유일한 실천 유도 장치입니다. (§4)

> 🔄 v12의 「실천하면 **별 2배**」 문구는 폐기됐습니다. v13은 배수가 아니라 **경로 수와 완주 보너스(⭐10)** 로 같은 방향을 만듭니다.

## 3-2. 🌲 월간 숲 — 월말에 총정리

**나무 4개마다 문서를 따로 만들지 않습니다. 4칸 내용이 한 화면 안에 정리됩니다.**

```
┌─────────────────────────────────────────────┐
│  🌲 2026년 3월 숲                            │
├─────────────────────────────────────────────┤
│  이번 달 한 줄                                │
│  "쓰기와 모으기가 함께 자랐습니다"              │
├─────────────────────────────────────────────┤
│  🌳 4개 영역 최종 단계                        │
│     벌기 🌳 나무   잘 쓰기 🌿 새싹             │
│     모으기 🌱 씨앗  불리기 ⬜ 잠김              │
├─────────────────────────────────────────────┤
│  📚 학습    완주 12회 · 퀴즈 정답률 78%        │
├─────────────────────────────────────────────┤
│  🏃 실천    미션 8회 · 사려다 멈춤 5회          │
│             위시리스트 70% 달성 · 적금 가입     │
├─────────────────────────────────────────────┤
│  💳 소비    총 지출 32,000원 · 저축 15,000원   │
├─────────────────────────────────────────────┤
│  📈 지난달과 비교                             │
│     사려다 멈춤   2회 → 5회                   │
│     가격 비교     0회 → 4회                   │
│     저축률       12% → 32%                   │
├─────────────────────────────────────────────┤
│  ⭐ 이번 달 획득 별  46개                      │
└─────────────────────────────────────────────┘
```

| 왜 하나로 묶나 | |
|---|---|
| 4개로 나누면 | 부모가 4번 봐야 하고, **영역 간 연결이 안 보임** |
| **하나로 묶으면** | *"쓰기를 배웠더니 저축이 늘었다"* 같은 **연결이 드러남** |

**「지난달과 비교」가 핵심입니다.** 유림 시장분석의 결론이 *"부모에게 필요한 건 활동량이 아니라 성장 증거"* 인데, **전월 대비 변화가 그 증거**입니다.

## 별과 나무의 역할 분담 — 📐 3층 구조

| 층 | 무엇 | 초기화 | 누가 보나 | 역할 |
|---|---|---|---|---|
| **1** ⭐ **별** | 벌면 늘고, 옷 사면 줄어드는 **잔액** | ❌ **없음 — 계속 이어짐** | **아이** | **즉각 보상** |
| **2** 🌳 **일일 나무** | 이번 달 성장 단계 | ⭕ **매달 초기화** | **부모** | **이번 달 성취** |
| **3** 🌲 **월간 숲** | 그 달의 성과를 정리 | ❌ **쌓임** | **부모** | **장기 성장 증거** |

```
⭐ 별       계속 이어짐   →  몇 달 모아서 비싼 옷을 살 수 있다
🌳 나무     매달 초기화   →  매달 새로 도전한다
🌲 숲       쌓인다        →  1년치 성장이 보인다
```

하영이 조사한 학술 근거와 대응합니다 — *"인센티브는 행동의 **양**, 내재동기는 **질**을 예측"* (183편·21만명).
별은 양(즉각 보상), 나무·숲은 질(성장 증거)입니다.

### 📅 출석체크에 별을 주는 이유 — **지속 학습**

**매일 앱에 오는 습관이 학습과 실천의 전제입니다.** 학습을 시작하지 않은 날은 퀴즈도 미션도 회고도 일어나지 않으므로, **출석 자체를 별로 보상해 접속 습관을 만듭니다.**

| | |
|---|---|
| 출석 ⭐1이 만드는 것 | **매일 오는 습관** — 학습·실천이 일어날 수 있는 조건 |
| 나머지 트리거가 만드는 것 | 온 다음에 **무엇을 했는지** |

**출석은 「왔다」에, 나머지는 「했다」에 주는 별입니다.** 둘은 대체 관계가 아니라 순서 관계입니다.

## 4-4. ⬜ 월 획득량 — **계산용 가정** (팀 확정 수치 아님)

옷 가격표를 정하려면 월 획득량 추정이 필요합니다. **아래 빈도는 조사 결과가 아니라, 계산을 돌려보기 위해 임의로 넣은 값입니다.**

| 트리거 | 가정한 빈도 | ⭐/월 | 이 숫자의 출처 |
|---|---|---|---|
| 📅 출석체크 | 매일 | **30** | ✅ **규칙에서 도출** — 1일 1회 × 30일 |
| ❓ 퀴즈 정답 | 주 3회 | 12 | ⬜ **임의 가정** |
| 🧹 미션 승인 | 주 2회 | 8 | ⬜ **임의 가정** |
| 💳 결제 회고 | 월 4회 | 4 | ⬜ **임의 가정** |
| 🎯 위시리스트 단계 | 월 1단계 | 1 | ⬜ **임의 가정** |
| 💰 예적금 가입 | 1회 | 1 | ⬜ **임의 가정** |
| | | **≈ 56** | |

> 🔴 **⭐30만 규칙에서 그대로 나오는 수이고, 나머지 26개는 위 빈도 가정에 전부 달려 있습니다.**
> 아이 사용 빈도 데이터가 없으므로 이 표를 그대로 인용하면 안 됩니다. 하영 리뷰분석(「돈 때문에 매일 푼다」 126건 등)이나 프로토타입 테스트로 **아래 5줄을 채워야** 실제 가격표를 뽑을 수 있습니다.

### 가격표에 주는 함의

| | |
|---|---|
| **출석 = 기반선** | 실천이 없어도 월 ⭐30이 들어옵니다 — **지속 학습을 위한 의도된 설계** (§4-1) |
| **실천 = 그 위의 증분** | 미션·회고·위시리스트·예적금이 기반선 위에 얹힙니다 |
| **그래서 가격대는** | 저가 아이템은 기반선으로 닿게, **상위 아이템은 기반선만으로는 못 닿게** 잡습니다. 그래야 "매일 오기"와 "실천하기"가 각각 다른 보상을 갖습니다 |
| **최저가** | **⭐1 고정** — 온보딩에서 ⭐1로 살 수 있는 아이템을 제시하기로 확정 (§7) |

# 5. 📍 위치 알림 + 💳 결제 회고 — **5단계 루프** (확정)

## 5-1. 루프

```
① 계획       "다이소에서 5,000원까지 쓸 수 있어"
             ← 부모 또는 아이가 미리 정해둠
                        ↓
② 알림 확인   아이가 계획해둔 장소 범위에 있고,
             📍 3분 이상 머무르면 → 알림 → 아이가 확인
                        ↓
③ 소비        "5,000원까지 쓸 수 있다"를 인지하고 구매 결정
                        ↓
④ 결제 이후   계획 금액 ↔ 실제 결제 금액 비교 화면 제시
                        ↓
⑤ 결제 회고   별을 받은 이유 / 못 받은 이유 제시
             → [확인했어요] 클릭 → ⭐ 1개 지급
```

## 5-2. 왜 **3분**인가

| | |
|---|---|
| **지나가는 것 ≠ 들어간 것** | 장소 앞을 통과할 때마다 알림이 오면 알림 자체가 무시됩니다. **체류 시간이 「살 마음이 있다」의 신호**입니다 |
| 개입 시점이 구매 직전 | 매장에 들어가 고르는 동안 알림이 도착합니다 — 결제 전 마지막 판단 지점 |

> 💡 리테일이 10년간 써온 지오펜싱 마케팅과 **트리거는 같고 메시지가 반대**입니다 — "사세요"가 아니라 **"지금 사면 목표까지 3주 늦어져요."**

## 5-3. 이 루프가 닫히는 이유

**계획 → 알림 → 판단 → 결제 → 비교 → 회고**가 한 고리로 닫힙니다. 카드 결제 내역이 자동으로 들어오므로 **참았는지가 아이 자기 보고 없이 확인**됩니다.

| 단계 | 정책 조항 |
|---|---|
| ② 알림 | **P-19** — 만 14세 미만 개인위치정보 **옵트인 · 좌표 미저장** |
| ④ 비교 | 카드 결제 내역 기반 (**P-17 · P-18** 한도·업종 제한) |

## 5-4. 왜 [확인했어요] **한 번**으로 끝내나 — 팀 합의

**그 순간에 아이한테 회고까지 시키면 너무 복잡합니다.** 결제 직후는 아이가 매장에 서 있거나 이동 중인 시점이고, 7세에게 입력을 요구하면 루프가 거기서 끊깁니다.

| | |
|---|---|
| **아이가 하는 것** | 비교 화면을 보고 **[확인했어요] 한 번** |
| **아이가 하지 않는 것** | 회고 작성 · 이유 선택 · 감정 입력 |
| **회고 내용은 누가 주나** | **앱이 준다** — 별을 받은 이유 / 못 받은 이유를 문장으로 제시 |

**회고를 아이에게 시키지 않습니다. 앱이 대신 말해주고 아이는 읽고 넘어갑니다.** 인지 부하를 앱이 부담하는 구조입니다.

> 💡 **퍼핀의 「오답에도 보상 절반」과 다른 점** — 퍼핀은 **틀린 답 자체에** 보상을 줍니다. 우리는 **계획과 실제를 비교한 결과를 아이가 확인한 것**에 별을 줍니다. 그리고 계획을 지켰는지 못 지켰는지는 🌲 월간 숲의 「사려다 멈춤」 지표로 부모에게 그대로 보고됩니다 (§3-2) — 확인 버튼이 결과를 덮지 않습니다.

# 6. 🎯 위시리스트 · 💰 예적금 (확정)

## 6-1. 🎯 위시리스트 — 단계 지급

| | |
|---|---|
| **순위 변경** | **한 달에 한 번** |
| **단계 지급** | 한 상품의 달성 퍼센트로 단계를 나눠 **30% · 70% · 100%** 에 각 ⭐1 |

```
🎯 자전거 120,000원
├─ 30%   36,000원   ⭐1  ✅
├─ 70%   84,000원   ⭐1  ⬜
└─ 100% 120,000원   ⭐1  ⬜
```

| 왜 이렇게 | |
|---|---|
| **왜 단계로 쪼개나** | 12만원짜리 목표는 7세에게 너무 멉니다. **중간에 세 번 보상이 오면 포기 지점이 사라집니다** |
| **왜 순위 변경을 월 1회로 막나** | 매일 바꾸면 목표가 쌓이지 않아 지연 만족 훈련이 무력화됩니다. 완전 고정은 아이의 관심 변화를 못 받아줍니다 — **월 1회가 그 사이** |

## 6-2. 💰 예금·적금 vs 부모 적금 — **선택**하게 한다

아이가 **직접 선택**해서 어떤 것이 합리적인지 경험하게 합니다.

| | 지급 |
|---|---|
| **가입** 시 | ⭐ **1** |
| **완주** (일정 기간 납입) | ⭐ **10** |

> ⚠️ **가입 「연결」은 하지 않습니다.** **비교·선택 경험까지만** 제공해 금융상품 중개업을 회피합니다 (P-20 · §13-5).
> ⬜ 「일정 기간」이 몇 개월인지는 미정입니다 (§14-5).

## 4칸 명칭 — **부모·아이 화면 동일** (v13 확정)

| 영역 | **화면 표기** | 한 줄 설명 |
|---|---|---|
| 소득 | **💰 벌기** | 일하면 돈이 생겨요 |
| 소비 | **🛒 잘 쓰기** | 진짜 필요한 걸까? |
| 저축 | **🐷 모으기** | 안 쓰고 두면 쌓여요 |
| 이자·복리 | **🌱 불리기** | 모아두면 **저절로** 늘어나요 |

> **💰 돈이 생기고 → 🛒 잘 쓰면 → 🐷 모이고 → 🌱 저절로 늘어나요**

**부모 화면과 아이 화면이 같은 말을 씁니다.** 이름이 갈리면 부모가 나무를 보고 아이와 대화할 때 번역이 한 번 더 필요합니다.

## 🔴 그래서 「알기 쉬운 언어」는 **한 줄 설명이 담당합니다**

> ⚠️ 「불리기」는 7세가 아는 말이 아닙니다. 그런데도 명칭을 통일했으므로, **법정 의무를 채우는 건 이름이 아니라 그 옆의 한 줄 설명**입니다.

| | |
|---|---|
| **규칙** | 아이 화면에서 「🌱 불리기」는 **한 줄 설명 없이 단독 노출하지 않습니다** |
| **학습 단계** | 「불리기」 주제는 이자·복리를 다루므로 **4칸 중 가장 먼저 막히는 칸**입니다 |

> 핀프렌즈는 제휴사 인프라 위에서 **학습·실천 연결과 성장 가시화**를 담당한다.

## ⚠️ B안 리스크

| 리스크 | 내용 |
|---|---|

| **무료 모델의 수익원 집중** | 부모 구독 매출이 없으므로 실제 카드 연결·결제액·금융사 제휴 성과가 사업성을 결정 |

| ⬜ 실제 조건 미확인 | 코나아이 사례는 검색 요약 수준 — **수수료·최소물량 문의 필요** |

## 🆓 이용료 — 부모·아이 모두 무료 *(v12 확정 유지)*

**월 구독이 없습니다.** 수익모델은 **결제 수수료 + 금융사 제휴** 2중 구조입니다.

## 🔴 무료 전환에 따라 다시 계산해야 하는 것

유림 시장분석은 **구독 기준**으로 작성됐습니다.

| | 유림 분석 (구독 기준) | **무료 모델** |
|---|---|---|
| 1년차 SOM | 440가구 × 월 4,900원 = **연 2,590만원** | 🔴 **구독 매출 0원** |
| 수익 구조 | 구독 + 결제 수수료 + 제휴 **(3중)** | 결제 수수료 + 제휴 **(2중)** |
| 사업성을 결정하는 것 | 유료 전환율 | **카드 연결률 · 결제액 · 제휴 성과** |

> ⚠️ 유림 분석의 결론이 *"구독만으로는 사업이 안 되고 3중 모델이 전제"* 였습니다.
> **구독을 없애면 SOM 산출식과 KPI가 함께 바뀝니다.**

| 확인해야 할 것 | |
|---|---|
| ① | 구독 삭제가 **최종 결정**인가 |
| ② | SOM을 **무엇으로 다시 산출**하는가 (예: 카드 연결 가구 × 월 결제액 × 수수료율) |
| ③ | KPI가 「유료 전환율」 → 「**카드 연결률 · 월 결제액**」으로 바뀌는가 |

**→ 8/20 스크럼 안건.** 정리되지 않으면 8/21 PRD의 「지표」 항목을 쓸 수 없습니다.

> 💡 **v13 기능과의 접점** — 무료 모델에서 사업성을 결정하는 건 **카드 결제액**입니다. 그런데 §5의 위치 알림·결제 회고는 **아이가 덜 쓰게 만드는 기능**입니다. 「덜 쓰게 해서 신뢰를 얻고, 오래 써서 총 결제액을 만든다」는 논리가 성립하는지 위 ②·③에서 함께 정리해야 합니다.

# 12. 🔥 발표 포인트 3개

## ① 학습을 실천으로 잇는다 — **나무가 증거입니다**
> 퍼핀은 퀴즈와 카드가 따로 논다. 우리는 같은 4칸으로 묶는다.
> **부모가 보는 나무는 성장 조건에 「행동 실천 횟수」가 들어 있어, 퀴즈만 100개 풀어도 자라지 않는다.**
> 즉 나무가 자랐다는 것은 **"배운 걸 실제로 했다"** 는 증거다.
> 퍼핀 퀴즈는 **7과목 중 4개가 비금융**(한국사·시사·어휘·과학기술)이라 **구조적으로 못 따라온다.**

## ② 소비 앞과 뒤를 모두 잡는다 — **5단계 루프**
> 퍼핀은 **쓴 다음에** 기록한다. 우리는 **쓰기 전에 개입하고, 쓴 뒤에 회고한다.**
> **매장에 3분 이상 머무르면** 알림이 간다 — 지나가는 게 아니라 **살 마음이 생긴 순간**이다.
> 그리고 카드 결제 내역으로 **계획과 실제가 자동 비교된다.** 계획 → 알림 → 판단 → 결제 → 회고가 **한 고리로 닫힌다.**

## ③ 실천에서 나오는 별이 훨씬 많다
> 학습으로 받는 별은 **경로 2개**(퀴즈·온보딩), 실천으로 받는 별은 **경로 5개**다.
> 그리고 **가장 큰 보상 ⭐10은 적금을 완주해야** 받는다 — 여러 달 부어야 나오는 유일한 보상.
> 저축 격차 53%p — 부모가 원하는 것 1위 **저축 65.8%** ↔ 아이가 하는 것 꼴찌 **12.8%**.
> 아이가 저축을 안 하는 건 **이유가 없어서**다. **위시리스트 단계 지급(30/70/100%)과 적금 완주 ⭐10이 그 이유를 만든다.**
> Greenlight는 이미 한다 — 부모가 이자율을 직접 설정하고 **평균 19.84%** 를 준다.
