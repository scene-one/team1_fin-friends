# 1. 핵심 구조 — 4칸으로 학습과 행동을 잇는다

```
        📚 배운다                🏃 실제로 한다
       ─────────────           ────────────────────
   벌기   소득의 종류      ═══   📸 용돈 기록(OCR) + 🧹 미션
  잘 쓰기 필요 vs 원함     ═══   📍 위치 알림에서 참기
  모으기  목표 저축        ═══   🎯 위시리스트 달성
  키우기  이자·복리        ═══   💰 부모 이자로 늘어남
                      ↓
                ⭐ 별 = "배운 걸 했다"
                      ↓
          🐾 동물 + 👕 옷장 해금        🌳 부모: 4칸 통과 현황
```

## 왜 이게 엣지인가

**퍼핀은 위 칸(학습)과 아래 칸(행동)이 만나지 않습니다.**

"이자율 퀴즈"를 풀게 하고, 별개로 "편의점 2,000원"을 기록합니다. 둘을 연결하지 않아요.

| | 퍼핀 | **핀프렌즈** |
|---|---|---|
| 별(보상)을 언제 주나 | 퀴즈를 맞히면 | **실제로 했을 때** |
| 그래서 증명하는 것 | "문제를 풀었다" | **"배운 걸 실제로 했다"** |
| 부모가 보는 것 | "문제 75개 풀었어요" | **"쓰기 단계를 통과했어요"** |

## 🔴 퍼핀이 구조적으로 못 따라옵니다

퍼핀 퀴즈는 **7과목 중 4개가 비금융**입니다 (한국사·시사·어휘·과학기술).
플러스 월간 퀴즈는 **4개 중 3개가 비금융**입니다 (사자성어·수능 비문학 어휘·뉴스시사용어).

> **"사자성어 퀴즈"를 실제 소비 행동과 어떻게 연결하겠습니까?**

우리는 **금융 4주제만** 하므로 하나하나 실제 행동과 짝이 맞습니다.
퍼핀이 따라하려면 **자기 퀴즈 절반을 버려야 합니다.**

# 2. ⭐ 별의 정의 — 차감 없이 쌓이고, 누적으로 해금된다

**옷장을 유지하면서 「별 = 눈금」도 지키는 방법입니다.**

| | |
|---|---|
| 별은 **차감되지 않습니다** | 쓰는 게 아니라 **쌓이기만** 함 |
| 옷은 **누적 별 개수가 조건** | "별 100개를 모으면 모자가 **해금**" |
| 어떤 옷을 입을지는 **아이가 선택** | 꾸미는 재미는 그대로 |

## 🔴 "구매"가 아니라 "해금"이어야 하는 이유

**전자금융거래법 제2조 제14호** — 선불전자지급수단 요건:
> 이전 가능한 금전적 가치로서, **제3자로부터 재화 또는 용역을 구입하고 그 대가를 지급**하는데 사용되는 것

| 표현 | 판정 |
|---|---|
| ❌ "별 100개로 모자 **구매**" | "재화 구입 + 대가 지급" 구조에 가까워짐 |
| ⭕ "별 100개를 모으면 모자가 **해금**" | 성장 조건. 요건 미충족 |

**같은 기능인데 문구와 구조에 따라 해석이 달라집니다.** 별을 차감하지 않으면 논란 자체가 없습니다.

### 그리고 세 가지를 동시에 만족합니다

| | |
|---|---|
| 👕 옷장 | ✅ 유지 |
| 📏 별 = 학습량 눈금 | ✅ 차감 없으니 누적 총량이 그대로 남음 |
| ⚖️ 선불수단 회피 | ✅ 구입·대가 지급 구조 없음 |

# 4. 🧹 미션 — 퍼핀과 뭐가 다른가

**⚠️ 퍼핀에 「미션하기」가 이미 있습니다.**
> 퍼핀페이 약관 별첨1 — "멘티와 목표를 설정하고 완료 시 보상을 주는 서비스"
> 「사진등록 및 전송」 — "미션하기 인증을 위해 멘토에게 사진을 전송"

**그러므로 "우리도 미션 있어요"로 발표하면 감점입니다.** 차별점은 미션 자체가 아니라 **미션이 학습과 이어진다는 것**입니다.

| | 퍼핀 | **핀프렌즈** |
|---|---|---|
| 미션 | 있음 | 있음 |
| 미션 보상이 가는 곳 | 그냥 잔액 | **「벌기」 칸에 누적** |
| 학습과의 연결 | ❌ 없음 | ✅ **「벌기」 학습 → 미션 실행 → 같은 칸에 기록** |
| 아이가 배우는 것 | — | **"노동의 대가로 돈이 생긴다"를 실제로 경험** |

## 💡 미션이 들어오면 「벌기」라는 이름이 맞아집니다

미션이 없으면 아이가 하는 건 **용돈 받기**뿐이라 「벌기」 학습(소득의 종류·근로소득)과 어긋납니다.
**미션 = 근로소득 체험.** 교육 주제와 실제 행동이 일치합니다.

## ⚠️ 규제 — 부모가 직접 이체하는 구조로

```
❌ 부모 → [핀프렌즈 지갑에 충전] → 아이     ← 선불전자지급수단
⭕ 부모 → [자기 은행앱에서 직접 이체] → 아이
         핀프렌즈는 승인·기록·알림만
```

회사가 돈을 보관하면 **자본금 20억 + 선불충전금 100% 별도관리** 의무가 발생합니다.

## ⚠️ 사진 인증

퍼핀 「사진등록·전송」과 동일한 기능입니다. 넣는다면:
- 사진은 **부모에게만** 전달
- **서버 저장 안 함** (전달 후 폐기)
- 그래야 아동 이미지 리스크가 관리됩니다

# 6. 🗣️ 아이 눈높이 용어

**개인정보 보호법 제22조의2 제3항** — 아동에게는 "이해하기 쉬운 양식과 명확하고 알기 쉬운 언어"를 사용해야 합니다. **법정 의무**이고, 퍼핀은 안 하고 있습니다.

| 부모·발표용 | **아이 화면** | 한 줄 설명 |
|---|---|---|
| 벌기 (소득) | **💰 벌기** | 일하면 돈이 생겨요 |
| 쓰기 (소비) | **🛒 잘 쓰기** | 진짜 필요한 걸까? |
| 모으기 (저축) | **🐷 모으기** | 안 쓰고 두면 쌓여요 |
| **불리기 (이자·복리)** | **🌱 키우기** | 모아두면 **저절로** 늘어나요 |

> **💰 돈이 생기고 → 🛒 잘 쓰면 → 🐷 모이고 → 🌱 저절로 자라요**

**「불리기」는 7세가 모르는 말입니다.** 「키우기」는 동물 키우기와도 이어져서 서비스 전체 메타포가 됩니다.

# 8. 🔥 발표 포인트 3개

## ① 학습과 행동을 잇는다
> 퍼핀은 퀴즈와 카드가 따로 논다. 우리는 같은 4칸으로 묶는다.
> 퍼핀은 퀴즈 7과목 중 4개가 비금융이라 **구조적으로 못 따라온다.**

## ② 제약이 커버리지를 넓혔다
> 카드 라이선스가 없어서 **현금부터** 시작했다.
> 용돈을 현금으로 주는 **48.9%** 는 퍼핀 카드에 안 잡힌다. 우리는 사진 한 장으로 잡는다.

## ③ 저축 격차 53%p를 이자로 친다
> 부모가 원하는 것 1위 **저축 65.8%** ↔ 아이가 하는 것 꼴찌 **12.8%**
> 아이가 저축을 안 하는 건 **이유가 없어서**다. 이자가 이유를 만든다.
> Greenlight는 이미 한다 — 부모가 이자율을 직접 설정하고 **평균 19.84%** 를 준다.
