# 아이 화면

아이가 보는 프로토타입 캡처 **19장**. 폴더는 [기능정의 v14 §8 「아이 화면」](../../0.%20확정%20기능%20정의/기능정의_v14.md) 의 화면 구분을 따릅니다.

- 하단 탭 4개 — **내 방 · 미션 · 배우기 · 내 통장**
- 4칸 명칭은 v14 §9 확정 표기 **벌기 · 잘 쓰기 · 모으기 · 불리기** 를 씁니다
- 🔴 **금액 · 아이 이름(수빈) · 정답 수는 전부 예시 값입니다.** 실제 데이터가 아닙니다

**온보딩**(짧은 학습 → 퀴즈 → ⭐1 → 살 수 있는 아이템 제시) · **계획 카드 작성 폼**(날짜·어디서·얼마까지) ·
**출석체크 스트립** · **부모가 준 미션 목록** · **미실행 칸 애니메이션**(v14 §8, 정지 화면으로는 안 보임)
