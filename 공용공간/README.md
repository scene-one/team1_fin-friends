## 📌 하영 리서치 브리핑 (8/17)

리뷰 921건 전수 분류 → 퍼핀 공식자료 교차검증 → 금전·비금전 보상 학술연구 16편 → 경쟁 4사(gohenry·Greenlight·아이쿠카·아이부자) 비교까지 끝냄. 상세: [`하영/`](../하영/)

**핵심 3가지.** ① 퍼핀이 **자기 앱 설명에** 퀴즈 과목을 "경제·금융·한국사·시사·어휘·투자·과학기술"로, **공식 블로그에** 플러스 월간 퀴즈를 "투자왕 / 뉴스시사용어 / **사자성어와 속담** / **수능 비문학 어휘**"로 적어놨음 — 금융이 아닌 게 절반 이상. ② 퍼핀은 `학습→풀이→보상`은 완비인데 **`보상→성취/성장`이 비어 있음.** 국내 3사 공통 공백이고 해외 2개는 채움. ③ **돈 보상은 잘 작동 중** — 리뷰 126건(13.7%)이 "돈 때문에 매일 푼다"고 하고 학술 근거도 같은 방향이라 **돈을 빼는 제안은 못 함.**

**8/19에 정할 것.** 1순위 개선 기회를 **"금융 학습의 누적을 구분해서 보이게 한다"** 로 잡을지. 퍼핀이 15단계 커리큘럼을 이미 갖고 있어 **새로 만들 게 아니라 드러내는 것**이라 실행이 가벼움. 위험은 하나 — **리뷰 921건 중 "금융이 아니어서 문제"라고 한 부모가 0명**이고 유일한 관련 리뷰는 오히려 영단어를 요구했음. **부모 3~5명에게 한 문장만 물어보면 갈림.** 이게 「별」인지는 미정 — 별이 *보상 화폐*면 근거 부족, *학습 누적 지표*면 근거 있음.

> ⚠️ 병윤의 「퍼핀에 이미 있는 것」 목록에 1개 추가 — **부모가 아이 학습 내역을 보는 기능은 2024-10에 이미 출시됨**(개발사 답변). "학습 내역을 보여주자"는 개선안이 될 수 없음.
