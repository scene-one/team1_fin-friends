## 🔴 8/19 안건 — 개선 기회 1순위 제안 (하영, 8/17)

> 리서치 6단계까지 끝냈습니다. **마지막 개선 기회 선정은 팀이 같이 봐야 할 문제라 여기 올립니다.**
> 근거 전문: [`하영/06_개선기회확정/`](../하영/06_개선기회확정/)

### 제안하는 1순위

> **"금융 학습의 누적을 구분해서 보이게 한다"**

### 왜 이것인가 — 세 줄

1. **아이·부모 페인포인트가 사실 하나입니다.** 퍼핀은 `학습 → 문제풀이 → 보상`은 완비인데 **`보상 → 성취/성장` 구간이 비어 있습니다.** 아이 쪽에서 보면 "뭘 알게 됐는지 모르겠다", 부모 쪽에서 보면 "금융을 얼마나 배웠는지 모르겠다" — **같은 공백의 양면**입니다.
2. **퍼핀이 이미 15단계 커리큘럼을 갖고 있습니다.** 새로 만드는 게 아니라 **드러내는 것**이라 실행 조건이 가볍습니다.
3. **국내 3사(퍼핀·아이쿠카·아이부자) 모두 이 구간이 공백입니다.** 해외 2개(gohenry·Greenlight)는 채웁니다 → **선점 가능한 자리**입니다.

### 근거 (전부 출처 확인 완료)

| 근거 | 내용 |
|---|---|
| 퍼핀 공식 앱 설명 | 퀴즈 과목 **7개 중 4개가 비금융**(한국사·시사·어휘·과학기술) |
| 퍼핀 공식 블로그 | 플러스 월간 퀴즈 **4개 중 3개가 비금융** — **사자성어·수능 비문학 어휘** |
| 개발사 답변(2024-04) | 오답 보상 문제를 **"의도와 다르게 작동하는 케이스"로 인정**, 학습 목표를 "스쳐 보기라도" 수준으로 자인 |
| 학술 (183편·21만명) | **인센티브는 "양", 내재동기는 "질"을 예측** → 아이 페인포인트가 이론적으로 예측되는 현상 |
| 학술 (41편·5,071명) | 게임화 효과는 **초등에서 가장 큼**(g=1.293) — 퍼핀 타깃과 일치 |

### 🔴 결정 전에 팀이 같이 판단해야 할 것 3가지

**① 부모가 정말 "금융"을 원하는가** (가장 위험)
리뷰 921건 중 *"금융이 아니어서 문제"* 라고 말한 부모는 **0명**입니다. 유일한 관련 리뷰는 **역방향**이었고, 퍼핀은 그 요구를 수용했습니다.
→ **부모 3~5명에게 한 문장만 물으면 됩니다.** *"아이 금융 앱에서 사자성어·수능 비문학 어휘 퀴즈가 나오면 어떠세요?"*
→ 이게 아니라고 나오면 **1순위를 다시 잡아야 합니다.**

**② 이게 「별」인가, 다른 것인가**
4단계 리서치 결론은 **조건부**입니다.
- 별이 **"돈 대신 주는 보상"** 이면 → 🔴 근거 부족. 포인트·레벨은 내재동기를 못 올린다는 연구가 있고(Mekler 2017), 16주 뒤 오히려 동기가 나빠진 사례도 있습니다(Hanus & Fox 2015)
- 별이 **"금융 학습이 얼마나 쌓였는지 보여주는 지표"** 면 → 🟢 근거 있음
→ **어느 쪽으로 갈지 팀이 먼저 정해야** 설계로 넘어갈 수 있습니다.

**③ 금전 보상은 유지가 맞다고 봅니다**
리뷰 **126건(13.7%)** 이 "돈 때문에 매일 푼다"고 말하고, 학술 근거도 같은 방향입니다. 즉시 지급도 퍼핀이 잘하는 축이라 건드리면 손해입니다.
→ 이 제안은 **돈을 빼는 게 아니라 돈이 못 하는 일(질·누적 가시화)을 채우는 것**입니다.
