**② 부모 페인포인트의 논점을 「금융 순도」로 고정**

퍼핀 **App Store 앱 설명 원문**에서 확인한 것입니다.

- 퀴즈 과목: **"경제, 금융, 한국사, 시사, 어휘, 투자, 과학기술"** → **7개 중 4개가 금융이 아님**

→ 우리가 쓸 논점은 **"금융 커리큘럼이라면서 한국사·어휘가 섞여 있어 금융만 따로 확인할 수 없다"** 입니다.
