# 2. 유림 — 시장 규모와 고객 세분화

📁 [`유림/시장분석/`](4. TAM-SAM-SOM_Market-Segment/)

### 어떻게 조사했나
공공통계(아동 인구) + 시장조사기관 자료 + **퍼핀 실적으로 역산**. 모든 수치에 근거등급 `[A][B][C]` 부여.

### 무슨 내용인가

| 단계 | 결과 |
|---|---|
| TAM (글로벌 전체) | 약 5.9조원 |
| SAM (게임 요소 결합) | 글로벌 1.2~2.6조 / **국내 실제 화폐화 29~50억** |
| 타깃 고객 | 초등 1~3학년 97.6만 → 용돈받는 81.8만 → **「성장증명형」 29.3만명** |
| 1년차 SOM | **440가구 / 약 2,600만원** |

### 🔴 제일 중요한 발견

**구독 매출만으로는 사업이 안 됩니다.** 퍼핀으로 역산하면:

```
퍼핀 구독 매출  약 2.4억  (4,000명 × 5,000원 × 12개월)
퍼핀 전체 매출  약 14억
────────────────────────────
차액 11.6억 = 결제 수수료 + 충전 잔액 + 금융사 제휴
```

→ **「구독 + 결제 수수료 + 제휴」 3중 수익모델이 전제**여야 함

⚠️ 단 **"퍼핀은 체계가 없다"는 쓸 수 없습니다.** 퍼핀이 "15단계 레벨 경제금융학습 커리큘럼"을 명시하고 있어서, 논점은 **체계 유무가 아니라 금융 순도**입니다.

# 6. 🔴 팀 전체를 관통하는 발견 3개

## ① 1차 페인포인트의 리뷰 근거가 무너졌다 — 그런데 대응은 이미 있다

하영이 발견하고 혜원이 대응 전략을 세웠습니다. **가설이 틀린 게 아니라 증거 유형이 틀렸다**는 정리가 설득력 있습니다.
→ 발표에서 정직하게 다루면 **「근거와 추론의 투명성 10점」** 에 오히려 유리합니다.

## ② 퍼핀에 이미 있는 기능이 생각보다 많다

병윤(약관) + 하영(공식자료)이 각각 찾은 것을 합치면:

| 이미 있음 | 출처 |
|---|---|
| 미션하기 (목표 설정 → 완료 시 보상) | 퍼핀페이 약관 별첨1 |
| 또래 집단 비교·분석 | 퍼핀페이 약관 별첨1 |
| 15단계 경제금융학습 커리큘럼 | App Store 설명 |
| **부모가 아이 학습 내역 확인** (2024-10 출시) | 개발사 답변 |
| 사진 등록·전송 (미션 인증용) | 퍼핀페이 약관 제15조 |

→ **"이걸 만들자"고 하면 이미 있는 걸 제안하는 게 됩니다.** 개선안 잡을 때 반드시 대조 필요.

## ③ 돈 보상은 빼면 안 된다 — 3명이 같은 결론

| 누가 | 근거 |
|---|---|
| 하영 (리뷰) | 긍정 126건 vs 부작용 11건 |
| 하영 (학술) | 인센티브는 행동의 **양**을 확실히 늘림 |
| 유림 (시장) | 실패 요인 1·2위는 "행동 전이 안 됨"·"성장 증거 없음" — 돈 자체가 아님 |

→ **"돈 대신 별"이 아니라 "돈이 못 하는 일을 별이 채운다"** 로 프레이밍해야 합니다.

| | 하영 (6단계 결론) | 혜원 (근거보강 결론) |
|---|---|---|
| 1순위 문제 | **금융 학습의 누적을 구분해서 보이게** | **아이가 성장하는 느낌을 못 받음** (1차 유지) |
| 금융 순도(비금융 퀴즈 섞임) | 🔴 **핵심 논점** | ❌ **기각** — "핵심 근거 1건·역방향이라 더 위험하고, 별⭐/아바타라는 차별점과 무관해짐" |
| 근거 전략 | 퍼핀 공식자료 중심 | 이론 + 산업비교 + 팀 직접사용 3계층 |

**두 사람이 같은 사실(리뷰 근거 부족)에서 다른 결론으로 갔습니다.**

### 겹치는 부분은 있습니다

둘 다 **「성장·누적이 안 보인다」** 는 데는 동의합니다. 갈리는 건 **"그 원인이 금융 순도냐, 성장 가시화 부재냐"** 입니다.

### 정하는 방법 — 하영이 이미 제안했습니다

> **부모 3~5명에게 한 문장만 물어보면 갈립니다.**
> "아이 금융 퀴즈에 한국사·어휘가 섞여 있는 걸 알고 계셨나요? 그게 문제라고 느끼시나요?"

**8/19 오전에 이것부터 하시는 걸 권합니다.** 답에 따라 1순위 개선 기회가 바뀌고, 그게 8/20 전체를 결정합니다.
