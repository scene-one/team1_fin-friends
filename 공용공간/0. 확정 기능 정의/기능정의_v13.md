# 3. 🌳 성장 나무 · 🌲 월간 숲 — **부모 화면 전용**

## 왜 부모 화면에만 두는가

| 화면 | 동기 장치 | 왜 |
|---|---|---|
| **아이** | 👕 **옷장** (별 누적 → 해금) | 7세에게 나무 4개 + 진도율 + 정답률은 **정보 과부하**. "별 몇 개 더 모으면 새 옷"이 훨씬 직관적 |
| **부모** | 🌳 **나무 4개** | 부모가 원하는 건 "얼마나 했나"가 아니라 **"어디까지 자랐나"** |

**아이는 옷장으로 움직이고, 부모는 나무로 확인합니다.**

## 3-1. 🌳 성장 나무 — 4개 영역, 4개 나무

```
   💰 벌기        🛒 잘 쓰기      🐷 모으기      🌱 불리기
    🌳             🌿              🌱             🌱
   나무           새싹            씨앗           씨앗
```

**함께 표시되는 실시간 지표** — 진도율 · 퀴즈 정답률 · 미션 수행률.

**매일 바뀌는 것** — 나무의 성장 진행도 · 진도율 · 정답률 · 미션 수행률 (실시간 반영).

### 성장 조건 — 3종을 모두 채워야 다음 단계

각 성장 단계마다 **학습 완주 횟수 · 퀴즈 정답 개수 · 행동 실천 횟수** 가 정해져 있습니다.

| 예시 | 조건 |
|---|---|
| **새싹 → 나무** | 학습 완주 **3회** + 퀴즈 정답 **5개** + **행동 실천 1회** |

### 🔄 초기화 주기는 나무마다 다릅니다

| 나무 | 초기화 주기 |
|---|---|
| 💰 **벌기** · 🛒 **잘 쓰기** · 🐷 **모으기** | **매달** — 달이 바뀌면 씨앗부터 다시 |
| 🌱 **불리기** | **가입한 적금 상품의 만기 기준** — 적금 시작일부터 만기까지가 한 주기 |

```
[벌기 · 잘 쓰기 · 모으기]
1월          2월          3월
🌳 나무  →  🌱 씨앗  →  🌿 새싹      (매달 다시 시작)
   ↓            ↓            ↓
🌲 1월 숲     🌲 2월 숲     🌲 3월 숲     ← 쌓인다

[불리기]
적금 시작 ─────────────────────────→ 만기
🌱 씨앗  →  🌿 새싹  →  🌳 나무          (상품 기간이 한 주기)
```

| 왜 이렇게 나누나 | |
|---|---|
| **벌기·잘 쓰기·모으기 = 매달** | 지난달에 못했어도 부담 없이 재도전. 월 단위로 목표를 새로 세우고 부모·아이가 변화를 함께 돌아봄 |
| **불리기 = 적금 만기** | 적금은 **여러 달에 걸쳐 부어야 완성되는 행동**이므로, 매달 초기화하면 진행이 끊긴다. 상품 기간을 그대로 한 주기로 삼아 만기까지 계속 자란다 |
| 장기 기록은 숲이 담당 | 나무는 "이번 주기", 숲은 "지금까지" |

> ⚠️ **초기화되는 건 나무뿐입니다.** ⭐ 별은 초기화되지 않고 그대로 남습니다.

## 🔴 왜 이게 문제 정의를 정면으로 치는가

**성장 조건에 「행동 실천 횟수」가 들어 있습니다.**

```
퀴즈만 100개 풀어도  →  나무는 안 자란다
실천을 1번 해야      →  다음 단계로 간다
```

**퍼핀은 퀴즈 개수만 셉니다.** 우리는 **실천 없이는 나무가 멈추게** 설계했습니다.
→ 나무가 자랐다 = **"우리 애가 배운 걸 실제로 했다"** 는 증거

**문제 정의 ①(부모가 성장을 체감할 수 없다)과 ②(학습이 실천으로 안 이어진다)를 한 화면이 동시에 답합니다.**

나무가 아이 화면에 없으므로, **아이 쪽 실천 유도는 별 지급 규칙(§4)이 전담합니다.**

## 3-2. 🌲 월간 숲 — 월말에 총정리

**4칸 내용이 한 화면 안에 정리됩니다.**

```
┌─────────────────────────────────────────────┐
│  🌲 2026년 3월 숲                            │
├─────────────────────────────────────────────┤
│  이번 달 한 줄                                │
│  "쓰기와 모으기가 함께 자랐습니다"              │
├─────────────────────────────────────────────┤
│  🌳 4개 영역 최종 단계                        │
│     벌기 🌳 나무   잘 쓰기 🌿 새싹             │
│     모으기 🌱 씨앗  불리기 🌱 씨앗              │
├─────────────────────────────────────────────┤
│  📚 학습    완주 12회 · 퀴즈 정답률 78%        │
├─────────────────────────────────────────────┤
│  🏃 실천    미션 8회 · 사려다 멈춤 5회          │
│             위시리스트 70% 달성 · 적금 가입     │
├─────────────────────────────────────────────┤
│  💳 소비    총 지출 32,000원 · 저축 15,000원   │
├─────────────────────────────────────────────┤
│  📈 지난달과 비교                             │
│     사려다 멈춤   2회 → 5회                   │
│     가격 비교     0회 → 4회                   │
│     저축률       12% → 32%                   │
├─────────────────────────────────────────────┤
│  ⭐ 이번 달 획득 별  46개                      │
└─────────────────────────────────────────────┘
```

| 왜 하나로 묶나 | |
|---|---|
| 4개로 나누면 | 부모가 4번 봐야 하고, **영역 간 연결이 안 보임** |
| **하나로 묶으면** | *"쓰기를 배웠더니 저축이 늘었다"* 같은 **연결이 드러남** |

**「지난달과 비교」가 핵심입니다.** 유림 시장분석의 결론이 *"부모에게 필요한 건 활동량이 아니라 성장 증거"* 인데, **전월 대비 변화가 그 증거**입니다.

## 📐 3층 구조

| 층 | 무엇 | 초기화 | 누가 보나 | 역할 |
|---|---|---|---|---|
| **1** ⭐ **별** | 벌면 늘고, 옷 사면 줄어드는 **잔액** | ❌ **없음 — 계속 이어짐** | **아이** | **즉각 보상** |
| **2** 🌳 **성장 나무** | 이번 주기 성장 단계 | ⭕ **벌기·잘 쓰기·모으기 매달** · **불리기 적금 만기** | **부모** | **이번 주기 성취** |
| **3** 🌲 **월간 숲** | 그 달의 성과를 정리 | ❌ **쌓임** | **부모** | **장기 성장 증거** |

```
⭐ 별       계속 이어짐   →  몇 달 모아서 비싼 옷을 살 수 있다
🌳 나무     주기마다 초기화 →  벌기·쓰기·모으기는 매달, 불리기는 만기마다 새로 도전한다
🌲 숲       쌓인다        →  1년치 성장이 보인다
```

**나무만 초기화됩니다.** 별이 초기화되면 여러 달 모아서 좋은 아이템을 사는 재미가 사라지므로, **별은 잔액처럼 계속 이어집니다.**

하영이 조사한 학술 근거와 대응합니다 — *"인센티브는 행동의 **양**, 내재동기는 **질**을 예측"* (183편·21만명). 별은 양(즉각 보상), 나무·숲은 질(성장 증거)입니다.

> 💡 **별을 차감해도 규제 문제는 없습니다.** 별은 ① 돈으로 산 게 아니라 **금전적 가치가 아니고** ② 옷은 자사 앱 내 아이템이라 **제3자 거래도 아닙니다** — 전자금융거래법 제2조 제14호 요건 둘 다 미충족.
> 모든 모바일 게임이 게임 재화로 아이템을 구매하지만 선불업 등록을 하지 않는 것과 같습니다.

## 4-3. 별에서 지켜야 할 선 3개

# 5. 📍 위치 알림 + 💳 결제 회고 — 5단계 루프

```
① 계획       "다이소에서 5,000원까지 쓸 수 있어"
             ← 부모 또는 아이가 미리 정해둠
                        ↓
② 알림 확인   아이가 계획해둔 장소 범위에 있고,

                        ↓

                        ↓
④ 결제 이후   계획 금액 ↔ 실제 결제 금액 비교 화면 제시
                        ↓
⑤ 결제 회고   별을 받은 이유 / 못 받은 이유 제시
             → [확인했어요] 클릭 → ⭐ 1개 지급
```

| ⑤단계에서 | |
|---|---|
| **아이가 하는 것** | 비교 화면을 보고 **[확인했어요] 한 번** |

**그 순간에 아이에게 회고까지 시키면 너무 복잡하므로, 앱이 대신 말해주고 아이는 읽고 넘어갑니다.**

# 12. 🔥 발표 포인트 3개

## ① 학습을 실천으로 잇는다 — **나무가 증거입니다**

> **부모가 보는 나무는 성장 조건에 「행동 실천 횟수」가 들어 있어, 퀴즈만 100개 풀어도 자라지 않는다.**

> 퍼핀 퀴즈는 **7과목 중 4개가 비금융**(한국사·시사·어휘·과학기술)이라 **구조적으로 못 따라온다.**

## ② 소비 앞과 뒤를 모두 잡는다
> 퍼핀은 **쓴 다음에** 기록한다. 우리는 **쓰기 전에 개입하고, 쓴 뒤에 회고한다.**
> **매장에 3분 이상 머무르면** 알림이 간다. 리테일이 10년간 써온 지오펜싱 마케팅을 정확히 반대로 쓴다 — "사세요"가 아니라 **"지금 사면 목표까지 3주 늦어져요."**
> 그리고 카드 결제 내역으로 계획과 실제가 자동 비교된다. 알림 → 판단 → 결과가 한 고리로 닫힌다.

## ③ 저축에 이유를 만든다
> 저축 격차 53%p — 부모가 원하는 것 1위 **저축 65.8%** ↔ 아이가 하는 것 꼴찌 **12.8%**.
> 아이가 저축을 안 하는 건 **이유가 없어서**다.
> **위시리스트 30/70/100% 단계 지급**과 **적금 완주 ⭐10** 이 그 이유를 만든다.
> Greenlight는 이미 한다 — 부모가 이자율을 직접 설정하고 **평균 19.84%** 를 준다.

| (b) "별 상관없다" | ⚠️ 「금융 100%」를 차별점으로 내세우지 말고 **실천 연결만** 앞세움 |
| (c) "여러 과목이 좋다" | 🔴 포지션 변경 |

# 14. 남은 설계 질문

| 질문 | 왜 |
|---|---|
| 나무 **성장 단계 몇 개** · 단계별 조건 수치 | 콘텐츠 분량과 체류 기간이 여기서 결정 |
| 🔄 **매달 조건이 같은가, 올라가는가** | 같으면 지루하고, 올라가면 좌절. 난이도 곡선 설계 필요 |
| 동물 **몇 종** · 옷 **몇 벌** · 가격표 | 3D 에셋 제작량 = 개발 비용 = 별 모을 이유의 총량 |
| 부모 이자 **주기** — 주 단위(복리 체감) vs 월 단위(Greenlight 방식) | 체감 vs 부모 부담 |
| 「불리기」에 **모의투자 넣을지** | ⚠️ 퍼핀 앱 이름이 *"퍼핀 - 용돈기입장, **모의투자**, 돈버는퀴즈"* → 넣으면 클론 |
| 미션 **사진 인증** 넣을지 | 퍼핀 「사진등록·전송」과 동일 기능 + 아동 이미지 리스크 |
