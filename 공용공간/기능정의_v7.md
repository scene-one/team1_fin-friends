# 1. 핵심 구조 — 4칸으로 학습과 행동을 잇는다

```
        📚 배운다                🏃 실제로 한다
       ─────────────           ────────────────────
   벌기   소득의 종류      ═══   🧹 미션 수행 → 용돈
  잘 쓰기 필요 vs 원함     ═══   📍 위치 알림에서 참기 + 💳 카드 결제 내역
  모으기  목표 저축        ═══   🎯 위시리스트 달성
  키우기  이자·복리        ═══   💰 부모 이자로 늘어남
                      ↓
                ⭐ 별 = "배운 걸 했다"
                      ↓
          🐾 동물 + 👕 옷장 해금        🌳 부모: 4칸 통과 현황
```

## 왜 이게 엣지인가

**퍼핀은 위 칸(학습)과 아래 칸(행동)이 만나지 않습니다.**
"이자율 퀴즈"를 풀게 하고, 별개로 "편의점 2,000원"을 기록합니다. 둘을 연결하지 않아요.

| | 퍼핀 | **핀프렌즈** |
|---|---|---|
| 별(보상)을 언제 주나 | 퀴즈를 맞히면 | **실제로 했을 때** |
| 증명하는 것 | "문제를 풀었다" | **"배운 걸 실제로 했다"** |
| 부모가 보는 것 | "문제 75개 풀었어요" | **"쓰기 단계를 통과했어요"** |

## 🔴 퍼핀이 구조적으로 못 따라옵니다

퍼핀 퀴즈는 **7과목 중 4개가 비금융**(한국사·시사·어휘·과학기술),
플러스 월간 퀴즈는 **4개 중 3개가 비금융**(사자성어·수능 비문학 어휘·뉴스시사용어)입니다.

> **"사자성어 퀴즈"를 실제 소비 행동과 어떻게 연결하겠습니까?**

우리는 **금융 4주제만** 하므로 하나하나 실제 행동과 짝이 맞습니다.
퍼핀이 따라하려면 **자기 퀴즈 절반을 버려야 합니다.**

# 2. ⭐ 별의 정의 — 차감 없이 쌓이고, 누적으로 해금된다 ✅ 확정

| | |
|---|---|
| 별은 **차감되지 않습니다** | 쓰는 게 아니라 **쌓이기만** 함 → 학습량 눈금이 그대로 남음 |
| 옷은 **누적 별 개수가 조건** | "별 100개를 모으면 모자가 **해금**" |
| 입는 건 **아이가 선택** | 꾸미는 재미는 유지 |

## ⚠️ 정정 — 별은 애초에 선불전자지급수단이 아닙니다

**v6에서 제가 "구매 ❌ / 해금 ⭕" 문구를 규제 이유로 구분했는데, 과한 걱정이었습니다.**

**전자금융거래법 제2조 제14호** 요건:

| 요건 | 별⭐ |
|---|---|
| ① 이전 가능한 **금전적 가치** | ❌ 돈으로 산 게 아님. 현금 전환·양도 불가 |
| ② **제3자로부터** 재화·용역 구입 + 대가 지급 | ❌ 옷은 **자사 앱 내 아이템.** 제3자가 아님 |

**요건 둘 다 미충족 → 차감형이어도 해당 없습니다.** (모든 모바일 게임이 게임 재화로 아이템을 구매하지만 선불업 등록을 하지 않습니다.)

**→ 「누적·해금」 방식은 규제 때문이 아니라 「별 = 학습량 눈금」이라는 제품 정의 때문입니다.**

## 🔴 별에서 진짜 지켜야 할 선 3개

| 하면 안 되는 것 | 왜 |
|---|---|
| ❌ **현금으로 별 충전** | 대가를 지급하고 취득 → 금전적 가치가 됨 |
| ❌ **별을 현금으로 환급** | 같은 이유 |
| ❌ **별 양도·거래·선물** | "이전 가능" 요건 충족 |

> 💡 별과 돈(저금통)은 **완전히 분리된 재화**입니다. 교차하는 지점이 없어야 합니다.

# 3. 🔴 선불업 B2B 제휴 — v7의 최대 변경

**부모가 자기 은행앱에서 직접 이체하는 구조를 폐기하고, 앱 안에서 돈이 움직이게 합니다.**

## 3-1. 두 가지 제휴 모델

| | **A. 직접 등록 + 카드사 대행** | **B. 기존 선불업자 인프라 활용** |
|---|---|---|
| 라이선스 | **우리가 선불업 등록** | **제휴사가 보유** |
| 자본금 20억 | 🔴 필요 | ✅ 불필요 |
| 카드 발급 | 카드사가 대행 | 제휴사가 발행 |
| 예시 | **퍼핀** — 레몬트리 등록 + KB국민카드 대행 | 코나아이 등 — "비금융사도 카드 발행" |
| 통제력 | 높음 | 낮음 (수수료·조건 종속) |

**→ 역기획 제안에서는 B를 전제로 쓰는 것을 권합니다.** 자본금 20억 없이 성립하고, 실제 사례도 있습니다.

## 3-2. 선불업 구조가 되면 생기는 의무

| 의무 | 내용 | 누가 지나 |
|---|---|---|
| **선불충전금 100% 별도관리** | 신탁 / 예치 / 지급보증보험 중 하나로 은행 등 관리기관에 | **A면 우리 · B면 제휴사** |
| 별도관리 방법 **고지·상시 게시** | 계약 시 고지 + 홈페이지 항상 게시 | 동일 |
| 이용한도 관리 | 참고: 퍼핀은 만 14세 미만 **50만원** 한도 | 동일 |
| 미등록 시 처벌 | 3년 이하 징역 또는 2천만원 이하 벌금 | — |

**🔴 PRD에 "제휴사가 선불업자이고, 충전금 별도관리 책임도 제휴사에 있다"를 명시해야 합니다.** 이게 빠지면 실행조건 분석이 비어 보입니다.

## 3-3. 파급 효과 — 좋아지는 것

| | v6 (부모 직접 이체) | **v7 (선불업 제휴)** |
|---|---|---|
| 미션 보상 지급 | 부모가 은행앱에서 직접 | ✅ **앱 안에서 즉시** |
| 부모 이자 지급 | 부모가 직접 이체 | ✅ **앱 안에서 자동** |
| 「잘 쓰기」 결제 기록 | 수동 입력 | ✅ **카드 결제 자동 수집** |
| 위치 알림 → 결제 → 결과 | 고리가 끊김 | ✅ **한 고리로 닫힘** |
| 수익모델 | 구독만 (연 2,590만원) | ✅ **구독 + 결제 수수료 + 제휴** |

**유림 시장분석의 「구독만으로는 사업이 안 된다」가 이걸로 해결됩니다.**

```
퍼핀 구독 매출   약 2.4억
퍼핀 전체 매출   약 14억
──────────────────────────
차액 11.6억 = 결제 수수료 + 충전 잔액 + 제휴
```

## 3-4. 앱 밖의 현금은 **의도적으로 범위 밖**입니다

「용돈 지급 수단 현금 48.9%」라는 숫자가 있지만, 이건 **커버리지 공백이 아닙니다.**

```
부모가 우리 앱을 쓰기로 한다  →  용돈을 카드로 충전한다  →  현금으로 안 준다
```

**48.9%는 「앱을 안 쓰는 가정」의 현황이고, 고객이 되는 순간 카드로 전환됩니다.**

### 그럼 남는 현금은?

| 현금 종류 | 누가 정하나 | 우리 범위 |
|---|---|---|
| 정기 용돈 | 부모 → 카드 충전 | ⭕ 포함 |
| **세뱃돈 · 친척 용돈 · 심부름값** | **아이가 알아서** | ❌ **제외** |

두 번째는 용돈이 아니라 **선물**이고, 저금하든 쓰든 아이 재량입니다.

**추적하려 하면 오히려 나빠집니다** — 아이가 매번 수동 입력해야 하고, 안 하면 데이터가 비어 성장 리포트의 정확도가 떨어집니다. **아예 안 잡는 게 데이터 신뢰도가 높습니다.**

### 🔥 PRD 「범위」에 이렇게 씁니다

> **포함** — 앱을 통해 충전된 용돈의 흐름 (벌기 → 잘 쓰기 → 모으기 → 키우기)
>
> **제외** — **앱 외부에서 오간 현금**(세뱃돈·친척 용돈 등). 아이의 자율 영역이며, 수동 입력에 의존하면 데이터 신뢰도가 떨어져 성장 리포트의 정확성을 해칩니다.

가이드가 PRD 요건으로 **"포함·제외 범위가 구분된다"** 를 요구하고, 「너무 넓은 범위」를 경고합니다.
**"안 하는 걸 알고 안 한다"가 배점입니다.**

# 5. 🧹 미션 — 퍼핀과 뭐가 다른가

**⚠️ 퍼핀에 「미션하기」가 이미 있습니다.**
> 퍼핀페이 약관 별첨1 — "멘티와 목표를 설정하고 완료 시 보상을 주는 서비스"
> 「사진등록 및 전송」 — "미션하기 인증을 위해 멘토에게 사진을 전송"

**"우리도 미션 있어요"로 발표하면 감점입니다.** 차별점은 **미션이 학습과 이어진다는 것**입니다.

| | 퍼핀 | **핀프렌즈** |
|---|---|---|
| 미션 | 있음 | 있음 |
| 보상이 가는 곳 | 그냥 잔액 | **「벌기」 칸에 누적** |
| 학습과의 연결 | ❌ 없음 | ✅ **「벌기」 학습 → 미션 실행 → 같은 칸에 기록** |
| 아이가 배우는 것 | — | **"노동의 대가로 돈이 생긴다"를 실제로 경험** |

## 💡 미션이 있어야 「벌기」라는 이름이 맞습니다

미션이 없으면 아이가 하는 건 **용돈 받기**뿐이라 「벌기」 학습(소득의 종류·근로소득)과 어긋납니다.
**미션 = 근로소득 체험.** 교육 주제와 실제 행동이 일치합니다.

## ⚠️ 사진 인증 — 넣을지 미정

퍼핀과 동일 기능입니다. 넣는다면:
- 사진은 **부모에게만** 전달 · **서버 저장 안 함**

# 7. 🗣️ 아이 눈높이 용어

**개인정보 보호법 제22조의2 제3항** — 아동에게는 "이해하기 쉬운 양식과 명확하고 알기 쉬운 언어"를 사용해야 합니다. **법정 의무**이고 퍼핀은 안 하고 있습니다.

| 부모·발표용 | **아이 화면** | 한 줄 설명 |
|---|---|---|
| 벌기 (소득) | **💰 벌기** | 일하면 돈이 생겨요 |
| 쓰기 (소비) | **🛒 잘 쓰기** | 진짜 필요한 걸까? |
| 모으기 (저축) | **🐷 모으기** | 안 쓰고 두면 쌓여요 |
| **불리기 (이자·복리)** | **🌱 키우기** | 모아두면 **저절로** 늘어나요 |

> **💰 돈이 생기고 → 🛒 잘 쓰면 → 🐷 모이고 → 🌱 저절로 자라요**

「불리기」는 7세가 모르는 말입니다. 「키우기」는 동물 키우기와도 이어져 서비스 전체 메타포가 됩니다.

# 8. 🔥 발표 포인트 3개

## ① 학습과 행동을 잇는다
> 퍼핀은 퀴즈와 카드가 따로 논다. 우리는 같은 4칸으로 묶는다.
> 퍼핀은 퀴즈 7과목 중 4개가 비금융이라 **구조적으로 못 따라온다.**

## ② 소비 직전에 개입하고, 결과까지 닫는다 *(v7 신규)*
> 퍼핀은 **쓴 다음에** 기록한다. 우리는 **쓰기 전에** 개입한다.
> 리테일이 10년간 써온 지오펜싱 마케팅을 정확히 반대로 쓴다 — "사세요"가 아니라 **"지금 사면 목표까지 3주 늦어져요."**
> 그리고 카드 결제 내역으로 **참았는지 아닌지가 자동으로 확인된다.** 알림 → 판단 → 결과가 한 고리로 닫힌다.
>
> **그리고 우리는 앱 밖의 현금은 추적하지 않는다.** 아이의 자율 영역이고, 수동 입력에 의존하면 리포트의 신뢰도가 떨어지기 때문이다.

## ③ 저축 격차 53%p를 이자로 친다
> 부모가 원하는 것 1위 **저축 65.8%** ↔ 아이가 하는 것 꼴찌 **12.8%**
> 아이가 저축을 안 하는 건 **이유가 없어서**다. 이자가 이유를 만든다.
> Greenlight는 이미 한다 — 부모가 이자율을 직접 설정하고 **평균 19.84%** 를 준다.
