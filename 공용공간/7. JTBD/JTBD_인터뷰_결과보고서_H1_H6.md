# 1. 요약 — 두 장의 카드가 말하는 것

| | **H1 정미경** | **H6 임태경** |
|---|---|---|
| **Segment** | Core / ① 금융성장 증명형 (29.3만·35.8%) | Adjacent / ③ 용돈 소비통제형 (13.3만·16.3%) |
| **Job** | 배운 것이 **행동으로 이어졌는지 확인**하고 싶다 | 말 말고 다른 수단으로 **지출을 줄이고** 싶다 |
| **최고 AOS** | 3.2 (C2·C3) | **4.0 (A6 · 전체 1위)** |
| **최고 DOS(SOM)** | **3.00 (C1·C2 · 전체 1위)** | 1.20 (A6 · 7위) |
| **판정** | 🟢 **1차 타깃 — 지금 만든다** | ⚠️ **1차 타깃 제외 · 제품에서 배제하지 않음** |

> 🔴 **두 카드의 Job Statement가 서로 다릅니다.** H1은 「확인」, H6은 「감축」입니다. **제품의 Job은 H1 쪽이고, H6은 성공 기준 자체가 다른 고객**입니다. 이 차이가 AOS와 DOS의 순위를 정반대로 만듭니다.

# 6. 한계와 사용 금지선

- 🔴 **이 문서는 인터뷰 결과가 아니라 「가설 카드」입니다.** 부모 0건·아이 0건 상태이며, **Evidence의 인용문 자리는 비어 있습니다.** 발표·PRD에 *결과*로 인용할 수 없습니다.
- **🧪 [모의] 표기 발화는 Evidence가 아닙니다.** 모의 응답은 문항 검사용 [합성 가설]이며, 그 문서 §8이 인용을 금지합니다. 여기서는 **인터뷰에서 확인할 문장**으로만 실었습니다.
- **Desired Outcome의 수치 중 「15분 → 3분」·「주 5회 → 1회」·「30,000 → 20,000원」은 목표값이고 기준선은 미측정**입니다. 인터뷰 Q0-2·Q0-3·H6-1·H6-2에서 실측한 뒤 확정합니다.
- **AOS·DOS는 재계산하지 않고 ID로 인용했습니다.** 값이 갈리면 추적이 불가능해집니다. 원 점수 자체가 **[합성 가설] 위의 분석자 판단값**이라는 한계는 그대로 승계됩니다.
- **A5(아이 자율성)의 낮은 점수는 부모가 대신 답한 값**입니다. 아이 직접 조사(P-05 동의 · P-12 알기 쉬운 언어) 전에는 **낮다고 단정할 수 없습니다.**
- **카드는 2장뿐입니다.** 스펙트럼 v2 §3-3 모집안은 8가정이며, H2·H3·H4·H5는 2차 라운드, Extreme·Non-user는 **별도 프레임**입니다. 두 장으로 유형을 일반화하지 않습니다.
- **세그먼트 규모(29.3만·13.3만)는 모델값**입니다 — 관여도와 문제 강도의 **독립성을 가정**했고 교차조사 데이터는 공개된 바 없습니다.
- 인터뷰 후에는 **가설 카드를 삭제하지 말고** 실제 응답과 나란히 두어 **어디서 빗나갔는지** 남깁니다.
