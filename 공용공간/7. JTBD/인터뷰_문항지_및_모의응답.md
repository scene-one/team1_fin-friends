# 1. 인터뷰 설계

## 1-1. 상황 설정

**고객용 데모 페이지를 직접 체험한 뒤, 그 체험을 거울 삼아 자신의 기존 경험을 이야기하는 구조**입니다.

```
[사전] 지금 방식 확인   →  [체험] 데모 과업 수행  →  [회상] 기존 경험과 비교  →  [판단] 전환·지속
  5분 · 오염 전 기록         25분 · 관찰 중심          10분 · 구체적 사건으로     15분
```

| 항목 | 내용 |
|---|---|
| **형식** | 1:1 대면 또는 화상 · **75분** (본 인터뷰 60분 + 페르소나별 추가 15분) |
| **대상** | 부모 1인. *(아이 동석 없음 — 아이 조사는 법정대리인 동의 후 별도 세션)* |
| **준비물** | 데모 페이지(부모/아이 화면) · 위치 알림 시나리오 카드 · 녹취 동의서 |
| **기록** | 발화 녹취 + **행동 관찰 로그**(멈춘 지점·되돌아간 지점·소요 시간) |

**데모 페이지가 반드시 담아야 하는 것** — 문항이 이 화면들을 전제합니다.

| # | 화면 | 문항 연결 |
|:-:|---|---|
| ① | 부모 온보딩 5단계 (본인인증 → 계좌 → 카드 신청 → 자녀 초대 → 카드 등록) | T1 · Q4-1 |
| ② | 아이 온보딩 (짧은 학습 → 퀴즈 → ⭐1 → **⭐1로 살 수 있는 아이템**) | T2 |
| ③ | 🌳 **성장 나무** 4칸 + 진도율·정답률·미션 수행률 | T3 |
| ④ | 🌲 **월간 숲** (지난달과 비교 포함) | T4 |
| ⑤ | 📍 위치 알림 → 결제 회고 5단계 시나리오 카드 | T5 |
| ⑥ | 🧹 미션 생성·승인 화면 (부모) | T6 |

## 1-2. ⚠️ 순서 효과를 어떻게 막았는가

**데모를 먼저 보면 기존 경험 회상이 오염됩니다.** 새 화면을 본 직후에는 지금 쓰는 것이 실제보다 나빠 보이고, 없던 불만이 생깁니다.

그래서 **Part 0(4문항)만 데모 앞에 두고**, 나머지 회상은 데모 뒤에 둡니다.

| 무엇을 | 언제 | 왜 |
|---|---|---|
| **현재 루틴·마지막 확인 행동·아쉬운 점 1개** | **데모 전** | 이것만은 오염되면 baseline이 사라짐 |
| 나머지 회상·비교·전환 판단 | 데모 후 | 데모라는 **공통 기준점**이 있어야 비교가 구체적으로 나옴 |

> Part 3의 회상 답변은 **Part 0의 답변과 대조해서** 읽습니다. 두 답이 어긋나면 그것이 **데모가 만든 인식 변화**이며, 그 자체가 데이터입니다.

## 1-3. 문항 작성 원칙

| 원칙 | ❌ 이렇게 쓰지 않는다 | ✅ 이렇게 쓴다 |

| **평가 대신 재연** | "온보딩이 번거로우셨나요?" | "여기까지 오시는 데 뭘 하셨는지 순서대로요" |

# 8. 한계와 사용 금지선

- 🔴 **5·6부의 응답은 전부 [합성 가설]입니다.** 실제 인터뷰가 아니며, **"고객이 이렇게 말했다"로 인용할 수 없습니다.** 7부의 「발견」도 모의 응답에서 도출된 것이므로 **가설의 예행연습**이지 결과가 아닙니다.
- **모의 응답을 쓴 목적은 문항 검사입니다.** *"이 질문에 어떤 답이 나와도 판정이 되는가"*를 확인하려는 것이며, 실제 응답이 여기서 벗어나는 것이 **정상**입니다.
- **모의 응답은 작성자의 가설에 유리하게 기울 수 있습니다.** 그래서 H1에서 **검증과제 ①(b)**와 **C3 반증**을, H6에서 **리프레이밍 실패**를 의도적으로 포함시켰습니다. 그럼에도 편향이 남아 있다고 가정하고 읽어야 합니다.
- **표본이 2명입니다.** 스펙트럼 v2 §3-3 모집안은 최소 8가정이며, 본 문항지는 나머지 6슬롯에도 그대로 적용됩니다. **2명의 응답으로 유형을 일반화하지 않습니다.**
- **아이 응답은 이 문항지에 없습니다.** Q1-13·H6-5는 **부모가 예상한 아이 반응**이며 아이의 진술이 아닙니다. 아이 조사는 법정대리인 동의(P-05)와 알기 쉬운 언어(P-12)로 **별도 설계**가 필요합니다.
- **데모 품질이 응답을 좌우합니다.** §1-1의 화면 ①~⑥이 갖춰지지 않으면 T1~T6이 성립하지 않고, 특히 **T3(5초 회상)은 완성도가 낮으면 「못 읽음」이 디자인 탓인지 개념 탓인지 구분되지 않습니다.**
- 실제 인터뷰 후에는 **모의 응답을 삭제하지 말고**, 실제 응답과 나란히 두어 **어디서 빗나갔는지**를 남깁니다.
