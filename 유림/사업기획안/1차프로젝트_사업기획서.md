# 1. 요약

## 한 줄 정의

> **금융 학습의 진도와 성장률이 눈에 보이면, 아이는 스스로 돌아와 배우고 부모는 구독을 유지한다.**

## 네 칸 요약

| | 내용 |
|---|---|
| **① 문제** | 아이도 부모도 **아이의 금융 학습이 얼마나 자랐는지** 확인할 방법이 없다. 그래서 퀴즈가 '돈 버는 버튼'이 된다 |
| **② 해법** | 금융 100% 커리큘럼 위에서 **별⭐로 학습량을 재고**, 그 눈금에 따라 **동물 아바타가 자란다** |
| **③ 시장** | 1년차 SOM **440가구 · 3,100만원**. 구독 단독으로는 안 되고 **구독 + 결제수수료 + 제휴** 3중 구조가 전제 |
| **④ 차별점** | 국내 3사(퍼핀·아이쿠카·아이부자) 모두 **「학습 → 성취/성장」 구간이 공백**. 해외 2사만 채웠다 |

## v3에서 바뀐 것 — 6가지

| # | 항목 | v3 (기존) | **v4 (확정)** |
|---|---|---|---|
| 1 | 페인포인트 | 아이 성취감 / 부모 확신감 **2개로 분리** | **통합** — "아이의 성장을 확인할 수 있는가" |
| 2 | 학습 주제 | 금융 중심(범위 미확정) | **금융으로 한정** |
| 3 | 차별점 | 보상을 성장으로 남김 | **금융 학습 진도 및 성장률 시각화** |
| 4 | 별⭐의 역할 | 모아서 옷을 사는 **보상 재화** | **성장 지표** — 쓰지 않고 쌓이기만 하는 눈금 |
| 5 | 아바타 | 사람 아바타 + 옷장 꾸미기 | **동물** — 토스 「고양이 키우기」 방식 |
| 6 | 기능 구조 | 학습 루프 + **미션 루프** | 학습 루프 + **금융 행동 4기능** (미션 루프 삭제) |

# 2. 문제 정의

## 2-1. 아이와 부모의 페인포인트는 하나로 모인다

```
🧒 아이                              👨‍👩‍👧 부모
퀴즈를 풀고 현금을 받지만            학습현황에 남는 건
"내가 얼마나 늘었는지"가 안 보임      116일 · 75개 · 6,650원 숫자 3개
→ 퀴즈가 '돈 버는 버튼'이 됨          → "무엇을 배웠는지"는 어디에도 없음
        │                                    │
        └──────────────┬─────────────────────┘
                       ▼
        퍼핀에서는 아이의 금융 학습이
        얼마나 자랐는지 확인할 수 없다
```

> **통합 페인포인트**
> **아이도 부모도, 아이의 금융 학습이 얼마나 자랐는지 확인할 수 없다.**

두 사람이 다른 문제를 겪는 게 아니라, **같은 결핍을 다른 위치에서 겪고 있습니다.** 그래서 해법도 하나입니다 — 성장을 보이게 하는 것.

## 2-2. 근거 3계층 — 리뷰가 아니라 원문과 실사용으로

| 계층 | 확인한 것 | 상태 |
|---|---|---|
| **A. 팀 직접사용** | **E-11** 부모 학습현황이 숫자 3개뿐<br>**E-12** 오답에도 보상 절반 지급 (퍼핀 공식 사양) | ✅ 캡처 확보 |
| **B. 퍼핀 공식 원문** | 공식 블로그 「2월 월간 퀴즈」 = 투자왕 · **뉴스시사용어 · 사자성어와 속담 · 수능 비문학 어휘**<br>→ **4개 중 3개가 비금융**<br>보너스 퀴즈 상당수가 `sponsored-map-` 제휴 스폰서 콘텐츠 | ✅ 원문 확인 |
| **C. 경쟁 비교** | 국내 3사 모두 **「학습 → 성취/성장」 구간 공백** · 해외 2사(gohenry·Greenlight)는 채움 | ✅ 공개자료 |
| D. 리뷰 921건 | **보조 근거로 강등** — 성장 결핍 언급 3건(0.3%)에 그침 | ⚠️ 주근거 아님 |

**왜 리뷰를 주근거에서 뺐는가** — 아이가 "성장감이 없어요"라고 스토어 리뷰에 쓰는 일은 일어나지 않습니다. 가설이 틀렸다는 신호가 아니라, **증거 유형을 잘못 골랐다는 신호**입니다.

> ⚠️ **발표에서 이렇게 말하면 안 됩니다**
> ~~"퍼핀은 학습 체계가 없다"~~ → 퍼핀은 **15단계 경제금융학습 커리큘럼**을 명시하고 있습니다.
> ✅ 논점은 **체계의 유무가 아니라 「금융 순도」와 「성장 가시화」** 입니다.

# 3. 시장과 타깃

## 3-1. TAM — SAM — SOM

| 단계 | 규모 | 산출 |
|---|---|---|
| **TAM** (초등 연령대) | **약 2.6조원** | 글로벌 키즈 금융 플랫폼 5.9조원(2025) × 6~12세 세그먼트 44.1%<br>CAGR 13.2% → 2034년 17.9조원 |
| **SAM** (국내 현재 화폐화) | **약 10~30억원** | 구독 3.8~9.2억 + 결제수수료 7.6~20.3억<br>*(이론적 천장은 785억원)* |
| **SOM** (1년차) | **440가구 · 약 3,100만원** | 가입 도달 5% × 유료 전환 3% × 월 5,900원 |

> 유료 전환율 3%는 **퍼핀 실측 1.54%**(가입 26만 중 유료 4,000명) 대비 보수적으로 잡은 값입니다.

## 3-2. 타깃 — 「금융성장 증명형」

```
초등 1~3학년 전체        97.6만명
      ↓ 용돈을 받는 아이
                        81.8만명
      ↓ 부모 관여도 × 아이 금융행동 문제 (2축 4분할)
★ 금융성장 증명형        29.3만명  (35.8% — 최대 세그먼트)
```

부모가 교육에 관여하면서 **아이의 금융행동 개선 니즈까지 있는 층**입니다.

## 3-3. 🔑 문제 정의의 출발점 — 부모와 아이가 정반대

| 부모가 원하는 교육 1위 | | 아이가 실제 쓰는 곳 꼴찌 |
|---|---|---|
| **저축 습관 65.8%** | ↔ | **저축 12.8%** |

**격차 53%p.** 이 격차가 「금융 행동 기능 ① 용돈계획」이 겨냥하는 지점입니다.

## 3-4. ⚠️ 정직하게 밝힐 것

- 국내 SAM 10~30억은 **현재 화폐화된 규모**입니다. 시장 자체가 작습니다.
- 경쟁 서비스의 게임화 기능은 **대부분 이미 무료**입니다. **유료화 자체가 이 시장의 최대 리스크**입니다.

# 4. 수익모델

## 4-1. 구독만으로는 사업이 안 됩니다

**퍼핀 한 곳의 자금 흐름** — 모두 확인값입니다.

```
유료 구독      3.8억원   (4,000명 × 96,000원)
누적 충전액  484억원     ← 구독의 127배
금융사 제휴   신한투자증권(주식) · 국민은행(적금·청약)
```

국내 게임화형 시장 전체로 봐도 **결제 수수료(7.6~20.3억)가 구독(3.8~9.2억)보다 이미 큽니다.** 돈은 구독료가 아니라 **충전·결제**로 흐릅니다.

## 4-2. 3중 수익모델

| # | 수익원 | 내용 | 시점 |
|---|---|---|---|
| **①** | **구독** | 월 5,900원. 과금 근거는 '퀴즈 개수'가 아니라 **부모용 성장 리포트** — 우리 차별점이 곧 과금 근거 | Phase 1 |
| **②** | **결제 수수료** | 자체 선불카드 결제액의 0.3~0.8%. 「소비 기록」의 데이터 출처이자 수익원 — **기능과 매출이 같은 축** | Phase 2 |
| **③** | **금융사 제휴** | 저축·적금 상품 연계. 「용돈계획」의 저축 목표가 제휴 상품으로 자연 연결 | Phase 3 |

> ⚠️ **1년차 구독 매출 3,100만원은 사업으로 성립하지 않는 규모입니다.** 추정 실패가 아니라 이 시장의 구조입니다.

# 5. 솔루션 컨셉

## 5-1. 별⭐은 보상이 아니라 눈금입니다

별은 **쓰는 재화가 아니라 쌓이기만 하는 학습량의 단위**입니다. 별이 쌓이면 동물 아바타가 자랍니다 — **사는 게 아니라 자라는 것.**

```
📚 금융 학습      →  ❓ 퀴즈 + 해설   →  ⭐ 별 누적      →  🐾 아바타 성장  ↺
벌기·쓰기         해설 열람 후 적립     소비 불가          자동 진화
모으기·불리기                          쌓이기만           구매 없음
```

**단일 루프입니다.** 부모 개입 없이 아이 혼자 완결됩니다. (퍼핀: 부모가 보상을 안 걸면 루프 정지)

## 5-2. 왜 별을 '보상'에서 뺐는가

| 근거 | 내용 |
|---|---|
| 학술 | 포인트·레벨을 **보상**으로 쓰면 **내재동기에 영향 없음** — 183편·21만명 메타분석 |
| 학술 | 같은 별을 **「학습이 얼마나 쌓였는지 보여주는 지표」** 로 쓰면 **근거 성립** |
| 규제 | 현금 교차가 원천적으로 없어 **사행성·선불업 리스크 소멸** |

> **돈은 그대로 둡니다.** 리뷰 921건에서 「돈이 학습 동기가 된다」는 긍정이 126건(13.7%), 부작용은 11건(1.2%)입니다.
> → **"돈 대신 별"이 아니라 "돈이 못 하는 일을 별이 채운다"**

## 5-3. 아바타 — 동물, 토스 「고양이 키우기」 방식

```
🥚 Lv.1 알  →⭐→  🐣 Lv.5  →⭐→  🐥 Lv.10  →⭐→  🦉 Lv.20
```

| 원칙 | 내용 |
|---|---|
| **행동하면 자동으로 자란다** | 조합·구매·선택 없음. 학습하면 그만큼 자람 |
| **유료 꾸미기 없음** | 별(노력)로만 성장 → 또래 간 박탈감 차단 |
| **성장이 즉각 눈에 보인다** | 아이에게는 이것이 '진도 그래프'의 역할 |

> 🔴 **화면 재설계 필요** — v3 시안(C1 홈 · C2 옷장)은 사람 아바타 + 옷장 구매 구조입니다. 동물 아바타 + 성장 기록으로 다시 그려야 합니다.

## 6-2. 퍼핀 대비

|---|---|---|

| **제휴 광고** | 보너스 퀴즈에 스폰서 콘텐츠 혼재(`sponsored-map-`) | **아이 화면 광고·결제 0건** (가드레일 지표) |
| **오답 처리** | "틀리면 보상의 절반을 받아요" — 오답에도 지급 | **해설 열람 후 재도전**해야 별 적립 |
| **문항 생성** | 비공개 | AI 생성 → **사람 검수 → 출제 풀 등록** (실시간 생성 금지) |

**퀴즈 앞에 반드시 학습 단계를 둡니다** — "찍어서 보상만 받는" 흐름을 구조로 차단합니다.

## 6-3. ⚠️ 최대 미검증 가정

> **"부모가 금융 집중을 원한다"는 아직 확인 전입니다.**
> 관련 리뷰 1건은 오히려 **영단어 퀴즈를 요구**하는 역방향이었습니다.
> → **부모 3~5명에게 이 한 문장만 물어보면 갈립니다:**
> *"아이 금융 퀴즈에 한국사·어휘가 섞여 있는 걸 아셨나요? 그게 문제라고 느끼시나요?"*

# 7. 핵심기능 ② 금융 행동

**학습이 지식에서 멈추지 않도록** — 배운 것을 실제 행동으로 옮기는 4개 기능입니다.

```
① 목표를 세우고  →  ② 쓰기 전에 멈추고  →  ③ 쓴 걸 기록하고  →  ④ 자란 걸 확인한다  ↺
   위시리스트         위치 기반 알림          자체 카드 + 수동       주간 성장 리포트
   + 저축 계획
```

## ① 용돈계획 — 목표 [위시리스트 + 저축]

갖고 싶은 걸 등록하면 **얼마를 몇 주 모아야 하는지**가 자동 계산됩니다.
→ 부모 저축 니즈 65.8% ↔ 아이 저축 12.8%의 **격차 53%p를 직접 겨냥**합니다.

## ② 위치 기반 알림 — 소비 전 의사결정 도우미

매장 근처에서 **"지금 사면 목표까지 3주 늦어져요"**.
→ **소비 직전, 판단이 필요한 바로 그 순간에 개입**하는 것이 핵심입니다.
→ 위치정보는 **옵트인**이며 좌표는 저장하지 않고 알림 발생 여부만 기록합니다.

## ③ 소비 기록 — 자체 카드 내역 + 수동 기록

> 🔴 **마이데이터는 쓰지 않습니다.**
> 만 14세 미만은 **전송요구권 행사 주체가 아니라** 서비스가 성립하지 않습니다.
> **퍼핀도 마이데이터 사업자가 아니고 자체 카드 데이터를 씁니다.**
> 상세: [`자료조사/마이데이터_적용가능성_검토.md`](../자료조사/마이데이터_적용가능성_검토.md)

| Phase | 데이터 출처 |
|---|---|
| Phase 1 | 아이 **수동 기록**(용돈기입장) + 앱 내 행동 로그 |
| Phase 2 | + **자체 카드 결제내역**(결제처 포함) — 퍼핀과 동일 방식 |
| Phase 3 | + 마이데이터 (만 14세 이상만) |

## ④ 성장 리포트

진도·정답률에 **목표 달성률·저축률**까지 얹은 주간 리포트.
→ **구독의 과금 근거가 여기 붙습니다.**

## ⚠️ 「미션 루프」를 제외한 이유

| 이유 | 내용 |
|---|---|
| **중복** | 퍼핀 약관 별첨에 **「미션하기」가 이미 존재** — "목표를 설정하고 완료 시 보상" |
| **규제** | 회사가 현금을 보관하면 **선불전자지급수단**(자본금 20억 + 충전금 100% 별도관리)에 걸림 |

# 8. 차별점

> **차별점은 하나입니다 — 금융 학습 진도와 성장률의 시각화.**

## 8-1. 퍼핀 대비

| 비교 축 | 퍼핀 (AS-IS) | **핀프렌즈** |
|---|---|---|
| **학습 진도** | 시작 116일 · 해결 75개 — **누적 개수만** | **주제별 진도 12/40** — 어디까지 배웠는지 |
| **성장률** | ❌ 없음 | **주차별 정답률 추이 · 재도전 성공률** — 얼마나 늘었는지 |
| **보상의 형태** | 현금(퍼핀머니) — 쓰면 사라짐 | 현금 **+** 별⭐(학습량 눈금) — **기록으로 남음** |
| **아이가 보는 것** | 누적 보상 6,650원 | **자라는 동물 아바타** — 성장이 즉각 눈에 보임 |
| **부모가 보는 것** | 숫자 3개 | **주간 성장 리포트** — 학습 + 금융 행동 |

## 8-2. 왜 이 자리가 비어 있는가 — 경쟁 5사

| 구분 | 서비스 | 상태 |
|---|---|---|
| **국내 3사** | 퍼핀 · 아이쿠카 · 아이부자 | **「학습 → 성취/성장」 구간 전원 공백**<br>금융에 비금융을 섞고 교육표준 매핑 없음 |
| **해외 2사** | gohenry · Greenlight | 교육 주제가 **전부 금융** + 외부 교육표준 매핑<br>GoHenry는 저축 이체액 **30%+ 증가** 발표(자사 발표치) |

- ✅ **선점 가능한 자리입니다** — 국내에서 아무도 채우지 않았습니다.
- ✅ **게임화 효과는 초등학생에서 가장 큽니다** (g=1.293) — 타깃 연령이 유리하게 작동합니다.
- ⚠️ 단, **효과가 학술 검증된 서비스는 아직 하나도 없습니다.** 확인한 건 **설계의 차이**입니다.

# 10. 검증과 로드맵

## 10-1. North Star Metric

> ## 주간 성장 지속률
> 지난주에 **성장(별 누적 + 아바타 변화)** 을 경험한 아이 중, **이번 주에도 학습을 이어간 비율**
> — 아이 성취감의 결과이자, 부모 확신감(습관화)의 선행지표

## 10-2. 검증 실험 — 깨질 수 있는 가정부터

| # | 가설 | 성공 기준 | 방법 |
|---|---|---|---|
| **E1** | 가시적 성장이 동기로 작동한다 | 자발적 재방문율 **≥ 40%** | A/B 프로토타입, 각 8~10명 |
| **E2** | 성장 루프가 실제 학습을 유발한다 | 해설 열람률 **≥ 60%**<br>오답 재도전율 **≥ 40%** | 사용성 테스트 + 행동 로그 |
| **E3** | **부모가 금융 순도를 원한다** + 리포트가 확신을 준다 | 동의율 **≥ 70%** | 부모 인터뷰 8~10명 |
| **E4** | 온보딩에서 첫 성장까지 무개입 도달한다 | 5분 내 완주 **≥ 70%** | 온보딩 플로우 관찰 |

> **E1이 무너지면 서비스 전제 전체가 무너지므로 최우선입니다.**
> 성공 기준 수치는 설계 단계의 가정치이며 1차 실측으로 캘리브레이션합니다.

## 10-3. 로드맵

| Phase | 기능 | 수익 |
|---|---|---|
| **Phase 1 · MVP** | 금융 학습 + 별⭐ + 동물 아바타 + 용돈계획<br>소비 기록은 **수동 입력** | 구독 |
| **Phase 2 · 자체 카드** | 결제내역 자동 수집(결제처 포함) + 위치 기반 알림 | 구독 + **결제 수수료** |
| **Phase 3 · 제휴 · 확장** | 저축·적금 상품 제휴 · 마이데이터는 **만 14세 이상**부터<br>또는 **규제 샌드박스** 신청 검토 | 구독 + 수수료 + **제휴** |
