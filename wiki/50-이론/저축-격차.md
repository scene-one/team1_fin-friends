# 저축 격차 — 부모 1위 ↔ 아이 최하위

> **부모가 가장 가르치고 싶어 하는 것이 저축인데, 아이가 용돈을 실제로 쓰는 곳에서 저축은 꼴찌다.**

| 부모가 하려는 교육 | 비율 | | 아이가 용돈을 실제 쓰는 곳 | 비율 |
|---|:-:|:-:|---|:-:|
| **저축 습관 만들기** | **65.8%** (1위) | ↔ | **저축** | **12.8%** (최하위) |
| 용돈 스스로 관리 | 50.1% | | 간식·군것질 | 77.0% (1위) |
| 이자 등 금융지식 | 20.3% | | 문구·학용품 | 47.5% |

**출처** — 윤선생 설문조사 (2025.10.15~20 · 초등 학부모 586명 · 금융의 날 기념). 등급 **`[A]`**.
[[PRD_핀프렌즈_v0_2]] §9-1이 VPS §1-0④를 통해 인용.

> 65.8%는 **부모가 하는 교육** 문항, 12.8%는 **아이의 용돈 사용처** 문항으로
> **서로 다른 복수응답 문항**이다. 차감이 성립하지 않는다.

## 왜 이것이 문제 정의의 출발점인가

[[학습-행동-전이-격차]]가 **국제 학술 데이터**로 말하는 것을, 이 조사는 **국내 실측치**로 말한다:

| | 무엇이 갈리는가 |
|---|---|
| 학습-행동 전이 격차 | 지식 +0.33 SD **vs** 행동 +0.07 SD |
| **저축 격차** | 부모의 **의도** 1위 **vs** 아이의 **행동** 최하위 |

둘 다 **「원하는 것」과 「일어나는 것」 사이의 단절**이고, [[핀프렌즈]]는 그 사이에 [[성장-나무]]의 실천 조건을 끼워 넣겠다는 제품이다.

## 함께 확인된 것 — 결제 인프라는 이미 깔려 있다

같은 조사에서:

| 용돈 지급 수단 | 비율 |
|---|:-:|
| **체크카드(충전식)** | **64.2%** |
| 현금 | 48.9% |
| 부모 명의 신용카드 | 2.6% |

→ 선불·충전식 카드가 이미 **초등 가정의 3분의 2에 침투**했다.
**새 결제수단을 설득할 필요가 없고**, 기존 카드 위에 교육·성장 레이어를 얹는 문제다.

v0.2는 이 `[A]` 주장에도 검증을 붙였다 — **카드 연결률과 대조**해 **≥ 50%면 인프라 전제 지지**.
