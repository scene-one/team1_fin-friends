# ⏰ 계획 카드 작성 트리거

[[소비-계획-카드]]를 **언제 적게 할 것인가**의 설계. 알림 하나가 아니라 **도달 경로 두 겹**이다.

> 🔴 **개입이 아니라 상기다.** 소비 순간에 아이를 멈춰 세우지 않는다.
> **그날 계획이 없을 때만** 한 번 알리고, 안 닿으면 화면에서 같은 말을 건넨다.

## 두 겹 구조

```
① 조건부 알림  ─ 평일 하교 시간대 / 주말 09:00
                  「오늘 계획 0건」일 때만 발송
      ↓ 안 닿거나 안 누르면
② 실천하기 화면 애니메이션 ─ 「잘 쓰기」 칸이 움직인다
```

**왜 두 겹인가** — 알림 하나에 기대면 [[PWA]] 푸시 제약(iOS는 홈 화면 추가가 전제)에서 무너진다.
그리고 [[배성우-H2]] 가정처럼 **아이 전용 기기가 없으면** 푸시 도달률이 더 낮다.

> 🔴 **급소** — ②는 **아이가 앱을 열어야** 작동한다. 알림이 안 닿고 그날 앱도 안 열면 계획은 없다.
> **알림 도달률(목표 ≥ 70% `[가설]`)이 이 설계 전체를 떠받친다.**

## ① 조건부 알림

| 항목 | 값 |
|---|---|
| **평일** | 부모가 설정한 **하교 시간대** — 기본 15:00~17:00 중 1회 |
| **주말·공휴일** | **09:00** |
| **발송 조건** | 🔴 **그날 계획 카드 0건** · 오늘 아직 이 알림을 보내지 않음 |
| **위치** | ❌ 쓰지 않는다 — **시각 기반 전용** ([[규제-상수]] P-19 무관) |
| **피로 관리** | 3일 연속 미작성 → 빈도를 **주 3회로** 낮춘다 |

### 왜 「조건부」가 핵심인가

기각된 알림안들의 공통점은 **상태와 무관하게 반복된다**는 것이었다.
정기 시각 알림은 소비 없는 날에도 울려 *"무시"* 를 학습시키고, 홈 상시 배너는 배너 실명을 만든다.

> **안 적은 날에만 울려야 신호가 유지된다.** 이미 적었으면 침묵하는 것이 이 설계의 전부다.

주말을 09:00으로 잡은 이유 — 평일은 **하교라는 소비 직전 시점**이 있지만 주말은 없다.
대신 **하루가 시작될 때** 한 번 묻는다.

## ② 실천하기 화면 애니메이션

[[학습-커리큘럼-퀴즈|실천하기 화면]]의 2×2 그리드에서 **오늘 실행하지 않은 칸이 움직인다.**
「잘 쓰기」 칸이 그중 하나다 — 자세한 것은 그 페이지의 「미실행 강조」 절.

**클리커 게임처럼 누르고 싶게** 만드는 장치이고, 알림이 안 닿았을 때 **마지막으로 남는 신호**다.

## 작성 UI

**3탭 이내 완료**를 목표로 한다. 받는 것은 **날짜 · 어디서 · 얼마까지** 셋뿐이고,
품목·업종을 받지 않으므로 카테고리를 고르는 단계가 없다.

## ⬜ 아직 정하지 않은 것

| 항목 | 상태 |
|---|---|
| 하교 시간대 **기본값** | ⬜ 15:00~17:00 잠정 — 학년별 하교 시각 편차 미확인 |
| 3일 미작성 **완화 방식** | ⬜ 빈도를 낮출지 문구를 바꿀지 |
| 알림 **도달률** | 🔴 목표 ≥ 70% `[가설]` · [[PWA]] 푸시 제약이 변수 |
| 작성률 | ⬜ MVP 4주 실측 (E3 · PASS ≥ 50%) |
