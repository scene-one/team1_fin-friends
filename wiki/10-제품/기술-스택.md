# 🧱 기술 스택

**정본은 `SRS v1.0` §2.5** 다. 이 페이지는 그 결정의 **판단 배경** — 무엇이 각 스택을 강제했고,
**AI를 어디까지 쓰기로 했는지**를 담는다.

> 🔑 **스택은 취향이 아니라 제약의 결과다.** 이 제품에서 스택을 고르는 힘은 셋뿐이다 —
> **아동 개인정보 규제**([[규제-상수]]) · **[[아바타-옷장]]의 3D** · **[[별-지급-엔진]] 원장의 정합성 0%**.

## 🤖 AI — 아동 데이터를 만지는가로 가른다

### 🧭 결정 배경 (Context)

**Summary** *"AI를 쓰는가"* 가 아니라 **"그 호출이 아동 데이터를 만지는가"** 로 세 평면을 나눈다
(`PRD ADR-017` · `SRS §2.5.1`).

| 평면 | 아동 데이터 | 스택 | 무엇에 |
|---|:-:|---|---|
| **D. 개발** | ❌ | LLM 코딩 도구 | 구현·리팩터링. **제품 런타임 아님** |
| **A. 콘텐츠 저작** *(오프라인)* | ❌ | Claude/OpenAI API · **ChromaDB** · Python | [[학습-커리큘럼-퀴즈]] 지문·문항 생성, 중복·난이도 드리프트 검사 |
| **R. 제품 런타임** | ✅ | **AWS Bedrock**(서울) | [[월간-숲]] **요약 문장 하나**(`FR-042`) — 부모 화면 전용 |

**Evidence**
- 국외 엔드포인트로 아동 데이터를 보내면 **국외이전 없음** 요구가 곧바로 깨진다 `[설계 확정]`
- [[아바타-옷장]]은 [[규제-상수]] **P-13이 생성형 AI 미사용을 명시**한다 `[설계 확정]`
- [[소비-계획-카드]]의 「어디서」는 **자유 입력**이라 프롬프트에 실리면 **아이의 생활 반경**이 드러난다 — P-19(위치 미수집)를 우회하는 경로가 된다 `[추론]`
- [[미션]] 사진은 **아동 이미지**라 저장도 금지돼 있다(P-13) `[설계 확정]`

**Implication** D·A는 규제 대상이 아니므로 **교안 스택을 그대로 쓴다.** R만 **국내 리전 · 비식별 ·
서버 경유** 셋을 지키면 된다. 이미 AWS를 쓰므로 **같은 리전에서 추론을 끝내는 경로**가 가장 짧다.

**왜 Bedrock인가** — 벤더 API를 직접 부르면 요청이 국외로 나간다. Bedrock 서울 리전이면
**「국외이전인가」라는 논쟁 자체가 성립하지 않는다.**
**왜 Pinecone이 아니라 ChromaDB인가** — ChromaDB는 자체 호스팅이 되고 Pinecone은 국외 SaaS다.

### 🔴 가드레일 6개 — 하나라도 못 지키면 기능을 끈다

| # | 규칙 |
|:-:|---|
| G-1 | 브라우저에서 **LLM API를 직접 호출하지 않는다** — 반드시 서버 경유 |
| G-2 | 요청 페이로드에 **아동 식별 데이터를 넣지 않는다** — 집계 수치와 라벨만 |
| G-3 | **아동에게 생성 텍스트를 실시간으로 노출하지 않는다** — 저작물은 **사람 검수 후 정적 배포** |
| G-4 | **[[미션]] 사진을 LLM에 보내지 않는다** |
| G-5 | **[[아바타-옷장]]을 생성형 AI로 만들지 않는다** |
| G-6 | 추론은 **서울 리전**에서 끝나고, 요청 데이터를 **모델 학습에 제공하지 않는다** |

> 🔴 **G-3이 급소다.** 1·2단계 학습 콘텐츠는 **금감원 대조 기준선이 없어서**([[금융감독원]] · [[학습-난이도-5단계]])
> 생성물 품질을 기계적으로 판정할 수단이 없다. 그래서 저작은 **오프라인 + 사람 검수 게이트**로만 돌린다.

🔴 **받아들인 대가** — 개인화 학습·대화형 튜터·자동 오답 해설이 **MVP에서 불가능**하다.
오답 시 제공은 [[학습-커리큘럼-퀴즈]]의 **「이야기 다시 읽기」** 로 고정된다.

**되돌리는 조건** — 가드레일 1건이라도 위반하면 `FR-042`를 끄고 **템플릿 문장**으로 되돌린다.
**AI는 보완이지 전제가 아니다** — 요약 문장이 없어도 [[월간-숲]]의 변화 지표는 그대로 성립한다.
