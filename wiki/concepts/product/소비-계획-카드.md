# 📝 소비 계획 카드 (F8)

**v0.2에서 유일하게 기능 목록 자체를 바꾼 결정**의 산물. [[PRD_핀프렌즈_v0_2]] §4-2 · 2026-08-21 확정.
우선순위 **Must** · 중요도 5 · 난이도 **5** · Job **J1 + J2**.

## 무엇인가 — 🔄 **봉투형** *(2026-09-01 재정의)*

> **미리 나눠 담고, 쓴 뒤에 어느 봉투에서 빠졌는지 본다.**

| 단계 | 내용 |
|:-:|---|
| **① 봉투 배분** | 충전액을 **용도별 봉투**에 나눠 담는다 — 🍪 간식 · ✏️ 문구 · 🎯 모으기 … |
| **② 결제** | 카드 승인 |
| **③ 자동 대조** | 승인 내역의 **가맹점 업종 → 해당 봉투에서 차감**. 아이가 따로 할 일 없음 |
| **④ 회고** | **두 갈래** — 봉투 안 ⭐1 / 봉투 초과는 회고만 |

**업종을 받는 것이 핵심**이다. 「얼마」만이 아니라 **「어디에」가 데이터로 남는다** → [[대안-대비-벤치마크]] · F13 소비 내역 업종별 집계.
봉투형에서는 **봉투가 곧 업종**이므로 이 대조가 별도 입력 없이 성립한다.

### 🔄 왜 「건별 계획 카드」에서 봉투로 옮겼나

v0.2가 F14·F19를 삭제하면서 **자동 발동이 사라졌다**(아래 참조). 남은 것은 *"아이가 결제 전에 스스로 앱을 열어 적는다"* 는 전제였는데,
**초등 저학년에게 이 전제가 성립하지 않는다.** 알림을 어디에 붙여도 전제 자체는 바뀌지 않는다.

그래서 **상기시키는 방법이 아니라 적는 단위**를 바꿨다 — 결제 건마다가 아니라 **돈이 들어올 때 한 번**.

| | 건별 계획 카드 | **봉투형** |
|---|---|---|
| 적는 시점 | 결제 직전마다 | **충전 시 1회** — 그 기간 전체를 덮는다 |
| 아이 부담 | 매 결제 전 앱 진입 | 배분 1회 + 이후 자동 |
| 작성률 지표 | `plan_card_created ÷ payment_settled` — 🔴 달성 난망 | **배분 완료 여부** — 분모 문제 소멸 |
| 업종 대조 | 계획에 업종을 직접 입력해야 성립 | **봉투 = 업종**이라 입력 없이 성립 |
| C5(충동구매) 신호 | 계획을 안 적으면 신호 자체가 없음 | *"간식 봉투가 비었는데 또 썼다"* 로 **드러난다** |

> 🔑 **근거는 [[배성우-H2]]다.** 현금 봉투를 **3년째** 쓰고 있는 가정이다.
> 새 습관을 요구하는 게 아니라 **이미 하고 있는 행동을 디지털로 옮기는 것**이라 채택률 가정이 훨씬 가볍다.

**제휴사 의존이 없다** — 실제 선불 잔액은 하나로 두고 **앱이 배분만 표시·차감**한다.
카드 한도 제어([[규제-상수]] P-17·P-18, 제휴사 정책 종속)에 기대지 않으므로 제휴 계약 전에도 확정할 수 있다.

### ✏️ 봉투 금액은 나중에 수정할 수 있다

아이가 **언제든 재배분**할 수 있다. *"간식을 줄이고 문구를 늘린다"* 는 판단 자체가 「잘 쓰기」 학습이므로 막지 않는다.

> 🔴 **다만 ⭐ 판정은 결제 시점의 배분 스냅샷으로 고정한다.**
> 그렇지 않으면 **초과 지출 후 봉투를 늘려 「지킴」으로 만드는 우회로**가 열린다.
> 수정은 **다음 결제부터** 적용되고, 재배분 이력은 부모 화면(F13 소비 내역)에 남는다.

| 항목 | 규칙 |
|---|---|
| 수정 주체 | **아이** *(부모는 [[2026-08-31_팀_기능정의-v13|v13]] 갱신 13과 같이 열람만)* |
| 수정 시점 | 제한 없음 |
| 판정 적용 | **결제 시각의 스냅샷** — 소급 없음 |
| 부모 가시성 | 재배분 이력이 소비 내역에 남는다 |

## 🔄 무엇을 대체했나 — F14·F19 삭제

| | 삭제 | 대체 |
|---|---|---|
| **F14** 📍 위치 알림 (3분 체류 · 온디바이스) | ❌ | **F8 계획 카드** |
| **F19** 🚦 소비 사전 개입 2차 트리거 | ❌ | **F8 계획 카드** |

v0.1에서 F19 배치는 **최상위 미결**(옵션 A 유지 / B 경량 분할 / C Must 승격)이었다.
**셋 다 채택하지 않고 넷째 안으로 확정** — *자동 트리거를 만들지 않고, 사전 개입을 「쓰기 전에 적는 행위」로 옮긴다.*

### 왜 삭제했나 — 선결 조건 4개 중 3개가 미해결이었다

| # | 선결 조건 | 상태 |
|:-:|---|:-:|
| ① | 아이 기기 전제 (키즈워치·부모 폰 공유에서 알림 수신) | 🔴 미해결 — **선별 인물 둘 다 전용 스마트폰이 없다** ([[배성우-H2]]의 아이는 키즈워치) |
| ② | 3분 임계값의 근거 (체류시간 실측) | 🔴 미해결 |
| ③ | [[규제-상수]] P-19 준수 방식 (좌표 미저장 → 온디바이스 판정) | 🔴 미해결 |
| ④ | 온라인 결제 개입 수단 | 🔴 미해결 |

> **그리고 ②는 해결해도 소용이 없었다** — **3분 트리거가 못 잡는 소비가 곧 C5** 였으므로, F14를 승격해도 선별 Pain이 남는다.

### 계획 카드는 넷을 전부 우회한다

| | F14 / F19 | **F8 계획 카드** |
|---|---|---|
| 기기 조건 | 🔴 스마트폰 + 백그라운드 위치 권한 + 알림 | ✅ **무관** — 부모 폰에서도 적을 수 있다 |
| 위치정보 | 🔴 수집·온디바이스 판정 (P-19) | ✅ **아예 안 씀 → P-19 적용 없음** |
| 검증 선행 | 🔴 체류시간 실측 필요 | ✅ **불필요** |
| 남는 데이터 | 알림을 봤다 / 안 봤다 | ✅ **업종 × 금액 대조** — 검증 가능한 행동 데이터 |

이 결정으로 **리스크 R2(아이 기기 전제)가 해소**됐다.

## 🔴 대가 — 정직하게 남긴 것

| 잃은 것 | 내용 |
|---|---|
| **자동 발동이 사라졌다** | 위치 알림은 아이가 아무것도 안 해도 울렸지만, 계획 카드는 **먼저 적어야** 작동한다. 사각지대가 없어진 게 아니라 **「3분 미만 소비」에서 「계획을 적지 않은 소비」로 옮겨갔다** |
| **C10·C12가 완전 미대응이 됐다** | 온라인 결제·FOMO 3초 판단은 F19 하나에 걸려 있었고 이제 **대응 기능이 0개**다. 온라인 결제는 계획 카드를 적을 **계기조차 없다** |
| **대외 문구를 바꿔야 한다** | *"매장에 3분 이상 머무르면 알림"* 은 **더 이상 사실이 아니다.** 발표·자료에서 지오펜싱 서술을 전부 내릴 것 → [[인용-금지-목록]] |

## 🔑 생존 조건 — 🔄 **봉투 배분율** *(2026-09-01 지표 교체)*

원래 생존 조건은 **결제 건 대비 계획 카드 작성률 ≥ 50%** 였다. 봉투형으로 옮기면서 **분모가 바뀐다.**

> **충전 건 대비 봉투 배분 완료율 ≥ 80%.**
> 미달이면 사전 절반이 비고, **대조할 것이 없어 사후 절반까지 무너진다** — 실패 방식은 같다.

| 코드 | 지표 | 비고 |
|---|---|---|
| **O7** *(개정)* | `envelope_allocated` ÷ `wallet_topped_up` | 🔄 분모가 **결제 건수 → 충전 건수** |
| **E3** *(개정)* | PASS ≥ 80% / HOLD 60~79% / **FAIL < 60% → 배분 UX 재설계 · C5 발생률 재산출** | 기준선이 오른 이유는 아래 |
| **US-4 AC4** | MVP 운영 4주 실측 | 그대로 |

> ⚠️ **왜 50%가 아니라 80%인가** — 행위 빈도가 낮아졌기 때문이다.
> 결제마다 적는 구조에서 50%는 *"두 번 중 한 번"* 이지만, 충전 때 한 번 나누는 구조에서 50%는
> *"충전의 절반이 용도 없이 들어간다"* 는 뜻이라 훨씬 나쁘다. **행위가 드물어질수록 기준선은 올라야 한다.**

🔴 **이 두 숫자는 전부 `[가설]`이다.** 봉투 배분율의 기준선은 `⬜ 미측정`이며,
MVP 4주 실측 전까지 어떤 값도 성과로 인용할 수 없다 → [[인용-금지-목록]].

판정 규칙은 [[PASS-HOLD-FAIL-3구간-판정]].

## 두 갈래 회고 — C6 대응

> **보상의 존재 여부가 아니라 보상이 무엇에 연결되어 있는가가 문제다** ([[외적보상과-내재동기]]).
> 여기서 ⭐는 「소비했다」가 아니라 **「나눠 담은 대로 썼다」** 에 연결된다.

⭐를 **계획 준수 시에만** 지급하도록 확정(v13 §5)해서 *"참은 날 = 안 참은 날"* 문제는 해소됐다.

| 갈래 | 조건 | ⭐ | 기록 |
|:-:|---|:-:|---|
| **A 지킴** | 결제액이 **해당 봉투 잔액 이내** *(결제 시점 스냅샷 기준)* | **⭐1 지급** | `plan_met=true` · `star_granted=true` |
| **B 넘김** | 결제액이 **봉투 잔액을 초과** | **미지급** *(보유 별 차감 없음 — P-03)* | `plan_met=false` · `star_granted=false` |

🔴 **갈래 B의 이탈 감시**가 남은 위험이다 — 보상 없는 쪽 회고가 방치되면 **「행동」 데이터가 실패한 날만 비게 된다.**
AC2-3: 계획 초과 건의 회고 열람률이 **계획 준수 건 대비 ≥ 70%**.

## 미결 1건 — 🔄 봉투 간 이동을 허용할 것인가

봉투형으로 옮기면서 **US-4 AC-E2가 다른 질문으로 바뀌었다.**

원래 질문은 *"계획한 업종과 다른 업종에서 썼는데 금액은 이내라면?"* 이었다.
봉투형에서는 **봉투가 곧 업종**이라 이 경우가 자동으로 잡힌다 — 간식 봉투가 비면 간식 결제가 초과다.

> **남은 질문은 하나다 — 🍪 간식 봉투가 비었을 때 ✏️ 문구 봉투에서 빼 쓸 수 있게 할 것인가?**

| 안 | 결과 |
|---|---|
| 봉투 간 이동 **금지** | 봉투 경계가 진짜 제약이 된다. 다만 잔액이 남았는데 결제가 막히면 아이·부모 모두 불만 |
| **자동 이동 허용** | 결제가 안 막힌다. 대신 봉투가 사실상 하나가 돼 **구조가 무의미**해진다 |
| **아이가 명시적으로 옮겨야** 이동 | 「옮긴다」는 의식적 행위가 남아 학습이 된다. 단계가 하나 늘어난다 |

**미결로 남긴다** → 원장 S6. 위 「봉투 금액 수정 가능」 결정과 경계가 붙어 있어 함께 판단해야 한다.

## 선결 과제 순서

```
① 결제 매칭 검증 (업종 매칭 정확도 ≥ 90% · US-4 AC2)
   → ② 봉투 배분율 실측 (MVP 4주 · E3 개정)
      → ③ 봉투 간 이동 규칙 결정 (원장 S6)
```

**①②를 먼저 두는 이유** — 둘 다 문항이 아니라 **계측**이고, 결과가 F8의 성립 여부를 직접 바꾼다.
①이 실패하면 대조 화면이 신뢰를 잃고, ②가 실패하면 대조할 것이 없다.

🔴 **봉투형에서 ①의 무게가 더 커졌다.** 건별 계획 카드는 아이가 업종을 직접 골랐지만,
봉투형은 **가맹점 업종 코드가 봉투를 자동 결정**한다. 매칭이 틀리면 아이가 안 쓴 봉투에서 돈이 빠지고,
그것은 **아이가 모은 것을 잃는 경험**이라 [[별-지급-엔진]]의 정합성 원칙과 같은 무게로 다뤄야 한다.
가맹점 분류 상세도는 **제휴 계약 확인 사항**이다([[규제-상수]]).
