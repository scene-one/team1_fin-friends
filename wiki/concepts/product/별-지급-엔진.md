# ⭐ 별 지급 엔진 (F4)

[[3층-구조]] 최하층(별)의 지급 로직. 우선순위 **Must** · 중요도 5 · 난이도 3 · Job **J1**.
**차감형 · 초기화 없음.**

**대안 대비 근거** — 실천 5경로 vs 학습 2경로. **경로 수로 실천을 유도**한다.

## 트리거 8종 — 자동 7 / 수동 1

> **병목이 8분의 1로 좁혀진 상태다.** 부모 승인이 필요한 것은 **미션 1종뿐**이고 나머지 7종은 자동 판정. `[설계 확정]`

| 구분 | 트리거 | [[WPA-북극성-지표]] 분자 포함? |
|:-:|---|:-:|
| **학습 경로** | 1 온보딩 학습 | ❌ **제외** |
| | 2 출석체크 — **아이 앱 실행만으로 ⭐1** `[설계 확정]` | ❌ **제외** |
| | 3 퀴즈 정답 — **하루 총 4개 한도** · 오답 시 별 없음 | ❌ **제외** → [[학습-커리큘럼-퀴즈]] |
| **실천 경로** | 4 미션 승인 *(유일한 수동)* — **⭐1 + 부모가 정한 용돈 충전** | ✅ WPA-v1 |
| | 5 소비 회고 | ✅ WPA-v1 |
| | 6 위시리스트 달성 | ✅ WPA-v1 |
| | 7·8 예적금 ([[불리기-예적금-실천]]) — 🔒 **MVP 잠금** | ⏳ WPA-v2 *(잠금 해제 후)* |

### 🔴 학습 경로를 분자에서 뺀 이유

> 출석 ⭐1이 분자에 들어가면 *"접속만으로 실천 지표가 오르는"* **활동량 지표로 퇴화**한다.

이 분리가 [[외적보상과-내재동기]]의 실무 적용이다. 검증 방법까지 붙어 있다 —
**출석률과 WPA의 상관 r ≤ 0.3** (§9-1, [G] 항의 검증 설계).

## 💰 미션 보상은 둘이다 — 용돈과 ⭐

미션 승인 시 아이가 받는 것은 **두 가지**이고, 둘은 [[3층-구조]]의 서로 다른 층에 있다.

| 받는 것 | 무엇 | 어디로 |
|---|---|---|
| 💵 **용돈** | 부모가 미션 등록 시 정한 **보상 금액**(실제 돈) | 아이 지갑 충전 → 쓸 때 [[소비-계획-카드]]로 계획 |
| ⭐ **별 1개** | 즉각 보상 재화 | 옷장 |

**둘은 교환되지 않는다** — [[규제-상수]] P-01·P-21. 별로 돈을 살 수 없고 돈으로 별을 살 수 없으며,
그 경로를 **코드에 두지 않는다**.

### 등록 주체 — 부모 또는 아이

아이도 미션을 제안할 수 있다. 다만 **부모가 승인해야 활성**된다 — 보상 금액이 실제 돈이기 때문이다.

### 🔴 화면에서 둘을 나란히 두지 않는다

미션 완료 화면은 **⭐를 먼저** 보여주고, 충전된 금액은 **지갑·봉투 화면에서** 확인하게 한다.

> 나란히 두면 아이가 *"별 = 돈"* 으로 학습하고, 그것이 바로 **P-01·P-21이 막으려는 인지**다.
> 규제는 데이터 구조뿐 아니라 **화면 배치에도 걸린다.**

### 경계 사례

| 상황 | 처리 |
|---|---|
| 보상 **0원** 미션 | 허용 — ⭐와 실천만 기록 |
| 부모 지갑 **잔액 부족** | **⭐와 실천은 정상 지급**, 충전만 보류하고 부모에게 요청 표시 |
| 승인 후 **취소** | ⭐도 충전도 **회수하지 않는다** — 아이가 이미 받은 것을 잃게 하지 않는다 |
| β 기간 | 🧪 **모의 충전**([[핀프렌즈]] 결제 트랙) |

## 🧭 결정 배경 (Context) — 출석 ⭐를 접속만으로 준 이유

**Summary** [[정미경-H1]]과 [[배성우-H2]]가 정반대 신호를 보내던 지점에서 **H2 쪽을 택했다.**

**Evidence**
- H1 — *"출석만 해도 주면 공부를 안 할 수도"* (우려) `[관측]`
- H2 — 학습 진도가 느려 **출석 ⭐1이 유일한 초기 별** `[관측]`
- [[학습-행동-전이-격차]] — 지식 **+0.33 SD** vs 행동 **+0.07 SD** `[A]`

**Implication** 「학습 1개 이상」 조건은 진도가 느린 아이의 **첫 성공 경험 자체를 지연**시키고, 그 아이들이 바로 전이 격차가 가장 크게 벌어지는 집단이다. 1차 타깃이 H2형([[핀프렌즈]])이므로 진입 문턱을 우선했다.

🔴 **H1의 우려는 해소되지 않았다.** 접속 ⭐가 아이 홈(옷장)과 겹쳐 *"켜기만 하면 되는 앱"* 으로 굳을 수 있다. 이 결정은 **두 방어선에 의존한다** — ① [[WPA-북극성-지표]] 분자에서 출석 ⭐ 제외 ② [[성장-나무]] 승급에 실천 횟수 필수. **①이 풀리면 이 결정도 함께 철회 대상**이다.

**기각한 대안** — 학습 1개 이상(*H2 진입 지연*) · 주당 상한 3회(*규칙이 늘어 아이에게 설명이 어렵다*) · 출석 트리거 삭제(*저진도 아이의 첫 성공 경로가 하나 줄어든다*).

## 규제 제약 — [[규제-상수]]

- **P-01 · P-21** — 별은 **차감형 · 교차 금지**, 별↔저금통 **완전 분리**
- ❌ 현금 충전 ❌ 현금 환급 ❌ 양도·거래
- 🔴 **전환 경로 자체를 코드에 두지 않는다** — 기능 플래그로 막는 방식 **금지**
- **P-03** — 별은 모으기만. 계획을 넘겨도 **보유 별을 차감하지 않는다**([[소비-계획-카드]] 갈래 B)

## 정합성 — 협상 불가

| 항목 | 값 | 왜 |
|---|:-:|---|
| **별 지급·차감 정합성 오류율** | **0%** | **아이가 모은 것을 잃는 경험**이라 허용 오차가 없다 |
| ⭐ 소급 지급 성공률 | **100%** | US-6 AC1 · AC-E2 |
| 별 지급 반영 p95 | ≤ 800 ms *(잠정)* | *"동일 세션 내 반영"* — 아이 세션 이탈이 잦아 1초 내 체감이 전제 |

**별 원장은 이중 기입 + 일일 정산 배치**로 검증하고, 불일치 **> 0건이면 즉시 알림**(개발 온콜 · 30분 내 확인 · 1시간 내 원인 특정 · 4시간 미해결 시 팀 전체 에스컬레이션).

### ⏱ 승인 병목 — **3일 자동 만료 · 만료는 「미실천」이 아니다** *(2026-09-01 확정 · MINOR)*

미션 승인은 **유일한 수동 트리거**다. 부모가 누르지 않으면 아이의 실천이 기록되지 않는다.

| 시점 | 처리 |
|---|---|
| 완료 즉시 | 부모에게 승인 요청 |
| **24시간 미승인** | 부모에게 1회 리마인드 |
| **72시간 미승인** | **자동 만료** — ⭐ 미지급 |
| 만료 표시 | 🔴 **「승인되지 않음」이 아니라 「확인하지 못했어요」** — 아이 화면에서 **부모의 미확인**임을 분명히 한다 |

**왜 자동 만료를 두나** — 승인 대기가 무한히 쌓이면 아이 화면이 *"기다리는 중"* 으로 막힌다.
O13(≤ 3일)이 일반 공개 게이트에 있는 것도 같은 이유다.

> 🔴 **만료를 「미실천」으로 집계하지 않는다.** 아이는 했는데 부모가 안 본 것이다.
> [[WPA-북극성-지표]] 분자에서 빠지지만 **분모에서도 빼지 않는다** — 빼면 지표가 좋아 보이고,
> 그러면 **승인 병목이 지표에 안 잡힌다.** 별도로 `mission_expired` 비율을 감시한다.

| 미션 **사진 첨부** 확인 | 부모 승인 화면에 표시 후 **판정 즉시 파기** — 서버 무저장([[규제-상수]] P-13) · 남는 것은 **승인 이력**뿐 |

| 승인이 **주기 초기화 이후** | ⭐ 지급 · 나무 조건은 주기 N 귀속 · [[월간-숲]] 스냅샷에만 반영 |

거절·주기 초기화 2건은 [[측정가능성-리뷰]]가 찾아낸 **스펙 공백**이었다.

## ✅ 출석체크 조건 — **접속만으로 ⭐1** *(2026-09-01 확정)*

[[정미경-H1]]과 [[배성우-H2]]가 **정반대 신호**를 보내던 지점이다:

| 인물 | 신호 |
|---|---|
| H1 정미경 | *"출석만 해도 주면 공부를 안 할 수도"* — 우려 |
| H2 배성우 | 학습 진도가 느려 **출석 ⭐1이 유일한 초기 별** |

**H2 쪽을 택했다.** 「학습 1개 이상」 조건은 진도가 느린 아이의 **첫 성공 경험 자체를 지연**시키고,
그 아이들이 바로 [[학습-행동-전이-격차]]가 가장 크게 벌어지는 집단이다. 진입 문턱을 낮추는 쪽을 우선한다.

### 🔴 이 결정이 지는 부담 — H1의 우려는 해소되지 않았다

접속 ⭐가 **아이 홈(옷장)** 과 겹친다([[3층-구조]]). 앱을 켜기만 해도 옷을 살 재화가 쌓이므로
*"켜기만 하면 되는 앱"* 으로 굳을 수 있다. 이 결정은 **두 개의 방어선에 의존한다**:

| 방어선 | 어디 | 내용 |
|:-:|---|---|
| ① | [[WPA-북극성-지표]] | 출석 ⭐는 **분자에서 제외** — 접속이 실천 지표를 올리지 못한다 |
| ② | [[성장-나무]] | 승급 조건에 **실천 횟수**가 있어 출석만으로는 나무가 자라지 않는다 |

> ⚠️ **①이 무너지면 이 결정도 함께 무너진다.** 출석 ⭐를 분자에 넣자는 제안이 나오면
> 그것은 지표 조정이 아니라 **이 결정의 철회**로 다뤄야 한다.

**검증 장치** — 출석률과 WPA의 상관 **r ≤ 0.3**(§9-1 [G] 항). 초과하면 출석 ⭐가
실천을 대체하고 있다는 신호이므로 **조건 재설계**(주당 상한 도입 등)를 검토한다.
