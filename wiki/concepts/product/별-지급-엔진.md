# ⭐ 별 지급 엔진 (F4)

[[3층-구조]] 최하층(별)의 지급 로직. 우선순위 **Must** · 중요도 5 · 난이도 3 · Job **J1**.
**차감형 · 초기화 없음.**

**대안 대비 근거** — 실천 5경로 vs 학습 2경로. **경로 수로 실천을 유도**한다.

## 트리거 8종 — 자동 7 / 수동 1

> **병목이 8분의 1로 좁혀진 상태다.** 부모 승인이 필요한 것은 **미션 1종뿐**이고 나머지 7종은 자동 판정. `[설계 확정]`

| 구분 | 트리거 | [[WPA-북극성-지표]] 분자 포함? |
|:-:|---|:-:|
| **학습 경로** | 1 온보딩 학습 | ❌ **제외** |
| | 2 출석체크 | ❌ **제외** |
| | 3 퀴즈 정답 | ❌ **제외** |
| **실천 경로** | 4 미션 승인 *(유일한 수동)* | ✅ WPA-v1 |
| | 5 소비 회고 | ✅ WPA-v1 |
| | 6 위시리스트 달성 | ✅ WPA-v1 |
| | 7·8 예적금 (F15) | ⏳ WPA-v2 *(개통 후)* |

### 🔴 학습 경로를 분자에서 뺀 이유

> 출석 ⭐1이 분자에 들어가면 *"접속만으로 실천 지표가 오르는"* **활동량 지표로 퇴화**한다.

이 분리가 [[외적보상과-내재동기]]의 실무 적용이다. 검증 방법까지 붙어 있다 —
**출석률과 WPA의 상관 r ≤ 0.3** (§9-1, [G] 항의 검증 설계).

## 규제 제약 — [[규제-상수]]

- **P-01 · P-21** — 별은 **차감형 · 교차 금지**, 별↔저금통 **완전 분리**
- ❌ 현금 충전 ❌ 현금 환급 ❌ 양도·거래
- 🔴 **전환 경로 자체를 코드에 두지 않는다** — 기능 플래그로 막는 방식 **금지**
- **P-03** — 별은 모으기만. 계획을 넘겨도 **보유 별을 차감하지 않는다**([[소비-계획-카드]] 갈래 B)

## 정합성 — 협상 불가

| 항목 | 값 | 왜 |
|---|:-:|---|
| **별 지급·차감 정합성 오류율** | **0%** | **아이가 모은 것을 잃는 경험**이라 허용 오차가 없다 |
| ⭐ 소급 지급 성공률 | **100%** | US-6 AC1 · AC-E2 |
| 별 지급 반영 p95 | ≤ 800 ms *(잠정)* | *"동일 세션 내 반영"* — 아이 세션 이탈이 잦아 1초 내 체감이 전제 |

**별 원장은 이중 기입 + 일일 정산 배치**로 검증하고, 불일치 **> 0건이면 즉시 알림**(개발 온콜 · 30분 내 확인 · 1시간 내 원인 특정 · 4시간 미해결 시 팀 전체 에스컬레이션).

## 경계 사례 (AC-E)

| 상황 | 처리 |
|---|---|
| 아동 기기 **오프라인** 후 재연결 | ⭐ **중복 지급 0건**(`idempotency_key`) · 반영 ≤ 60초 · 주차 귀속은 **`client_ts` 기준** |
| 동일 미션 승인 요청이 **2회 이상** | **⭐는 1회만** · 별 원장 불일치 0건 |
| 부모가 **거절** | ⭐ 미지급 · **「승인되지 않음 + 사유」** 표시 · **「미실천」과 시각적 구별** · 실천 카운트 미가산 |
| 승인 대기 **5건 이상 누적** | **일괄 승인 경로** 제공 · 각 건은 **완료 시각 기준으로 개별 소급** |
| 승인이 **주기 초기화 이후** | ⭐ 지급 · 나무 조건은 주기 N 귀속 · [[월간-숲]] 스냅샷에만 반영 |

거절·주기 초기화 2건은 [[PRD_핀프렌즈_v0_1_품질리뷰]]가 찾아낸 **스펙 공백**이었다.

## 🔴 미결 — 출석체크 조건

[[정미경-H1]]과 [[배성우-H2]]가 **정반대 신호**를 보낸다:

| 인물 | 신호 |
|---|---|
| H1 정미경 | *"출석만 해도 주면 공부를 안 할 수도"* — 우려 |
| H2 배성우 | 학습 진도가 느려 **출석 ⭐1이 유일한 초기 별** |

「학습 1개 이상」으로 잡으면 **H2의 진입이 지체된다.** F4 스펙 확정 전 결정 필요.
