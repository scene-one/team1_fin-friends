# ⭐ WPA — Weekly Practiced Active (주간 실천 인정 아동 비율)

[[핀프렌즈]]의 **단 하나의 북극성 KPI**. [[PRD_핀프렌즈_v0_2]] §1-3.
[[PRD_핀프렌즈_v0_1]]에서는 **분모가 미정의**여서 계측 불가였고([[PRD_핀프렌즈_v0_1_품질리뷰]] D1 · CRITICAL), v0.2에서 조작적 정의를 확정했다.

## 조작적 정의

```
WPA(주차 w) = 분자 / 분모

분자 — 주차 w 동안 「실천 트리거」로 ⭐를 1회 이상 받은 아동 수
       (practice_credited 이벤트가 1건 이상 있는 distinct child_id)

분모 — 주차 w 「활성 아동」 수
       = 주차 w 시작 시점에 아래 3조건을 모두 만족하는 아동
         ① 보호자 법정대리인 동의 완료 (P-05)
         ② 아이 계정 생성 후 7일 경과   ← 온보딩 ⭐가 실천을 과대계상하는 것을 차단
         ③ 직전 28일 내 앱 세션 1회 이상 ← 완전 이탈 계정 제외

주차 기준 — ISO 주(월~일) · KST
```

## v1 / v2 분리

| 버전 | 「실천 트리거」 범위 | 언제 |
|:-:|---|---|
| 🔴 **WPA-v1** *(MVP)* | 트리거 **4** 미션 승인 · **5** 소비 회고 · **6** 위시리스트 달성 — **3종** | v0.2 MVP 전 기간 |
| **WPA-v2** | v1 + 트리거 **7·8** 예적금(F15) — **4종** | F15 개통 시점부터 |

> 🔴 **v0.1은 5종을 분자에 넣었으나 그중 2종이 MVP에 없었다.**
> 정의와 구현이 어긋나면 **WPA가 구조적으로 3종 상한에 묶인 것을 성능 문제로 오독**하게 된다.
> **v2 전환 시 시계열을 단절 표기**하고, 전환 후 4주간 v1·v2를 **병기**한다.

## 제외 규칙 — 분자에 넣지 않는 것

트리거 **1** 온보딩 학습 · **2** 출석체크 · **3** 퀴즈 정답. 셋 다 **학습 경로**다.

> 특히 출석 ⭐1이 분자에 들어가면 *"접속만으로 실천 지표가 오르는"* **활동량 지표로 퇴화**한다.

→ [[별-지급-엔진]] · [[외적보상과-내재동기]]

## 왜 이것 하나인가 — 근거 세 겹

1. **[[두-가치-선언]] 선언 ①이 ②의 전제다.** 아이가 실천하지 않으면 부모 화면은 거짓말을 하지 않고 **비어 있을 뿐**이고, 그 빈 화면이 *"우리 애가 안 하는구나"* 로 읽힌다. **②의 어떤 지표를 북극성으로 삼아도 ①이 죽으면 함께 죽는다.**
2. **C2가 AOS·DOS 두 지표에서 순서가 흔들리지 않는 유일한 항목이다** `[추론]` — 논쟁의 여지가 가장 적은 투자처. [[고객-문제-Pain-코드]]
3. **나무 성장 조건에 「행동 실천 횟수」가 들어 있다** `[설계 확정]` — 실천 없이는 [[성장-나무]]·[[월간-숲]]·별이 전부 작동하지 않는다. WPA는 **제품 전체가 파생되는 단일 원천 지표**다.

## ⚠️ 북극성으로 채택하지 않은 후보

| 후보 | 왜 아닌가 |
|---|---|
| 나무 5초 회상 성공률 (O1) | **인터뷰 회차 지표**라 상시 계측 불가. ①이 죽으면 회상할 내용 자체가 없다 |
| 다음 달 충전율 (O14) | **지연 지표** — 문제를 한 달 뒤에 알려준다 |
| 아이 7일 재접속률 | 접속은 실천이 아니다. 출석 ⭐1만으로 올라가 **활동량 지표로 퇴화** |

## 목표와 판정

| 항목 | 값 |
|---|---|
| 기준선 | ⬜ 미측정 — 프로토타입 2주차부터 산출 |
| 목표 `[가설]` | **≥ 5/8 가정** (β 클로즈드 · n=8) → 일반 공개 후 **≥ 55%** |
| 판정 | PASS ≥ 5/8 · HOLD 3~4/8 · FAIL ≤ 2/8 → [[PASS-HOLD-FAIL-3구간-판정]] |
| 측정 주기 | 주간 (ISO 주 마감 후 D+1 배치) |
| 측정 경로 | `practice_credited` + 활성 아동 스냅샷 |
| 알림 | 전주 대비 **−10%p** → 제품 담당 · 24시간 내 원인 분석 · **2주 연속이면 로드맵 재검토** |

## 롤아웃 게이트에서의 역할

| 단계 | WPA 게이트 |
|:-:|---|
| β 클로즈드 | **WPA ≥ 5/8** (+ E4 PASS · E1 PASS) |
| 일반 공개 | **WPA ≥ 55% 2주 연속** (+ O13 ≤ 3일 · 정합성 오류 0건) |
