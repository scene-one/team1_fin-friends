# 📚 학습 커리큘럼 4주제 + 퀴즈 (F3)

우선순위 **Must** · 중요도 5 · 난이도 3 · Job **J1(실천할 자리 만들기)**.
[[두-가치-선언]] 선언 ①의 **「학습」 마디**를 담당하는 기능이다.

## 한 문장

> **퀴즈는 별을 주지만 성장은 주지 않는다.**

이것이 [[퍼핀]]과 갈리는 지점이고, 이 기능의 설계 전체를 결정한다.

## 왜 이 기능이 존재하나

| 대응 Pain | |
|---|---|
| ★ 선별 **C2**(실천 공백 → 나무 정체) | 학습이 실천으로 이어지지 않으면 4칸이 전부 멈춘다 |
| △ 감시 **A1**(「불리기」 학습 장벽) | → [[불리기-예적금-실천]] |

**대안 대비 근거** — **4/4 전부 금융** vs [[퍼핀]] 3/7. 4칸 매핑이 구조적으로 가능한 쪽이다
([[대안-대비-벤치마크]] ④ 축).

## 흐름 — 학습에서 실천까지

```
① 짧은 학습 콘텐츠  →  ② 퀴즈  →  ③ ⭐1 지급  →  ④ 「실천하기」 화면
                                                     미션 · 소비 계획 카드
                                                     위시리스트 · 예적금
```

🆕 **2026-08-31 확정** — 학습을 마치면 **「실천하기」로 연결**되고, 실천 4종이 **한 화면에 통합**된다.
전에는 화면이 분리돼 있었다. [[학습-행동-전이-격차]]를 UI 층에서 좁히려는 조치다.

### 🆕 「실천하기」 화면 = 4칸 그리드 *(2026-09-01 확정)*

4종을 **2×2 고정 그리드**로 놓고, 미개통인 「불리기」는 **🔒 「곧 열려요」 잠금 카드**로 자리를 지킨다.

| | |
|---|---|
| 🧹 **벌기** — 미션 (F2) | 📝 **잘 쓰기** — [[소비-계획-카드]] 봉투 배분 (F8) |
| 🎯 **모으기** — 위시리스트 (F12) | 🔒 **불리기** — [[불리기-예적금-실천]] (F15 · 미개통) |

**왜 4칸을 다 보이나** — 부모 화면의 [[성장-나무]]가 **4분할(2×2)** 이다([[2026-08-31_팀_기능정의-v13|기능정의 v13]] 갱신 12).
아이 실천 화면과 부모 나무 화면이 **같은 공간 배치**를 쓰면, 부모가 *"이 칸이 왜 안 자랐지"* 를 물을 때
아이가 **같은 자리를 가리킬 수 있다.** 두 화면이 다른 배치면 [[두-가치-선언]] ①과 ②를 잇는 공통 언어가 없다.

> ⚠️ **받아들인 대가 2가지**
> ① **미완성 인상** — MVP 내내 4칸 중 하나가 잠겨 있다. 잠금 카드 문구가 *"우리가 안 만든 것"* 이 아니라
>    *"네가 아직 갈 곳"* 으로 읽히게 써야 한다(US-2 AC4).
> ② **전이 강도 손실** — 방금 배운 칸 하나만 크게 주는 편이 [[학습-행동-전이-격차]]를 더 좁힌다.
>    이를 보완하기 위해 **방금 학습한 칸을 그리드 안에서 강조 표시**한다.

## ❓ 퀴즈 — 확정된 규칙

| 항목 | 확정 |
|---|---|
| **일일 한도** | 4칸 **분야별 하루 1개 · 총 4개** |
| **오답 처리** | 🔴 **「이야기 다시 읽기」만 제공 · 별 추가 지급 없음** |
| 재도전 | 가능하되 **오늘치 별은 이미 소진** 상태 |
| ⭐ | 정답 시 **⭐1 자동**(트리거 3) → [[별-지급-엔진]] |
| 부모 화면 | **퀴즈 정답률** 실시간 표시 |
| 난이도 | **부모가 온보딩에서 5단계 설정** → [[학습-난이도-5단계]] |

### 🔴 오답 처리가 퍼핀과 정확히 반대다

| | [[퍼핀]] | **핀프렌즈** |
|---|---|---|
| 오답 시 | **보상 절반 지급 + 재시도** | **보상 없음 · 「이야기 다시 읽기」만** |
| 결과 | [[정미경-H1]]의 **학습 데이터 불신** — *"오답 재시도 보상 목격 → 이 숫자를 못 믿겠다"* | 정답률이 실제 이해도를 반영 |

일일 한도(총 4개)도 같은 방향이다 — **많이 푸는 것으로 지표를 올릴 수 없게** 막는다.

## 🔑 그런데 퀴즈로는 나무가 자라지 않는다

승급은 **학습 · 퀴즈 · 실천 3종을 모두** 채워야 한다. → [[성장-나무]] · [[3층-구조]]

> 🔴 **퀴즈만 100개 풀어도 승급 불가.** 실천 0건이면 도달 가능한 최대 단계는 **0단계**다.
> ⚠️ 단 **「불리기」는 예외** — F15 ⭐ 잠금 기간 동안 실천 요건 **0**이라 학습·퀴즈만으로 열매나무까지 간다([[성장-나무]]).

그리고 [[WPA-북극성-지표]] **분자에서도 제외**된다(트리거 1·2·3은 학습 경로).
넣으면 *"접속만으로 실천 지표가 오르는"* 활동량 지표로 퇴화한다 → [[외적보상과-내재동기]]

**수용 기준에도 새겨져 있다** — US-1 AC2에서 부모가 *"퀴즈를 많이 풀어서"* 라고만 답하면 **AC 실패**다.
나무가 학습량 게이지로 오독되면 이 제품은 [[퍼핀]]과 같아진다.

### 승급에 필요한 퀴즈 정답 횟수

세 기준표 모두 **학습·퀴즈 기준은 동일**하고 미션 실천 횟수만 다르다.

| 단계 | 학습 | **퀴즈 정답** | 미션 실천 (벌기·쓰기 / 모으기 / 불리기) |
|---|:-:|:-:|:-:|
| 🌱 새싹 | 0 | **0** | 0 / 0 / 0 |
| 🌳 나무 | 5 | **4** | 2 / 1 / **0** |
| 🌸 꽃나무 | 10 | **8** | 5 / 2 / **0** |
| 🍎 열매나무 | 15 | **12** | 8 / 3 / **0** |

> ⚠️ **일일 한도와 겹쳐 읽어야 한다.** 한 칸의 퀴즈는 하루 1개이므로,
> 열매나무의 **퀴즈 12회는 최소 12일**이 걸린다. 승급 속도의 하한이 여기서 정해진다.

## 🔴 이 기능이 안고 있는 문제

| # | 문제 |
|:-:|---|
| **1** | 🔴 **「학습」 마디는 고객 Pain으로 지탱되지 않는다.** Core 12건 중 학습 자체를 다루는 건이 0건이고, A1 하나뿐인데 부모 Importance **최하위(1.02)**. **설계 근거로만 서 있다** → [[두-가치-선언]] · [[고객-문제-Pain-코드]] |
| **2** | 🔴 **제작량** — 5단계를 그대로 만들면 **연 7,300문항**([[퍼핀]] "2,000+"의 3.6배). 완화안은 「지문 3종 × 숫자 변형 5종」 + 출시 순서 **3 → 1·5 → 2·4** |
| **3** | 🔴 **초1~3 정규 교육과정에 금융·경제가 없다.** 난이도를 개념 깊이로 나눌 근거 자체가 없어 **3축(수 감각·문해·시간 지평)** 으로 재정의했다 → [[학습-난이도-5단계]] |
| **4** | ⚠️ **리스크 R4** — *"부모가 금융 집중을 원한다"* 가 미검증이다. 🧪 모의는 (b) *"그것도 공부니까 좋다"*. (c)가 나오면 4/4 금융이라는 차별점이 흔들린다 |

## 📦 제작량 대응 — **3단계만 만들고 3 → 2·4 → 1·5 순으로** *(2026-09-01 확정)*

5단계 × 4칸을 전부 만들면 **연 7,300문항**이다([[퍼핀]] "2,000+"의 3.6배). 4인 팀이 낼 수 없다.

| 결정 | 내용 |
|---|---|
| **출시 범위** | **3단계(초2-2~초3-1)만** — 기본값 단계 하나로 시작 |
| **확장 순서** | 3 → **2·4** → **1·5** |
| **문항 생성** | 「지문 3종 × 숫자 변형 5종」 — 지문을 재사용하고 숫자만 바꾼다 |
| **일일 소비량** | 분야별 1개 · 총 4개 한도라 **하루 4문항**. 승급에 필요한 퀴즈는 최대 12회 |

**왜 3단계부터인가** — [[학습-난이도-5단계]] 정의표에서 3단계 대상이 **초2-2~초3-1** 이고,
[[핀프렌즈]] 1차 타깃 **초1~3**의 한가운데다. 그리고 [[금융감독원]] 교재 기준선에서
3단계는 *"익힘책 진입 직전"* 이라 **외부 기준선에 가장 가까이 붙은 단계**다.

> 🔴 **받아들인 대가 — C9와 정면으로 부딪힌다.**
> C9에서 *"부모가 학년을 입력하면 단계가 자동 매핑된다"* 고 정했는데,
> **출시 시점에는 3단계밖에 없다.** 초1 가정이 들어오면 자동 매핑이 1·2단계를 가리키는데 콘텐츠가 없다.
>
> **처리** — 온보딩에서 매핑 결과를 보여주되 *"지금은 ○학년용 콘텐츠를 준비 중이에요.
> 우선 기본 단계로 시작할게요"* 를 명시한다. **숨기지 않는다.**
> 그리고 **β 코호트(원장 C4·O7)는 초2~3 가정으로 모집**해 이 구멍을 피한다.

## ✍️ 제작·검수 — **팀이 쓰고 외부 기준선에 대조한다** *(2026-09-01 확정)*

전문 필자를 두지 않는다. **[[금융감독원]] 교재 2종을 검수 기준으로 삼는다.**

| 역할 | 담당 |
|---|---|
| 지문·문항 작성 | 팀 내부 *(학습설계 담당)* |
| **난이도 검수** | [[학습-난이도-5단계]] 3축 체크 — ① 금액 자릿수·연산 ② 지문 길이·선택지 형식 ③ 시간 지평 |
| **내용 검수** | [[금융감독원]] 교재 대조 — 용어·개념이 국가 교재와 어긋나지 않는가 |
| **금지 확인** | `%` 미사용([[학습-난이도-5단계]]) · **이율을 정답 근거로 쓰지 않음**([[불리기-예적금-실천]] C7) |

> 🔴 **아동 대상 학습 콘텐츠를 비전문가가 쓴다.** 이것을 감추지 않는다.
> 방어선은 **금감원 교재라는 외부 기준선 하나뿐**이고, 그 교재는 **초3·4학년용**이라
> 1·2단계(초1~2)에는 대조할 기준이 없다 — 금감원이 그 구간을 뺐기 때문이다.
> **O1에서 3단계부터 출시하기로 한 것이 이 위험도 함께 줄인다.**
