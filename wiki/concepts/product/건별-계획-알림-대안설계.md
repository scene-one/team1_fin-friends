# 🔁 건별 계획 알림 대안설계

⚠️ 이 페이지는 **현재 결정을 뒤집는 제안이 아니다.** [[소비-계획-카드]]는 **봉투형**(🔄 2026-09-01)으로 확정돼 있다.
이 페이지는 봉투형 이전 모델(**건별 계획 카드** — 결제 전 아이가 직접 계획을 적는 방식)로 돌아갔을 때
*"상기 수단을 다르게 설계하면 기각 사유를 피할 수 있는가"* 를 탐색한 **비교 참고용 대안**이다.
봉투 배분율(E3)이 실측에서 미달해 F8이 재검토될 때 참고 대상.

## 전제 — 왜 원래 알림안들이 실패했나

[[소비-계획-카드]] 「기각한 대안」 5종의 공통점은 **상태와 무관하게 반복된다는 것**이다.
정기 시각 알림은 소비 없는 날에도 울려 *"무시를 학습"* 시켰고, 홈 상시 배너는 배너 실명을 만들었다.
아래 설계는 전부 이 공통점을 깨는 방향 — **조건부(상태·이벤트 기반)** 로 다시 짰다.

## 설계 — 출석 ⭐ 편승 + 조건부 시간 트리거

```
① 하교 시간대(부모 설정, 예: 15:00~17:00)
   → ② 그날 아직 계획을 안 세웠을 때만 발동
      → ③ 푸시 실패 대비 — 같은 프롬프트를 출석 ⭐ 세션 안에도 심어둔다
         → ④ 계획 세우기 (10초 내 완료되는 인터랙션)
```

| 장치 | 설계 | 왜 기각 사유를 피하는가 |
|---|---|---|
| **하교시간 알림 — 조건부** | 고정 시각이 아니라 **"오늘 아직 계획 없음" 상태일 때만** 발송 | 정기 시각 알림의 기각 이유(*"소비 없는 날에도 울림"*)를 정확히 제거 |
| **위치정보 없이 시간대만** | 순수 시각 기반 — 지오펜싱·온디바이스 위치 판정 없음 | F14가 못 넘은 선결 조건([[규제-상수]] P-19)을 애초에 안 건드림 |
| **출석 ⭐ 세션에 이중화** | [[별-지급-엔진]] 출석 ⭐(앱 실행만으로 별 1개)를 받으러 여는 세션 안에서도 *"오늘 계획 세웠어?"* 를 묻는다 | 키즈워치·부모 폰 공유([[배성우-H2]])에서 **푸시가 실패해도** 앱을 열기만 하면 도달 — 기기 의존성을 낮춘다 |
| **계획 세우기 UI** | 카테고리 아이콘 3~4개 + 금액 슬라이더, 3탭 이내 완료 | 원래 실패 원인이 *"결제 직전마다 진입해야 함"* 이었으므로 진입 자체를 가볍게 |

**반복 피로도 관리** — 3일 연속 계획 미작성 시 알림 빈도를 낮추거나 문구를 질문형→게임형으로 전환한다.
계속 무시하는 아이에게 같은 강도로 밀어붙이면 정기 시각 알림과 동일한 실패(*"무시 학습"*)가 재현된다.

## 이 안을 택해도 남는 문제 — 매칭은 그대로다

건별 계획으로 돌아가면 **품목별 계획 vs 실제 카드 내역 대조가 다시 업종 코드 매칭에 의존**한다
→ [[카드-업종-분류-MCC]]의 PG 뭉뚱그림·겸업 매장 오분류 문제가 그대로 재현된다.
봉투형이 이 문제를 회피한 이유(**봉투 = 업종**이라 대조가 입력 없이 성립)가 사라지므로,
아이가 직접 업종/카테고리를 고르는 입력 단계가 다시 필요해지고 그만큼 계획 세우기 UI가 무거워진다.

## 왜 봉투형 대신 이 안을 택할 이유가 될 수 있나 (참고)

봉투형은 *"충전 시 1회 배분"* 이라 **품목별(구매 건별) 계획-실제 비교라는 원래 학습 목표를 약화**시킨다 —
아이는 "간식에 얼마 남았나"는 보지만 "이번 주 무엇을 살지 미리 정하는" 경험은 안 한다.
건별 계획이 학습적으로 더 중요하다고 판단되면, 위 조건부 알림 설계가 재검토의 출발점이 될 수 있다.
다만 이는 **팀이 아직 내리지 않은 트레이드오프 판단**이다.
