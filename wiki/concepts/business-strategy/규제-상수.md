# 🔴 규제 상수 — 최우선 · 협상 불가

[[PRD_핀프렌즈_v0_2]] §5-1. 담당: 정책·법령 병윤.

> **아동 대상 금융 서비스의 1순위 NFR은 성능이 아니라 규제다.**
> 아래는 **설계 변수가 아니라 상수**다.

## 9조항

| 조항 | 요구사항 | 검증 방법 |
|---|---|---|
| **P-05 · P-22** | **법정대리인 동의 완료 전 아이 화면 진입 불가.** 아이 온보딩은 첫 화면부터 개인정보 처리가 시작되므로 **순서 자체가 규제 요건** | 동의 미완 상태 진입 시도 → **100% 차단** (자동 테스트) |
| **P-12** | 아동용 **알기 쉬운 고지.** 4칸 명칭은 부모·아이 **동일**하게 두고, 「알기 쉬운 언어」는 **한 줄 설명**이 담당 | 문구 검수 + 아동 이해도 확인 |
| **P-19** | 만 14세 미만 개인위치정보 **옵트인 + 좌표 미저장** → **서버 지오펜싱 불가, 온디바이스 판정 필수.** 동의 화면에 *「부모는 위치를 볼 수 없습니다」* 를 **동의 전에** 명시 | 서버 로그에 좌표 필드 **부재** 검증 · 패킷 검사 |
| **P-20** | 예적금 **가입 중개 안 함** — 비교·선택 경험까지만 | [[불리기-예적금-실천]](F15) 구현 전 법률 검토 통과 (검증과제 ⑤) |
| **P-01 · P-21** | 별은 **차감형 · 교차 금지**, 별↔저금통 **완전 분리.** ❌ 현금 충전 ❌ 현금 환급 ❌ 양도·거래 | 별 원장 감사 · **전환 경로 부재** 검증 |
| **P-13** | 동물 아바타 **얼굴 이미지 미수집** | 데이터 스키마 검수 |
| **P-11** | 해지 시 잔액 **전액 환불** | 해지 플로우 테스트 |
| **P-17 · P-18** | 카드 **한도·업종 제한은 제휴사 정책 종속** — 우리가 정할 수 없음 | 제휴 계약서 확인 |
| **F-01** | 만 14세 미만 **마이데이터 가입 불가** → 표준 API로 데이터를 받을 수 없음 | 아키텍처 리뷰 |

## 🔄 P-19는 적용 대상이 사라졌다

F14(위치 알림)·F19 삭제로 **위치정보를 일절 수집하지 않게 됐다** → [[소비-계획-카드]].
P-19가 요구하던 온디바이스 판정 구현 자체가 **불필요**해졌다. 이것이 계획 카드 안을 채택한 이유 중 하나다.

## 규제가 아키텍처를 결정한 두 지점

### ① F-01 → 폐쇄형 수집 구조

만 14세 미만은 마이데이터에 가입할 수 없다. **오픈뱅킹·마이데이터 연동이 불가**하므로
**자체 카드 발급 + 폐쇄형 수집** 구조가 **필수**다. 선택이 아니다.

### ② P-01·P-21 → 코드에 전환 경로를 두지 않는다

> **기능 플래그로 막는 방식은 금지.**

별↔저금통 전환 경로를 **코드 자체에 두지 않는다.** 플래그는 켜질 수 있기 때문이다. → [[별-지급-엔진]]

## 제휴사 API 경계 — 선불업 B안

```
[핀프렌즈]                          [제휴사 — 선불업 등록 보유]
브랜드 · 앱 · 4칸 학습·실천 시스템  ↔  선불전자지급수단 발행·관리
성장 나무 · 월간 숲 · 별 원장           선불충전금 100% 별도관리
실천 판정 로직                          카드 발행 · 가맹점망
                                        🔴 이용한도 · 업종 제한 (P-17·P-18)
```

🔴 **가맹점 분류 상세도가 회고 품질을 좌우한다** — [[소비-계획-카드]]의 업종 대조가 여기에 걸려 있다. 계약 시 확인 필요.

## 모니터링 — 규제 계층은 즉시 알림

| 항목 | 알림 기준 | 수신자 | 대응 SLA | 에스컬레이션 |
|---|:-:|---|---|---|
| 동의 미완 아이 진입 (`consent_gate_blocked`) · 서버 좌표 필드 유입 | **> 0건 즉시** | 개발 온콜 + 정책 담당 | **30분 내 확인 · 즉시 기능 차단** | **2시간 미해결 → 서비스 일시 중단** |

성능 알림보다 **한 단계 위**의 대응 강도다.
