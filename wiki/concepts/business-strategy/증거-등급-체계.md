# 증거 등급 체계

핀프렌즈 팀 산출물 전체가 공유하는 근거 등급 표기. VPS v2.0에서 승계돼 [[PRD_핀프렌즈_v0_1]] · [[PRD_핀프렌즈_v0_2]]가 그대로 쓴다.

| 표기 | 뜻 |
|---|---|
| **`[A]`** | 학술·공공통계 — 1차 출처로 확인된 사실 |
| **`[관측]`** | 팀이 직접 확인·캡처한 것 |
| **`[추론]`** | 해석·모델값 |
| **`[가설]`** | 미검증 |
| **`[설계 확정]`** | 기능정의 v13에서 확정된 사양 |
| ✍️ **`[합성 가설]`** | 페르소나·여정·Pain — 팀이 구성한 것 |
| 🧪 **`[모의]`** | 모의 응답 — 🔴 **Evidence가 아니다** |
| **`[C·확인 실패]`** | 재조사에서 확인하지 못함 — **인용 금지** |

## 🔴 이 체계를 지켜야 하는 이유

> **`[모의]`와 `[A]`를 섞으면 안 된다.**

팀 산출물에는 **모의 인터뷰 응답**이 섞여 있다. 위키나 발표 자료로 옮길 때 등급 표기가 사라지면
나중에 **실제 데이터로 오인**된다. [[PRD_핀프렌즈_v0_2]]가 §9-2에 [[인용-금지-목록]]을 명문화한 것도 같은 이유다.

## 등급별 실제 분포 — PRD의 경우

| 항목 | 등급 |
|---|---|
| 학습→행동 전이 격차 (+0.33 SD vs +0.07 SD) | **`[A]`** → [[학습-행동-전이-격차]] |
| 저축 교육 희망 65.8% ↔ 실제 저축 12.8% | **`[A]`** → [[저축-격차]] |
| 국내 3사의 「학습→성장」 공백 · [[퍼핀]] 부모 화면 숫자 3개 | **`[관측]`** |
| 실천 없이는 나무가 자라지 않는다 | **`[설계 확정]`** |
| C1·C2가 DOS 1위, C5가 AOS 1위 | **`[추론]`** |
| 페르소나 [[정미경-H1]]·[[배성우-H2]]의 Job과 Pain | ✍️`[합성 가설]` + 🧪`[모의]` |
| 모든 KPI 목표 수치 | **`[가설]`** · 기준선 대부분 ⬜ 미측정 |

## 등급이 검증 설계를 결정한다

[[PRD_핀프렌즈_v0_1_품질리뷰]]가 지적한 **D8(CRITICAL)** 이 이 지점이다 —
v0.1의 Proof 13행 중 5행이 *"학술 인용(추가 실험 불필요)"* 으로 끝났다.

> **인용형 주장도 「우리 제품에서 재현되는가」는 별도로 검증해야 한다.**

그래서 v0.2는 `[A]` 등급 주장에도 실험을 붙였다:

| `[A]` 주장 | 붙은 실험 |
|---|---|
| 학습은 늘지만 행동은 안 바뀐다 | **E10** — 3개월 종단, [[월간-숲]] 3지표 |
| 저축 격차 (부모 1위 ↔ 아이 꼴찌) | **E10에 저축률 지표로 편입** |
| 결제 인프라는 이미 깔려 있다 (충전식 카드 64.2%) | **카드 연결률과 대조** — ≥50%면 인프라 전제 지지 |
| 인센티브는 양, 내재동기는 질 | **E8 + WPA 제외 규칙 검증** (출석률과 WPA 상관 r ≤ 0.3) |

`[관측]` 등급 주장에는 **E11(경쟁사 분기 재점검)** 이 붙었다 — 관측은 시점이 지나면 낡는다.

## ⚠️ `[추론]` 을 「검증됨」으로 쓰지 않기

AOS·DOS 순위는 **합성 가설 위의 분석자 판단값**이다. 인터뷰 8슬롯 완료 후 재채점하되,
*"검증됨"* 으로 쓰지 않고 **순위 변동 여부만** 판정한다.
