# 학습 → 행동 전이 격차

> **가르치는 것과 행동을 바꾸는 것은 다른 문제다.**

| 지표 | 효과크기 |
|---|:-:|
| 금융교육이 **지식**에 미친 효과 | **+0.33 SD** |
| 금융교육이 **행동**에 미친 효과 | **+0.07 SD** |

**차이 약 5배.** 등급 **`[A]`** (학술) — [[PRD_핀프렌즈_v0_2]] §9-1 [K] 항, VPS §7-1 승계.

## 왜 이것이 제품의 출발점인가

[[두-가치-선언]] 선언 ①은 *"자녀가 금융에 대해 **학습**하고 금융 **행동을 실천**하며 **성장**할 수 있습니다"* 다.
즉 **이 격차를 건너겠다는 주장**이다. 문헌은 그게 잘 안 된다고 말한다.

그래서 제품 설계가 이렇게 나왔다:

| 문헌이 말하는 것 | 제품이 한 대응 |
|---|---|
| 지식은 늘어도 행동은 안 바뀐다 | [[성장-나무]] 승급 조건에 **실천 횟수**를 넣음 — *"퀴즈만 100개 풀어도 승급 불가"* |
| 배운 자리와 하는 자리가 멀다 | 학습 완료 후 **「실천하기」로 연결** — 미션·소비 계획·위시리스트·예적금이 **한 화면에 통합**([[학습-커리큘럼-퀴즈]]) |
| 활동량은 성장의 증거가 아니다 | [[WPA-북극성-지표]] 분자에서 **학습 경로 3종을 제외** |
| | [[월간-숲]]이 **전월 대비 변화**를 보여줌 (활동 누적이 아니라) |

[[대안-대비-벤치마크]] ① 축(승급에 필요한 최소 실천 횟수 0회 vs ≥1회)이 이 격차에 대한 직접 응답이다.

## 🔴 `[A]` 등급인데도 실험이 붙은 이유

[[측정가능성-리뷰]] **D8(CRITICAL)** — v0.1은 이 주장을 *"학술 인용(추가 실험 불필요)"* 으로 끝냈다.

> **인용형 주장도 「우리 제품에서 재현되는가」는 별도로 검증해야 한다.**

### E10 — 행동 전이 3개월 종단

| | |
|---|---|
| **설계** | 3개월 종단 관찰 — [[월간-숲]] 「지난달과 비교」 3지표 추적 |
| **지표** | 사려다 멈춤 횟수 · 가격 비교 횟수 · **저축률** |
| **PASS** | 3지표 중 **2개 이상**이 3개월 연속 개선 |
| HOLD | 1개만 개선 |
| **FAIL** | **실천은 늘고 3지표 불변** → 🔴 **선언 ①의 「성장」을 재정의** |

E10의 FAIL은 기능 수정이 아니라 **제품 정의의 수정**을 요구한다. 그만큼 무거운 실험이다.
판정 규칙은 [[PASS-HOLD-FAIL-3구간-판정]].

## 관련 격차

같은 구조가 국내 데이터에도 있다 — [[저축-격차]] (부모가 원하는 교육 1위 ↔ 아이의 실제 행동 최하위).
그쪽도 **E10에 저축률 지표로 편입**돼 같은 실험에서 함께 검증된다.

## ⚠️ 대외 인용 주의

이 격차를 근거로 *"우리는 행동을 바꿉니다"* 라고 쓰면 안 된다.
리스크 R3 — **효과 증명이 없다.** 허용 범위는 *"설계상 그렇게 되도록 만들었다"* 까지다. → [[인용-금지-목록]] 10번
