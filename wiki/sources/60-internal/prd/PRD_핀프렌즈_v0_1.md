# PRD 핀프렌즈 v0.1 — 원본 요약

> **원본** `raw/60-internal/prd/PRD_핀프렌즈_v0_1.md` · 726줄 · 2026-08-21
> ⚠️ **현행 판본이 아니다.** [[PRD_핀프렌즈_v0_2]]가 이 문서를 대체했다.
> **보존 이유** — 원본 스스로 *"v0.1은 남겨 **무엇이 측정 불가였는지의 기록**으로 보존한다"* 고 적었다([[PRD_핀프렌즈_v0_1_품질리뷰]] §5).

## v0.2와 같은 것

골격은 그대로다 — [[두-가치-선언]], [[WPA-북극성-지표]]를 북극성으로 삼은 선택, [[고객-문제-Pain-코드]] 8건, [[규제-상수]] 9조항을 NFR 최상단에 둔 구성, [[인용-금지-목록]] 10항목, 스토리 8개.

즉 **의사결정 문서로서의 내용은 v0.1에서 이미 완성돼 있었다.** v0.2가 바꾼 것은 *"이걸 어떻게 측정하고 합격/불합격을 판정하는가"* 다.

## v0.2와 다른 것 — 이것이 이 문서를 읽는 유일한 이유

| 축 | v0.1 | → v0.2 |
|---|---|---|
| **기능 수** | **19개** (Must 8 / Should 6 / Could 3 / Won't 2) | **17개** — F14·F19 삭제([[소비-계획-카드]]에 흡수) |
| **F19 지위** | 🔴 **최상위 미결** — 옵션 A/B/C 중 팀 결정 대기 | ✅ **삭제 확정**, 넷째 안 채택 |
| **선별 C5 대응** | **MVP에 대응 기능 없음** (숨기지 않고 4곳에 명시) | ⚠️ **부분 대응** — 계획 카드 |
| **북극성 분모** | ⛔ **「활성 아동」 미정의** · 분자 5종 중 2종이 MVP 밖 | 조작적 정의 확정 + v1/v2 분리 |
| **판정 구간** | 통과선·실패선만 — **사이 구간 없음** | [[PASS-HOLD-FAIL-3구간-판정]] |
| **AC** | 26개 · **예외 경로 0개** | 26 + **AC-E 17개** |
| **성능 NFR** | **전부 `⬜ 미정`** — 테스트 대상 부재 | AC 역산 **잠정 상한** + 재설정 트리거 |
| **측정 경로** | *"인앱 이벤트"* 수준 — 구현 불가 | **이벤트 명세 10종** (이름·필드·발생 시점) |
| **선결 순서** | 기술 검토 → 체류시간 실측 → F19 결정 → … | 결제 매칭 → 계획 카드 작성률 → … |

## 이 문서가 스스로 밝힌 한계 (머리말 3항)

1. **선별 Pain 3건 중 1건(C5)의 대응 기능이 MVP에 없다.** 숨기지 않고 §1-4·§4-3·§7-2에 남겼다.
2. **성능·가용성 목표값을 비워 뒀다** — 아키텍처 없이 숫자를 채우면 근거 없는 SLO가 되므로, *정하는 방법*만 §5-2에 적었다.
3. **「소비 사전 개입」은 현재 제공 기능이 아니다.** 대외 자료에 현재형으로 쓰지 말 것.

> 이 세 문장 중 1·3은 v0.2에서도 **살아 있다.** F19를 삭제해도 C5의 사각지대는 사라지지 않고 **「계획을 적지 않은 소비」로 옮겨갔을 뿐**이다([[소비-계획-카드]]).

## ⚠️ 인용 시 주의

이 판본의 수치를 인용하면 **F14·F19가 살아 있던 시점의 기능 목록**을 인용하게 된다.
특히 *"매장에 3분 이상 머무르면 알림"* 계열 서술은 v0.2에서 **대외 사용 금지**로 확정됐다 — [[인용-금지-목록]].
