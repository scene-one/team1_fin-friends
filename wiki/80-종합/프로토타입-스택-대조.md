# 🔍 프로토타입 스택 대조

프로토타입은 **[[기술-스택]] 확정 전에 SRS 기반으로 만들어졌다.** 그래서 물어야 할 것은
*"틀렸나"* 가 아니라 **「지금 확정된 §2.5와 어디서 갈라지는가」** 다.

> **대조 대상** — 데모 저장소 `github.com/2ma1995/finfriends`. 갈라진 지점은 그 저장소의
> **어긋남 대장** `docs/ops-docs/[Ops]Spec-Drift-Log.md`(D1~D71)에 구현자가 직접 기록해 두었다.
> 이 페이지는 그 대장을 **위키 쪽 근거와 맞춰 읽은 결과**다.

> 🟢 **대부분 수렴한다.** Next.js·TypeScript·React·three.js·PostgreSQL은 확정 스택 그대로다.
> **배포를 실제로 막는 것은 1건**이고, 나머지는 「미기록」이거나 「아직 없는 것」이다.

## 🔴 배포를 막는 것 1건

### 1. Pretendard를 jsDelivr CDN으로 불러온다

| | |
|---|---|
| **무엇을 어긴다** | `NFR-008` 브라우저에서 나가는 제3자 오리진 요청 **0건** |
| **명문 조항** | `SRS §2.5` 프런트엔드 행 — *"폰트·아이콘·라이브러리를 **전부 자체 호스팅**한다(외부 CDN 및 원격 폰트 로딩 금지)"* |
| **어디에 있나** | `app/src/app/globals.css` **첫 `@import`** — `cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9` `[관측]` |
| **어디서 걸리나** | **배포 관문 4**(CSP 리포트) · 아키텍처 결정 6 — *"CDN이 CSP에 막혀 **기능이 조용히 죽는다**"* |
| **고치는 법** | `npm i pretendard` → `next/font/local` 로 자체 호스팅. 서브셋도 빌드 타임에 로컬로 만든다 |

🔴 **폰트만의 문제가 아니다.** CSP를 켜는 순간 원격 폰트가 차단되고, 서브셋 로딩 실패는
**글꼴이 깨지는 게 아니라 레이아웃이 무너지는** 형태로 나타난다. 지금 잡는 게 가장 싸다.

> 반대로 **Tailwind·shadcn·@base-ui/react·lucide-react·three는 전부 npm 번들**이라 `NFR-008`에
> 걸리지 않는다. 3D 에셋(`.glb`)도 `public/models/` 자체 서빙이다.
> 제3자 오리진을 만드는 건 **폰트 한 줄뿐**이다.

## 🟢 해소된 것 — DB 벤더

**Supabase를 쓰지 않는다.** 로컬 PostgreSQL(Docker)로 개발하고, 인증도 자체 스키마(`dev_auth`)와
Server Action 3종으로 만들었다(어긋남 대장 `D10`) `[관측]`.

앞서 물었던 **결합 깊이 확인 5개**의 답은 전부 「아니오」다 — `@supabase/supabase-js` 의존성 없음 ·
Auth 자체 구현 · Storage 미사용([[미션]] 사진은 PostgreSQL 표에 두고 판정 즉시 파기) · Realtime 없음 ·
RLS는 **벤더 기능이 아니라 자체 마이그레이션의 Postgres 역할 2개**(`app_identity` · `app_activity`)다.

🟢 **그래서 이관 비용이 「접속 문자열」 쪽에 있다.** 이관 시 바뀌는 앱 코드는
`src/lib/session/guardian-session.ts` **한 파일**이라고 대장이 못 박아 두었다.

🔴 **다만 목적지를 다시 확인해야 한다.** `SRS §2.5` 인프라 행은 **AWS(ECS·RDS·S3) · 서울 리전 고정**이고
`NFR-009`는 아동 데이터 **국외이전 없음**을 요구한다. Supabase로 가면 **별개 사업자로의 처리위탁**이
되어 `NFR-009` 검수(데이터 흐름도 분기 1회)가 통과할 근거가 사라진다.
**마감은 β 클로즈드 직전** — 「로컬·α」는 데이터 폐기 전제라 모의 데이터면 규제 대상이 아니고,
**β부터 실제 8가정의 아동 데이터**가 들어온다.

프로토타입이 **사실상 결정해버린 항목들**이다. `SRS §2.5` 채택 표에 행이 없으면
나중에 *"정한 적 없는데 왜 쓰지"* 가 반복된다.

### 🔴 Web Push에 딸려 오는 새 제약

푸시 엔드포인트는 **브라우저 벤더 서버**(FCM·Mozilla·Apple)다 — 국외다.
페이로드가 종단 암호화되더라도, 규칙 없이 두면 `G-2`와 같은 구멍이 생긴다.

| 규칙 | 내용 |
|---|---|
| **G-7** `[제안]` | 푸시 페이로드에 **아동 식별 데이터·[[소비-계획-카드]] 내용을 넣지 않는다.** 알림 본문은 **고정 문구**로 하고, 상세는 앱을 열어야 보이게 한다 |

> `FR-022`의 알림은 원래 *"오늘 계획 카드 0건"* 이라는 **트리거 신호**일 뿐이라 문구를 고정해도 기능이 온전하다.

## ✅ 프로토타입이 옳아서 SRS를 고친 것 1건

### 6. 백엔드 런타임 — **Next.js 하나로 간다** (`PRD ADR-018`)

`SRS §2.5` 백엔드 행은 **Next.js 서버 런타임**(Route Handler·Server Action)으로 확정됐다.
Express 별도 서버는 **§2.5.3 범위 밖**으로 내렸다.

**왜** — 백엔드를 따로 뺀 원래 목적이 *"4인 팀의 런타임을 하나로 유지"* 였는데, **Next.js 하나면
그 목적이 더 잘 달성된다.** 런타임이 둘이면 배포·인증·타입 정의가 **두 벌**이 되고,
정작 규제 보증은 프레임워크가 아니라 **빌드 산출물(`NFR-003`)과 토큰 스코프(`NFR-004`)** 에 걸린다.

🔴 **받아들인 대가** — 서버 로직과 화면 코드가 한 저장소에 섞인다. 방어선 3겹 —
① `server-only` 강제 ② **배포 관문 1**(아이 번들에 `/parent/` 문자열 0건) ③ 오리진별 빌드 타깃 분리.
**되돌리는 조건** — 관문 1이 잡지 못하는 유출 경로가 1건이라도 나오면 도메인 계층을 별도 서비스로 뺀다.

## 🟠 계획과 다르게 만든 것 4건

**구현이 뒤처진 게 아니라 다른 방식을 고른 것들**이다. 문서를 고쳐야 하는 쪽이다.

### 7. 오리진 분리 — 단일 앱이라 못 가른다. 빌드 게이트로 대신한다 (`D38`)

**단일 오리진이다.** PWA 매니페스트도 하나이고, 시작 주소가 기기를 보고 아이·보호자 화면으로 가른다 `[관측]`.
`CON-01`(Next 단일 풀스택)이 도메인을 가르는 것을 막는다.

`AC-003-2`가 요구하는 **「아이 번들에 부모 엔드포인트 문자열 0건」** 은 **세 겹**으로 지킨다 —
① 미들웨어가 아이 기기의 부모 경로 진입을 서버에서 막고 ② 보호자 Server Action이 각자 첫 줄에서
인가를 다시 확인하고 ③ 빌드 게이트(`scan_child_bundle.mjs`)가 소스 import와 빌드 산출물을 검사해
하나라도 걸리면 빌드를 세운다.

🔴 **[[규제-상수]] `P-05`를 오리진 단위로 검증한다는 [[PWA]]의 전제가 지금은 성립하지 않는다.**
런타임 경계가 막아 주던 몫을 **빌드 게이트 하나가** 지고 있다.
**되돌리는 조건** — 게이트를 우회하는 유출 경로가 1건이라도 나오면 도메인을 가른다.

### 8. Service Worker 오프라인 큐 — 기각하고 서버 멱등 키로 (`D56`)

**워커는 요청을 가로채지 않는다.** 캐싱도 하지 않고 웹 푸시 수신만 한다 `[관측]`.

**기각 사유** — 이 앱은 잔액·미션 상태처럼 **낡으면 안 되는 숫자**를 보여준다.
워커가 오래된 화면을 돌려주면 **부모와 아이가 다른 잔액을 본다.**

`NFR-022` *"오프라인 후 ⭐ 중복 지급 0건"* 은 **서버 원장의 `idempotency_key` unique 제약**이
보증한다 — 같은 요청이 두 번 들어와도 두 번째가 DB에 들어가지 못한다.
**요구는 지켜지고 수단이 바뀐 것**이므로, `SRS §2.5` 오프라인 행을 고쳐야 한다.

### 9. 별 원장 — 잔액을 저장하지 않는다 · 정산이 배치가 아니다 (`D22` · `D39`)

[[별-지급-엔진]]이 말하는 **「이중 기입」** 은 회계의 차변/대변이 아니라
*"단일 컬럼 증감이 아니라 **원장 행 추가**"* 라는 뜻이다(`증강 시퀀스 §189`). 구현은 이 정의를 지킨다.

갈라지는 것은 둘이다 `[관측]`.

| | 문서 | 구현 |
|---|---|---|
| **잔액** | `PRD §645` 별 원장 필드에 **잔액**이 있다 | **잔액 컬럼이 없다.** 원장 합이 곧 잔액이다 — 둘을 따로 두면 어긋나는 순간 어느 쪽이 맞는지 알 수 없다 |
| **정산 시점** | `NFR-020` **일일 정산 배치** · 불일치 > 0건 즉시 **온콜 알림** | 주기 전환·월말 스냅샷·정산 세 함수를 **나무·숲 화면을 열 때** 부른다. 알림 인프라가 없어 **나무 화면 표시**로 대신한다 |

🟢 **불일치 처리 방침은 그대로다** — 어긋난 줄에 격리 표시만 하고 **잔액을 건드리지 않으며 지급도 멈추지 않는다**([[규제-상수]]).
🔴 **남은 일** — cron 연결. 아무도 화면을 안 열면 정산이 돌지 않는다. 시연에는 문제없고 운영에는 필요하다.

### 10. three.js — UI 의존성 0건 규칙의 예외 (`D2` · `D3`)

`REQ-TEC-007`이 Tailwind + shadcn/ui 외 의존성 **0건**을 요구하고 `ADR-T05`가 [[아바타-옷장]]을
**Lottie 2.5D**로 지정했는데, **three.js 3D로 갔다** — 캐릭터 12종 · 펫 11종 · 7분류 71개 아이템 `[관측]`.

🟢 **부수 효과가 크다** — 에셋이 전부 **CC0**(Kenney)라 3D 제작비가 거의 0이 되고 리스크 `R9`이 사라진다.
🔴 **승인이 남아 있다** — `ADR-T05` 자신이 전환의 대가로 *"회전이 사라진다"* 를 적고 승인을 요구해 두었다.

**`FR-034` 유휴 애니메이션은 CSS다** — `globals.css` 모션 절이 *"CSS 전용. Lottie·GSAP을 설치하지 않는다"* 이고,
키프레임과 `transform`만 쓴다 `[관측]`. three.js는 방·아바타 **렌더 전용**이라 §2.5 제약과 충돌하지 않는다.

## 🧭 결정 배경 (Context)

**Summary** 프로토타입은 **[[기술-스택]] 확정 전 산출물**이므로 갈라짐은 예상된 것이다.
분류 기준은 **「배포를 막는가」** 하나다 — 관문 1~6에 걸리면 🔴, 아니면 기록으로 흡수한다.

**Evidence**
- `NFR-008` 검증 수단은 **CSP 리포트**이고 관문 4에서 배포를 막는다 `[설계 확정]`
- `NFR-009` 검증 수단은 **데이터 흐름도 검수(분기 1회)** 라 벤더가 늘면 검수 범위가 그만큼 넓어진다 `[설계 확정]`

**Implication** §2.5.4(전환 경로 · 미션 이미지 0건 · 제3자 오리진 0건 · 국외이전 없음 ·
원장 정합성 0% · 컬럼 부재 제약)를 **깨는 것은 폰트 CDN 하나뿐**이다.
나머지는 **금지가 아니라 「미기록」이거나 「수단이 바뀐 것」** 이므로, 고칠 대상은 코드가 아니라 **문서**다.

**기각한 대안** — *"프로토타입을 §2.5에 맞춰 다시 만든다"*.
겹치는 스택이 압도적이라 **폰트 한 줄**을 고치고 나머지는 문서를 맞추는 편이 싸다.
