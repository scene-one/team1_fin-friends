# 랜딩페이지 퍼널 점검 — 인지부터 재구매까지 어디가 비어 있나

> **질문** — `기획산출물/30-산출물/랜딩페이지/landing.html`·`service-example.html`은 **인지→관심→고려→의도→평가→구매→재구매** 7단계 퍼널을 얼마나 채우고 있는가?
> **근거 범위** — 두 HTML 파일의 실제 마크업·문구, [[핀프렌즈]]·[[PWA]]·[[규제-상수]](이 위키), `조사/혜원/발표덱/마스터덱_목차.md`(경쟁 비교·신뢰 자료의 소재 확인용).

---

## 한 문장 답

> **인지·관심·평가(반박) 단계는 두텁지만, "고려"의 경쟁 비교와 "의도 이후"가 전부 비어 있다.
> 모든 CTA가 실제 전환 행동 없이 같은 페이지의 같은 자리(`#start`)로 되돌아오고,
> "화면 보기" 링크를 누른 방문자는 다시 랜딩으로 돌아올 CTA가 없는 막다른 페이지에 도착한다.**

---

## 1. 퍼널 7단계 대조표

| 단계 | 랜딩페이지가 채운 것 | 상태 |
|---|---|:-:|
| **인지** | 히어로 — "배운 돈 공부가 생활이 되는 순간", 3개 폰 목업으로 핵심 화면 예고 | 🟢 충분 |
| **관심** | "문제" 섹션 — 학습일수·문제 수·보상액 숫자는 쌓이는데 "달라졌냐"는 질문. 실제 인용 2건(교사·자영업) | 🟢 충분 |
| **고려** | 차별점 2가지(실천해야 자라는 나무 · 계획↔실제 대조), 4영역 학습 구조 | 🟡 부분 — **경쟁 서비스·현금 봉투 대비 비교가 없음** |
| **의도** | 헤더·히어로·최종 3곳에 CTA "무료로 시작하기" | 🔴 **형식만 있음** — 3곳 모두 `href="#start"`, 즉 같은 페이지의 마지막 섹션으로 돌아올 뿐 실제 가입 동작이 없음 |
| **평가** | "장벽" FAQ 4문항(비용·완료 부담·카드 대기·이전 기록) + "안전" 3항목(위치정보·동의·별의 성격) | 🟢 충분 — 반박형 신뢰 구축은 잘 되어 있음 |
| **구매** | 없음 | 🔴 **없음** — 회원가입·초대 링크·앱 진입 등 실제 전환 경로 부재 |
| **재구매** | 없음 | 🔴 **없음** — 공유·추천·재방문 유도 요소 없음 |

## 2. 구조적 결함 3가지

### 🔴 결함 1 — 모든 CTA가 같은 자리로 돌아온다

`landing.html`의 CTA 3곳(헤더 `.cta.sm`, 히어로, 최종 섹션)이 전부 `href="#start"`이고, `#start`는 **본문 맨 아래 CTA 섹션 자신**이다. 즉 "성격 급한 사용자를 위한 최상단/최하단 바로가기"라는 구조는 자리만 갖춰져 있고, **눌러도 도착하는 곳이 실제 전환 페이지가 아니라 같은 문구의 반복**이다.

- 예시로 든 퍼널 전략의 1번(진입=허브, 직접 전환 버튼)은 **버튼 위치는 맞지만 목적지가 없다.**
- 지금 상태로는 방문자가 "무료로 시작하기"를 눌러도 로딩이 아니라 스크롤만 일어난다 — 전환 의도가 있는 사용자를 그대로 페이지 안에 가둔다.

### 🔴 결함 2 — "화면 보기"가 막다른 골목이다

헤더의 `service-example.html` 링크를 따라가면 [[핀프렌즈]]의 3가지 핵심 화면(성장 나무·계획 대조·월간 숲) 목업을 볼 수 있지만, 이 페이지에는 **다시 랜딩으로 돌아가는 링크도, 가입 CTA도, 네비게이션도 전혀 없다.** 관심을 갖고 화면까지 들여다본 방문자가 **퍼널에서 그대로 이탈**하는 구조다.

- 예시 전략의 2번("서비스 페이지는 핵심 유인책 — 확인 순간 다음 단계로 유도")과 정반대로, 지금은 확인시켜주고 **아무 데도 안내하지 않는다.**

### 🟡 결함 3 — "고려" 단계의 경쟁 비교·신뢰 구축 콘텐츠가 없다

랜딩페이지 어디에도 퍼핀·아이부자·현금 봉투 같은 대안과의 비교, 팀 소개, 후기·가입자 수 같은 사회적 증거가 없다. 이미 존재하는 자료([[대안-대비-벤치마크]], `조사/혜원/발표덱/마스터덱_목차.md` 12p "기존 서비스들은 지금 어떻게 하고 있나")를 랜딩용으로 축약해 옮기면 되는데 아직 반영되지 않았다.

- "정보 페이지(신뢰 구축)"에 해당하는 **회사/팀 소개가 전무** — "안전" 섹션이 정책적 신뢰는 주지만 "이 팀을 믿어도 되는가"는 답하지 않는다.

## 3. 보완 방법 — 우선순위순

| 순위 | 무엇을 | 왜 |
|:-:|---|---|
| **1** | `#start` CTA를 **실제 액션**으로 바꾼다 — 최소한 이메일·전화번호를 받는 사전예약 폼이나, 부모 초대 링크 발급 흐름(SRS §3.1 온보딩) 목업으로 연결 | 지금은 "의도" 단계 사용자를 전환시킬 수단이 아예 없다 |
| **2** | `service-example.html` 상단에 **sticky 헤더**(로고 + "← 랜딩으로" + "무료로 시작하기" CTA)를 추가 | 화면까지 확인한, 전환 확률이 가장 높은 방문자를 그대로 잃고 있다 |
| **3** | "고려" 단계에 **경쟁 비교 섹션**을 추가 — 퍼핀·아이부자·현금 봉투 대비 "성장의 증거" 축 하나만 표로 | 발표덱 12p 자료를 그대로 축약 가능, 새로 조사할 필요 없음 |
| **4** | "평가" 섹션에 **팀 소개 1줄 + 신뢰 배지**(예: 규제 준수·법정대리인 동의 절차 명시는 이미 있음) 보강 | 정책적 신뢰는 있지만 "누가 만들었나"가 없다 |
| **5** | 최종 CTA 아래에 **"먼저 알림 받기" 보조 전환**을 추가 — 아직 가입할 준비가 안 된 방문자를 이메일로라도 남긴다 | 지금은 전환 아니면 이탈, 중간이 없다 |
| **6** | "재구매/공유" 단계용 — 월간 숲 화면(이미 히어로에 목업 있음) 옆에 **"우리 아이도 이렇게 자랐어요" 공유 버튼** 여지를 표시 | 예시 전략의 6번과 동일한 논리. MVP 범위 밖이면 "다음 버전 예정"으로만 표시해도 됨 |

> 🔴 **1·2번은 콘텐츠가 아니라 구조 결함이다.** 문구를 다듬기 전에 먼저 고쳐야 나머지 보완이 의미가 있다 — 지금은 퍼널의 "의도" 계단 자체가 없어서, 그 위(고려·인지)를 아무리 잘 채워도 전환으로 이어지지 않는다.

## 미결로 남은 것

- ⬜ **실제 가입·온보딩 페이지 부재** — [[PWA]] 전달 방식과 SRS §3.1 온보딩 시퀀스는 설계돼 있으나 랜딩에서 그리로 잇는 페이지가 없다
- ⬜ **경쟁 비교 콘텐츠를 랜딩용으로 축약할 담당자 미정**
- ⬜ 사전예약/알림 폼을 만들 경우 **수집 항목이 [[규제-상수]](법정대리인 동의 전 아동 정보 미수집)를 건드리지 않는지 확인 필요** — 부모 이메일만 받는 정도면 안전하나, 아이 정보를 묻는 순간 동의 절차 없이는 안 된다
