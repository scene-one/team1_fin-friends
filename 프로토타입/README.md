## 만져보면 보이는 것

- **⑦ 성장 나무** — 「벌기 실천 횟수」를 0 → 1로 올리면 새싹이 나무가 됩니다. **퀴즈만으로는 안 자란다**는 발표 포인트 ①의 실물 증명
- **⑤ 계획↔실제 대조** — 「실제 결제액」을 5,000원 이내로 내리면 **초록 화면 + ⭐1**, 넘기면 **「적어두지 않은 가게」가 주황으로 뜨고 별 없음.** 별은 「확인」이 아니라 「지킴」에 붙습니다
- **④ 계획 카드** — 업종 칩을 눌러 고르고, 금액을 바꾸면 자전거 목표 영향이 따라 바뀝니다
- **② 홈** — 옷 선택 / 별 부족 시 잠김
