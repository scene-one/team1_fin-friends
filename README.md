## 🎯 무엇을 다뤘나

### 찾은 문제 두 개

| | 문제 | 근거 |
|:-:|---|---|
| **①** | 아이의 학습 현황을 **볼 수는 있는데, 그게 성장인지 알 수 없다** | 부모 화면이 누적일수·문제수·보상액 **숫자 3개뿐** (팀 직접 캡처) |
| **②** | **학습이 실천으로 이어지지 않는다** | 실패 요인 1위 「금융 행동으로 전이되지 않음」 · **오답에도 보상 절반 지급** (퍼핀 공식 사양) |

> 🔑 **부모 66%가 원하는 「저축 습관」을 아이는 13%만 하고 있습니다.** — 격차 53%p가 문제 정의의 출발점입니다.
> ⚠️ 「성장을 **확인할 수 없다**」로 쓰면 반박당합니다. 퍼핀은 2024-10에 부모용 학습 내역 확인 기능을 이미 냈습니다. **확인은 됩니다. 그게 성장인지 모르는 것이 문제입니다.**

### 내놓은 해법 — 실천할 자리를 만든다

| | 기능 | 무엇이 달라지나 |
|:-:|---|---|
| 🧹 | **미션 루프** | 일해서 돈이 생기는 경험 → 「벌기」의 실천 근거 |
| 📝 | **소비 계획 카드** *(사전)* | 쓰기 **전에** 어디서·무엇을·얼마 쓸지 아이가 직접 적음 |
| 💳 | **계획 ↔ 실제 대조** *(사후)* | 적어둔 계획과 실제 결제를 업종·금액으로 겹쳐 봄. **별⭐은 「확인」이 아니라 「지킴」에 붙음** |
| 🎯 | **위시리스트 · 예적금** | 모을 동기 · 「불리기」를 선택으로 경험 |
| 🌳 | **성장 나무 / 월간 숲** *(부모)* | 4칸(벌기·잘 쓰기·모으기·불리기)이 실천으로만 자람 |

> 🔴 **청중이 하나만 기억한다면 —** **"퀴즈를 100개 풀어도 나무는 안 자란다."**

## 🔬 이 프로젝트에서 실제로 뒤집힌 전제 3가지

분석 도중 1차 프로젝트의 전제가 세 번 무너졌고, 그때마다 방향을 바꿨습니다. 기록으로 남겨둡니다.

| | 뒤집힌 것 | 어떻게 대응했나 |
|:-:|---|---|
| **①** | 1차 페인포인트의 **리뷰 근거가 거의 없었다** — 리뷰 921건 전수 분류 결과 「아이 성장 경험 부족」은 **3건(0.3%)**, 아이 본인 진술은 **0건** | 가설이 틀린 게 아니라 **증거 유형을 잘못 고른 것**으로 판정 → 근거를 **이론 · 산업 비교 · 팀 직접사용 3계층**으로 재구성, 리뷰는 보조근거로 강등 |
| **②** | **돈 보상은 잘 작동 중이었다** — 「돈 때문에 매일 푼다」 긍정 **126건(13.7%)** vs 부작용 11건, 학술 근거도 같은 방향 | 「돈 대신 별」이 아니라 **「돈이 못 하는 일을 별이 채운다」** 로 프레이밍 전환 |
| **③** | **위치 알림은 못 쓴다** — 아동 위치정보 수집의 무게에 비해 효과가 불확실 | 📍 위치 알림 **삭제** → 📝 **소비 계획 카드**로 대체. **위치정보를 일절 쓰지 않습니다** |

법령·약관 검토에서도 세 가지가 기능 설계를 흔들었습니다 — **만 14세 미만 마이데이터 가입 불가** · **Gemini API의 18세 미만 대상 서비스 금지** · **선불전자지급수단 등록 요건**. 각각 자체 기록 전환 · 자체 호스팅 · 현금 미션 Phase 2 분리로 처리했습니다. → [`병윤/03_법령조사/`](병윤/03_법령조사/법령조사_결과.md)

| # | 문서 | 무엇을 답하나 |

| 6 | 시장기회 분석 (AOS/DOS) | 어느 페인포인트를 고를 것인가 |

화면을 베낀 게 아니라 **원리를 가져와 우리 문제에 맞게 바꿨습니다.**
