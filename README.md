**무엇** — 초등 1~3학년(만 7~9세)과 부모를 위한 금융 학습·실천 서비스입니다. 부모용·아이용 **PWA 2종**.
아이가 용돈을 **벌기 · 잘 쓰기 · 모으기 · 불리기** 로 다루는 동안, 부모는 그 **행동의 변화**를 성장 나무와 월간 숲으로 봅니다.
**왜** — 부모는 아이의 학습 현황을 **볼 수는 있는데 그게 성장인지 알 수 없고**, 배운 것이 **실천으로 이어지지 않기** 때문입니다.
**어디까지** — 3개 차수에 걸쳐 **분석 근거 16종 → 사양 3종 → 기술설계 3건 → 작업 이슈 13건 → 동작하는 데모 배포**까지 갔습니다.
**누가** — 새싹프렌즈 1팀 **4명** · SeSAC AI Native PM Project. *(3차에 송유림 → 박수빈 교체)*

> ### 배운 것을 **실천할 자리**를 만든다
> 아이는 해보면서 자라고, 부모는 「배웠다」가 아니라 **「달라졌다」** 를 봅니다.

### 찾은 문제 두 개

| | 문제 | 근거 |
|:-:|---|---|
| **①** | 아이의 학습 현황을 **볼 수는 있는데, 그게 성장인지 알 수 없다** | 부모 화면이 누적일수·문제수·보상액 **숫자 3개뿐** `[관측]` |
| **②** | **학습이 실천으로 이어지지 않는다** | 실패 요인 1위 「금융 행동으로 전이되지 않음」 · **오답에도 보상 절반 지급** (퍼핀 공식 사양) |

> 🔑 **부모 66%가 원하는 「저축 습관」을 아이는 13%만 하고 있습니다.** 격차 53%p가 문제 정의의 출발점입니다.
> ⚠️ 「성장을 **확인할 수 없다**」로 쓰면 반박당합니다. 퍼핀은 2024-10에 부모용 학습 내역 확인 기능을 냈습니다.
> **확인은 됩니다. 그게 성장인지 모르는 것이 문제입니다.**

| | 기능 | 무엇이 달라지나 |
