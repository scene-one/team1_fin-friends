# 핀프렌즈 (FinFriends)

**새싹프렌즈 1팀** · SeSAC AI Native PM Project · 3차 프로젝트 **2026-08-31 ~ 09-03**

> ### 배운 것을 **실천할 자리**를 만든다
> 아이는 해보면서 자라고, 부모는 「배웠다」가 아니라 **「달라졌다」** 를 봅니다.

초등 1~3학년(만 7~9세)과 부모를 위한 금융 학습·실천 서비스입니다.
아이가 용돈을 **벌기 · 잘 쓰기 · 모으기 · 불리기** 로 다루는 동안,
부모는 그 **행동의 변화**를 성장 나무와 월간 숲으로 확인합니다.

## 🎯 무엇을 풀었나

### 찾은 문제 두 개

| | 문제 | 근거 |
|:-:|---|---|
| **①** | 아이의 학습 현황을 **볼 수는 있는데, 그게 성장인지 알 수 없다** | 부모 화면이 누적일수·문제수·보상액 **숫자 3개뿐** `[관측]` |
| **②** | **학습이 실천으로 이어지지 않는다** | 실패 요인 1위 「금융 행동으로 전이되지 않음」 · **오답에도 보상 절반 지급** (퍼핀 공식 사양) |

> 🔑 **부모 66%가 원하는 「저축 습관」을 아이는 13%만 하고 있습니다.** 격차 53%p가 문제 정의의 출발점입니다.
> ⚠️ 「성장을 **확인할 수 없다**」로 쓰면 반박당합니다. 퍼핀은 2024-10에 부모용 학습 내역 확인 기능을 냈습니다.
> **확인은 됩니다. 그게 성장인지 모르는 것이 문제입니다.**

### 내놓은 해법 — 실천할 자리를 만든다

| | 기능 | 무엇이 달라지나 |
|:-:|---|---|
| 📚 | **학습 · 퀴즈** | 분야별 하루 1문제 · 총 4문제 상한. 퀴즈만으로는 아이템을 살 별이 모이지 않습니다 |
| 📝 | **소비 계획 카드** | 쓰기 **전에** 「날짜 · 어디서 · 얼마까지」 3필드를 적고, 쓴 **뒤에** 실제 결제와 맞춰봅니다 |
| 🎯 | **위시리스트** | 목표 하나를 정해 모으고, 달성률에 따라 별을 받습니다 |
| 🧹 | **미션 루프** | 사진 인증 → 부모 승인 → 용돈 + ⭐. **72시간 미확인 시 자동 지급** |
| 💰 | **부모 적금** | 아이가 신청하고 부모와 **현실에서 협상**합니다. 합의 성립이 「불리기」 실천 1회 |
| 🌳 | **성장 나무 / 월간 숲** *(부모)* | 4칸이 **실천으로만** 자랍니다. 나무는 매월 초기화되고, 숲은 전월 대비로 남습니다 |

> 🔴 **하나만 기억한다면 —** **"퀴즈를 100개 풀어도 나무는 안 자란다."**
