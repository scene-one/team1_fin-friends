## 🚨 이것만은

**1. 범위를 넓히지 마세요**
"퍼핀 전체 분석"으로 가면 4일 안에 못 끝냅니다. 기능 딱 하나만 봅니다.

**2. 8/20 낮 12시가 고비입니다**
"뭘 고칠지" 1개를 그때까지 못 정하면 그날 하루가 날아갑니다. 12시 되면 팀장이 그냥 정하고 결정 기록에 "임시 · 오후 3시 재검토"로 남깁니다.

**3. 화면을 베끼지 말고 원리를 가져오세요**
2차 프로젝트 배점의 핵심입니다. "다른 서비스가 이렇게 생겼더라" ❌ → **"이 문제를 이런 원리로 줄였더라, 우리는 이렇게 바꿔서 쓴다"** ⭕

**4. 모든 주장에 라벨을 붙이세요**

| 라벨 | 뜻 | 예 |
|---|---|---|
| **사실** | 다시 확인 가능 | 앱 화면, 약관, 기사 |
| **추론** | 근거 있는 추측 | "정산 원장이 필요할 것이다" |
| **가정** | 아직 확인 못 함 | "부모 개입 부족이 이탈 원인일 것이다" |

가정을 없애는 게 목적이 아니라, **어디까지 알고 뭘 더 확인해야 하는지 관리**하는 게 목적입니다.
