### 작업할 때 지킬 것

**Five Forces** — 5가지 힘 각각에
- 근거 **1개씩** (링크 + 확인 날짜)
- **「그래서 퍼핀이 뭘 잘해야 하나」 한 줄** ← 이게 없으면 그냥 표가 됨

**TAM-SAM-SOM** — 3단계 각각에
- 계산식을 그대로 쓰기 (예: 초등학생 270만 × 앱 사용률 x% × 유료 전환 y%)
- 숫자마다 출처와 확인 날짜

**Segment Map** — 2축
- **축 2개를 왜 골랐는지** 설명이 있어야 함
- 우리가 노리는 세그먼트가 **혜원의 페르소나와 같은 사람**인지 확인 ← 15:00에 맞춰봄
