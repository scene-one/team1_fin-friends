# 0. 한 줄 정체성

> ## 핀프렌즈는 **돈을 옮기지 않고, 돈에 대한 판단을 훈련시키는** 서비스다.

**왜 이 문장인가** — 세 가지가 같은 방향을 가리켰습니다.

| 어디서 | 결론 |
|---|---|
| 유림 시장분석 | 진짜 문제는 재미가 아니라 **"성장을 증명하지 못하는 것"** |
| 퍼핀 리뷰 (1차) | "돈은 받는데 **내가 뭘 잘하게 됐는지 모르겠다**" |
| 법령·실행조건 조사 | 라이선스 없이 만들려면 **돈을 다루지 않는 구조**여야 함 |

**제약과 문제 정의가 일치합니다.** 이게 발표 전체를 관통하는 논리입니다.

# 1. 서비스 구조

```
┌─ 매일 루프 · Phase 0 · 라이선스 불필요 ────────────────┐
│                                                         │
│  경제문제 풀기 → 별⭐ 획득                              │
│       ↓                                                 │
│  별⭐ 소비 → 테마/옷장 잠금해제                          │
│       ↓                                                 │
│  아바타 사진 생성 (비동기) → 아이 기기 앨범 저장         │
│       ↓                                                 │
│  부모에게 성장 보여주기 ──────────────────┐             │
│                                            │             │
│  [친구] 진도·별 개수만 공유 (사진 ❌)      │             │
└───────────────────────────────────────────│─────────────┘
                                            ↓
                    부모: 성장 리포트로 확신 → 구독 유지

┌─ 월간 루프 · Phase 2 · 🔴 선불업 등록 전제 ─────────────┐
│  부모 충전 → 미션금 설정 → 아이 수행 → 현금 지급         │
│  → PRD에 "범위 외 · 전제 조건"으로 명시                  │
└──────────────────────────────────────────────────────────┘

❌ 제외: 버닝퀴즈 / 사진 공유
```

**핵심 기능 1개** = 경제문제 → 별⭐ → 아바타 성장 → 부모 확인
**보조 기능 0개** (가이드 "핵심 1개 + 보조 0~2개" 범위 내)

## 🔴 보상이 2층으로 분리되는 것이 핵심입니다

| 층 | 주기 | 보상 | 부모 개입 |
|---|---|---|---|
| **1층** | 매일 | **별⭐** | ❌ **없음** ← 퍼핀이 실패한 지점을 끊는 곳 |
| 2층 | 월 1회 | 저금통🐷 (현금) | ⭕ 있음 |

**퍼핀 도움말 Q4 원문:**
> "부모님과의 용돈계약을 통해 **학습보상 금액이 설정**되어 있어야 해요"
> "설정된 학습보상 금액이 **부모님의 퍼핀 잔액으로 충전**되어 있어야해요"

**→ 퍼핀은 아이의 학습이 부모의 지갑 상태에 종속됩니다. 1층을 별⭐로 만드는 것이 개선안의 본질입니다.**

```

15,000장 × 5초 = 약 21시간 GPU 실사용

❌ GPU 24시간 상시 가동:  730시간 → 월 70만원대
⭕ 비동기 처리 (필요할 때만):  21시간 → 월 2~3만원
```

**→ 비동기 처리가 비용을 15배 줄입니다. 그리고 "완성 알림"이 재방문 동기가 됩니다.**

**vs 외부 API**: 장당 과금이라 같은 볼륨에서 월 200만원대. **자체 호스팅이 규제·비용 양쪽에서 유리합니다.**

유림 매출 추정(월 216만원) 대비 GPU 비용은 **1.4%** → 비용은 병목이 아닙니다.

## ⚠️ GCP 무료 크레딧 사용 시 주의

```
① 무료 트라이얼 가입 ($300)
② 🔴 유료 계정으로 업그레이드  ← 트라이얼 상태에선 GPU 쿼터 요청 불가
③ 🔴 GPU 쿼터 증액 요청 (기본값 0) ← 승인 대기 필요
④ GPU 사용 — 남은 크레딧이 차감됨 ✅
```

**크레딧은 업그레이드 후에도 GPU에 적용됩니다.** 다만 ②③이 선행되어야 합니다.
