# PART 2. 법률 리스크 조사

## 2-0. 조사의 목적 — 이게 제일 중요

**법을 나열하는 게 목표가 아닙니다.** 그러면 점수 안 나옵니다.

프로젝트 가이드 원칙 5:
> 「도메인별 제약을 **마지막 체크리스트가 아니라 설계 입력값**으로 다룬다」

그리고 평가 기준:
> 「실행 가능성과 도메인 책임 **10점** — 산업별 법·윤리·운영 위험을 적정 깊이로 고려」

### 그래서 진짜 미션은 이겁니다

**1차 팀이 세운 「규제 방어선」이 실제로 유효한지 검증하기.**

1차 중간기획서에서 이미 이런 결정을 했습니다:

| 1차 결정 | 방어하려던 것 | 내가 검증할 질문 |
|---|---|---|
| 별⭐을 **현금 전환 불가 폐쇄형**으로 | 사행성 · 선불업 규제 | 정말 이러면 규제를 피하나? |
| 저축을 **실제 돈 안 받는 기록형**으로 | 선불업 등록 · 예치금 관리 | "기록형"의 경계는 어디까지? |
| 아바타 **꾸미기 아이템 판매 안 함** | 아동 현질 유도 | 판매 안 하면 정말 문제없나? |
| ~~버닝퀴즈에 저금통 못 걸게~~ | ~~사행성~~ | ❌ **버닝퀴즈 삭제로 무효** |
| 결제 주체를 **부모로** | 미성년자 계약 취소 | 부모 결제면 다 해결되나? |

**→ 이 5개 중 하나라도 "사실 그거 안 통해요"가 나오면 그게 발표에서 제일 강한 슬라이드가 됩니다.**

## 2-1. 개인정보 — 우리한테 제일 크게 걸리는 영역

| 법령 이름 | 확인할 것 | 왜 우리한테 걸리나 |
|---|---|---|
| **개인정보 보호법** | 만 14세 미만 아동의 개인정보 처리 시 **법정대리인 동의** 요건 / 아동에게 알기 쉬운 언어로 고지할 의무 | 주 사용자가 **7~14세**. 정면으로 걸림 |
| **개인정보 보호법 시행령** | 법정대리인 동의를 **어떤 방법으로** 받아야 하는지 | 온보딩 플로우 설계에 직결 |
| **개인정보위 「아동·청소년 개인정보 보호 가이드라인」** | 아동 대상 서비스 설계 권고사항 | 법은 아니지만 **실무 기준**. 감독기관 입장 |
| **개인정보 보호법 (민감정보 · 생체정보 관련 조항)** | 얼굴 이미지가 민감정보/생체인식정보에 해당하는지, 별도 동의 필요한지 | 🔥 **AI 아바타가 아이 사진 기반**. 여기가 최대 리스크 |

### 🔥 반드시 답을 찾아야 할 질문 3개

1. **아이 얼굴 사진으로 AI 아바타를 만드는 게 「생체인식정보 처리」인가?**
   - 단순 스타일 변환이면 아닐 수 있고, 얼굴 특징점을 추출·저장하면 해당될 수 있음
   - 해당되면 → **별도 동의 + 처리 제한**. PRD 요구사항이 통째로 바뀜
   - 검색어: `생체인식정보 개인정보보호법`, `얼굴 이미지 생체정보 여부 개인정보위`

2. **원본 사진을 저장하나, 아바타만 저장하나?**
   - 우리가 설계로 정할 수 있는 부분 → **"원본 즉시 폐기"를 요구사항으로** 넣으면 리스크 급감
   - 이게 PRD에 들어가면 "도메인 제약을 설계 입력값으로 다뤘다"는 근거가 됨

3. **법정대리인 동의를 어떻게 받나?**
   - 퍼핀은 부모-자녀 페어 구조라 이미 부모가 있음 → 우리도 그대로 쓸 수 있는지
   - 퍼핀 개인정보처리방침에 **실제 방법이 적혀 있을 것** → PART 1의 #2, #4에서 확인

**어디서 찾나**
- [개인정보보호위원회](https://pipc.go.kr) — 가이드라인·의결서·보도자료
- [개인정보포털](https://privacy.go.kr)
- 국가법령정보센터에서 「개인정보 보호법」 원문

## 2-2. 금융 — 별⭐과 저금통🐷이 걸리는 지점

| 법령 이름 | 확인할 것 | 왜 |
|---|---|---|
| **전자금융거래법** | **선불전자지급수단**의 정의 / 선불업자 **등록 의무**와 면제 요건 | 🔥 저금통🐷이 여기 걸리면 사업 자체가 흔들림 |
| **여신전문금융업법** | 미성년자 카드 발급 관련 | 퍼핀은 실물 카드 발급 중 |
| **금융소비자보호법** | 설명의무 / **광고 규제** / 부당권유 금지 | 아이 화면에 결제 유도 광고 = 1차에서 찾은 퍼핀 최대 불만 |
| **특정 금융거래정보의 보고 및 이용 등에 관한 법률** | 실명확인 · 자금세탁방지 | 미성년자 계좌 관련 |
| **민법 (미성년자 행위능력 조항)** | 미성년자 법률행위의 **취소권** | 아이가 결제하면 부모가 취소 가능 |
| **전자상거래법** | 청약철회 / 미성년자 계약 | 구독 결제 |

### 🔥 반드시 답을 찾아야 할 질문 3개

1. **「기록형 목표 저축」은 정말 선불업이 아닌가?**
   - 실제 돈을 받아 보관하면 → 선불전자지급수단 가능성
   - 우리가 "숫자만 기록하고 실제 이체는 부모가 직접"이면 → 회피 가능
   - **경계선이 어디인지**를 찾아야 함. 이게 PRD 정책 요구사항이 됨

2. **별⭐은 정말 규제 밖인가?**
   - 현금 전환 불가 + 외부 유통 불가 + 판매 안 함 → 이 3개가 다 충족돼야 안전할 가능성
   - 하나라도 깨지면? → **"별을 절대 판매하지 않는다"가 법적 요구사항**이 됨

3. **아이 화면에 뜨는 결제 유도 광고는 어떤 규제를 받나?**
   - 금융소비자보호법 광고 규제 + 아동 대상 광고 관련 기준
   - 1차에서 퍼핀 리뷰로 확인한 최대 불만 → **법적 근거까지 붙이면 개선안 설득력이 크게 올라감**

**어디서 찾나**
- [금융위원회](https://fsc.go.kr) — 보도자료·법령해석
- [금융감독원](https://fss.or.kr)
- [금융규제민원포털 (구 법령해석 회신사례)](https://better.fsc.go.kr) — 🔥 **"이런 서비스가 선불업인가요?" 질의응답 실제 사례가 있음**

## 2-3. 마이데이터 — 개인화 퀴즈의 전제조건

| 법령 이름 | 확인할 것 |
|---|---|
| **신용정보의 이용 및 보호에 관한 법률** | **본인신용정보관리업(마이데이터)** 허가 요건 |
| **금융위 마이데이터 관련 가이드라인** | 미성년자 가입 가능 여부와 조건 |

### 🔥 이게 우리 서비스의 **핵심 가정**입니다

핀프렌즈의 차별점이 **"소비 데이터 기반 개인화 퀴즈"** 인데,
**미성년자가 마이데이터에 가입할 수 없으면 이 기능이 성립하지 않습니다.**

**답을 찾아야 할 질문**
1. 미성년자도 마이데이터 서비스 가입이 되나? 몇 살부터?
2. 법정대리인 동의로 가능한가?
3. 안 된다면 **대안은?** → 마이데이터 없이 **우리 앱 안에서 발생한 소비 내역만** 쓰는 방식
   - 퍼핀은 자체 카드가 있으니 자체 결제 데이터는 있음 → 이걸로 대체 가능한지

> 💡 이 질문의 답이 「안 된다」면, 그건 실패가 아니라 **발표에서 제일 좋은 슬라이드**입니다.
> "우리는 이 제약을 발견했고, 그래서 설계를 이렇게 바꿨다" → 도메인 책임 10점 항목 직결

- 금융위 마이데이터 관련 보도자료
- 신용정보원

## 2-4. 사행성 · 게임 — ❌ **버닝퀴즈 삭제로 조사 종결**

> 버닝퀴즈를 없앴으므로 서비스에 **우연성 요소가 존재하지 않습니다.** 사행성은 "해당 없음"으로 정리합니다.
> 아래는 참고용으로만 남겨둡니다. **아바타 성장에 확률 요소를 넣을 경우에만** 다시 봅니다.

| 법령 이름 | 확인할 것 |
|---|---|
| **게임산업진흥에 관한 법률** | **확률형 아이템 확률 표시 의무** / 게임물 등급분류 대상 여부 |
| **사행행위 등 규제 및 처벌 특례법** | 사행성의 법적 정의 |
| **청소년 보호법** | 청소년 유해매체물 기준 |
