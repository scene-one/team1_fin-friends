# 조사

팀원별 **원자료와 조사 과정**입니다. 여기서 나온 결론이 [`기획산출물/`](../%EA%B8%B0%ED%9A%8D%EC%82%B0%EC%B6%9C%EB%AC%BC/) 의 사양으로 올라갑니다.

🔴 **이 폴더는 근거의 출처입니다.** 확정 사양을 찾는다면 `기획산출물/00-사양/` 으로 가세요.

**팀은 항상 4명입니다.** 3차에 **송유림 → 박수빈** 으로 한 자리가 바뀌었습니다.

| 사람 | 참여 | 맡은 것 | 어떻게 조사했나 | 폴더 |
|---|:-:|---|---|---|
| **박하영** | 1~3차 | 경쟁 · 리뷰 근거 | 리뷰 **921건 전수 수집·분류** · 퍼핀 공식 블로그 8건 원문 대조 · 학술 17편 · 경쟁 4사 | [`하영/`](%ED%95%98%EC%98%81/) |
| **신혜원** | 1~3차 | 고객 · 서비스 분석 | 이론 + 산업 비교 + 팀 직접사용 3계층 · 고객여정 2맵 · 교차산업 벤치마킹 | [`혜원/`](%ED%98%9C%EC%9B%90/) |
| **소병윤** | 1~3차 | 정책 · 법령 | 국가법령정보센터 원문 확인 · 퍼핀 공식 문서 4종 전문 확보 | [`병윤/`](%EB%B3%91%EC%9C%A4/) |
| **박수빈** | **3차** | 학습 설계 | 예적금 6종 실물 비교 · 초1~3 소비 패턴 실측 · 퀴즈 60문항 5단계 설계 | [`수빈/`](%EC%88%98%EB%B9%88/) |
| **송유림** | **1·2차** *(팀장)* | 시장 · 통합 | 공공통계 + 시장자료 + 퍼핀 실적 역산 · 마이데이터 적용가능성 검토 | [`유림/`](%EC%9C%A0%EB%A6%BC/) |

> 📌 **학습 콘텐츠**(난이도 5단계 · 지문 4종 · 퀴즈 60문항)는 **팀 공동 작업**입니다. 파일은 [`수빈/`](%EC%88%98%EB%B9%88/) 에 있습니다.
