# 초1~3 소비 패턴 실측 자료 (요일·장소·품목)

새싹프렌즈 1팀 · 2차 역기획 프로젝트 · **수빈** · 2026-09-01

> **왜 만들었나** 레포 전체를 확인한 결과 **아이 소비 패턴의 실측 자료가 0건**이었습니다. 「학교 앞 문구점에서 뽑기·팽이에 3,000원」 같은 서술은 전부 **✍️[합성 가설]**(페르소나 H2)이고, [`계획-카드-작성-트리거`](../../wiki/20-%EA%B8%B0%EB%8A%A5/%EA%B3%84%ED%9A%8D-%EC%B9%B4%EB%93%9C-%EC%9E%91%EC%84%B1-%ED%8A%B8%EB%A6%AC%EA%B1%B0.md)는 `sources: 0` · 전부 `[제안]` 등급입니다.
> **답하는 질문** 초1~3이 **언제(요일) · 어디서(장소) · 무엇을(품목) · 얼마나** 쓰는가
> **기준 사양** F8 = **「날짜 · 어디서 · 얼마까지」 3필드 건별 계획 카드** · 품목·업종 미수집 · ⭐ 판정은 금액만 *(2026-09-01 봉투형 폐기 후 확정)*

1. 🥇 **하나은행 「아이부자」가 요일까지 공개**하고 있습니다 — **토 > 일 > 금**, 화요일 최저.
2. 🔴 **그래서 「하교 시간대 조건부 알림」에 구멍이 하나 있습니다** — 소비가 **토·일에 몰리는데 주말엔 하교가 없습니다.** 작성 트리거에 **주말 경로가 비어 있습니다** (§4-1).

4. 🔴 **용돈 받는 날(1·10·25일)과 쓰는 날(주말)이 어긋납니다.**
5. 페르소나 H2의 **장소 비중이 과대**합니다(문구점 1위 → 실측 3위). 다만 **품목 서사(뽑기·팽이)는 지지**됩니다 — 무인문구점 매출의 **42%가 완구류**.
6. 📎 **PRD v0.3에 남은 정합성 하나** — F13 근거가 아직 *"F8이 업종을 받으므로 그대로 집계됨"* 인데, **F8은 이제 업종을 받지 않습니다** (§4-3).

# 4. 우리 설계에 바로 걸리는 것 5가지

## 4-1. 🔴 **작성 트리거에 「주말 경로」가 비어 있습니다**

[`계획-카드-작성-트리거`](../../wiki/20-%EA%B8%B0%EB%8A%A5/%EA%B3%84%ED%9A%8D-%EC%B9%B4%EB%93%9C-%EC%9E%91%EC%84%B1-%ED%8A%B8%EB%A6%AC%EA%B1%B0.md)의 채택안은 이렇습니다:

```
① 하교 시간대(부모 설정, 예 15:00~17:00)
   → ② 그날 아직 계획을 안 세웠을 때만 발동
      → ③ 출석 ⭐ 세션에도 같은 프롬프트를 이중화
```

**그런데 실측 소비는 토 > 일 > 금입니다. 주말엔 하교가 없습니다.**

| | 평일 | **주말** |
|---|---|---|
| 소비 빈도 | 낮음 *(화요일 최저)* | 🔑 **가장 높음 (토·일)** |
| 하교 시간대 트리거 | ✅ 작동 | 🔴 **발동 조건 자체가 없음** |
| 출석 ⭐ 이중화 | ✅ 작동 | 🟡 **앱을 열어야만 작동** |

> **즉 가장 많이 쓰는 이틀에 트리거가 출석 ⭐ 하나뿐입니다.** 그리고 출석은 「접속만으로 ⭐1」(S2)이라 **접속 자체가 담보되지 않습니다.**

**권장** — 주말은 시간대가 아니라 **다른 신호**로 잡아야 합니다. 후보 둘:
- **부모 발신** — 주말 외출 전 부모가 「오늘 계획 세우기」를 아이에게 보냄 *(H2 자영업 부모는 주말 근무라 어려울 수 있음 — C4에서 확인)*
- **금요일 저녁 1회** — 소비 3위인 금요일에 주말치를 미리 잡게 함 *(용돈 지급 주기 주 1회 51%와 맞물림)*

⚠️ 둘 다 `[제안]`입니다. **C4 인터뷰에 「주말에 아이가 언제 어디서 쓰는가」 문항을 넣는 것**이 선행입니다.

## 4-2. 🔴 용돈 받는 날과 쓰는 날이 어긋납니다

```
용돈 받는 날   1일 · 10일 · 25일   (자료 3)
소비하는 날    토 > 일 > 금        (자료 1)
```

월 1회 지급(49%) 가정에서는 **충전과 소비 사이에 최대 2주가 뜹니다.** 계획 카드는 건별이라 봉투형만큼 치명적이진 않지만, **「용돈 받은 날 = 앱을 여는 날」이라는 자연스러운 진입점이 소비일과 겹치지 않는다**는 뜻입니다.

> 🟢 **주 1회 지급(51%) 가정은 유리합니다** — 지급 주기가 짧아 진입점이 자주 옵니다. **β 8슬롯 모집 시 지급 주기를 스크리너에 넣어 대조**할 것을 권합니다.

## 4-3. 📎 PRD v0.3에 남은 정합성 하나

**F13(소비 내역) 근거가 아직 이렇게 적혀 있습니다:**

> *"H2의 최소 유지 조건 — 「어디서 얼마 썼는지, 그거 하나만」. **F8이 업종을 받으므로 그대로 집계됨**"*

🔴 **F8은 이제 업종을 받지 않습니다.** F13의 **업종별 집계는 이제 카드 승인 데이터의 업종 코드에서 직접** 와야 합니다.

**그래서 [`카드-업종-분류-MCC`](../../wiki/50-%EC%9D%B4%EB%A1%A0/%EC%B9%B4%EB%93%9C-%EC%97%85%EC%A2%85-%EB%B6%84%EB%A5%98-MCC.md)의 문제가 완전히 사라진 게 아닙니다** — **판정 경로에서는 빠졌지만 표시 경로에는 남아 있습니다.** 다만 성격이 달라집니다:

| | 판정용 *(과거)* | **표시용 *(현재 F13)*** |
|---|---|---|
| 틀렸을 때 | 🔴 **아이가 안 쓴 봉투에서 돈이 빠짐** | 🟡 부모 화면 집계가 조금 어긋남 |
| 요구 정확도 | ≥ 90% | **훨씬 낮아도 됨** |
| PG 뭉뚱그림 | 치명적 | 감수 가능 |

→ **표시용은 「기타」 비중이 높아도 무너지지 않습니다.** 이 구분을 F13 근거 문장에 넣어야 합니다.

## 4-4. 「어디서」 필드의 선택지 설계에 그대로 쓸 수 있습니다

F8이 3필드로 좁혀지면서 **「어디서」가 자유 입력인지 선택지인지**가 UI 과제로 남았습니다. 실측 순위가 그 선택지의 근거입니다.

| 우선순위 | 선택지 | 근거 |
|:-:|---|---|
| 1 | **편의점** | 세 자료 공통 1위 |
| 2 | **문구점** *(다이소·무인문구점 포함)* | 저학년 사용처 1위(60.1%) |
| 3 | **간식가게** *(떡볶이·분식)* | 자료 1 2위 |
| 4 | **그 밖** *(직접 적기)* | — |

> 🟢 **3탭 이내 완료**(작성 트리거 문서의 요구)와 맞습니다. 그리고 **판정에 안 쓰이므로 정확할 필요가 없습니다** — 아이가 기억을 붙잡는 표지일 뿐입니다.

| 현재 (✍️합성 가설) | 실측 | 판정 |
|---|---|:-:|
| *"학교 앞 문구점이 고정 동선"* | 문구점은 **3위**, 1위는 **편의점** | 🔴 **장소 비중 과대** |
| *"뽑기·팽이에 3,000원 소진"* | 무인문구점 **완구류 42%** · 1회 결제 **2,715원** | 🟢 **품목·금액 서사는 지지** |
| *"주 5,000원 현금"* | 저학년 월 20,000~32,000원 | 🟡 **주 5,000원 = 월 2만원** — 하단이지만 범위 안 |
| *"하교길"* | 소비는 **토·일** 집중 | 🔴 **요일 서사 미검증** |

→ **장소를 「편의점 + 문구점」으로 넓히고 「하교길」에 주말을 더하면** 실측과 맞습니다. 페인포인트(*"닷새 뒤 지갑 보고 안다"*)는 그대로 성립합니다.

## 4-6. β 모의 결제 시나리오의 근거가 생겼습니다

O8이 **제휴 없이 모의 결제로 β를 돌리기로** 했는데, 🔴 *"실제 가맹점 데이터가 없다"* 가 남은 문제였습니다. **이 자료가 모의 시나리오를 실제 동선으로 구성할 재료**입니다.

| 1회 금액 | 평균 **2,715원** | KB think |
