# 1. 4주제 = 4칸 그대로

v13 §9 확정 사항입니다. **새 주제를 만들지 않습니다.**

| 영역 | 표기 | 한 줄 설명 *(법정 의무 고지 — 개인정보보호법 §22조의2 ③)* |
|---|---|---|
| 소득 | 💰 **벌기** | 일하면 돈이 생겨요 |
| 소비 | 🛒 **잘 쓰기** | 진짜 필요한 걸까? |
| 저축 | 🐷 **모으기** | 안 쓰고 두면 쌓여요 |
| 이자·복리 | 🌱 **불리기** | 모아두면 저절로 늘어나요 |

> **학습 1회 = 한 칸의 한 대목**으로 셉니다. v13 §3-1 나무 성장 기준표가 「금융 콘텐츠 학습」을 **칸별로** 세기 때문입니다(열매나무 = 칸당 15회).

# 2. 지문 구조 — 「1편 = 한 이야기 = 4칸을 모두 지나감」

```
지문 1편  (하나의 이야기 · 주인공 지호)
├─ 💰 벌기    대목 2개  →  학습 2회  →  퀴즈 3문항
├─ 🛒 잘 쓰기 대목 2개  →  학습 2회  →  퀴즈 3문항
├─ 🐷 모으기  대목 1개  →  학습 1회  →  퀴즈 2문항
└─ 🌱 불리기  대목 1개  →  학습 1회  →  퀴즈 2문항
                 = 6대목   = 학습 6회   = 퀴즈 10문항
```

**왜 4칸을 한 이야기로 묶나** — v13 §7-1의 일일 한도가 **분야별 1개·하루 총 4개**입니다. 4문항이 서로 다른 상황이면 저학년에게 **맥락 전환 부담이 4배**가 됩니다.

**왜 대목 수가 칸마다 다른가** — 문항 배분(벌기3·잘 쓰기3·모으기2·불리기2)에 맞췄습니다. 「모으기」와 「불리기」는 실천 경로가 좁아(위시리스트 / 예·적금) 대목을 늘려도 소재가 반복됩니다.

# 3. 지문 4종 — 재사용 지도

| 지문 | 제목 | 쓰이는 난이도 | 커버 문항 | 형식 |
|---|---|---|---|---|
| **저** | 「**지호의 200원**」 | **1단계 + 2단계** | 20 | 네컷만화 + 음성 |
| **중** | 「**지호의 문구점 날**」 | **3단계** | 10 | 글 + 삽화 |
| **고** | 「**지호의 용돈 기입장**」 | **4단계 + 5단계 기본** | 20 | 글 + 표 |
| **심화** 🆕 | 「**지호의 1년**」 | **5단계 심화** | 10 | 글 + 표 + 그래프 |

**재사용 방식** — 저 지문 1편이 **1단계와 2단계에 그대로** 쓰입니다. **그림도 이야기도 같고 문항의 숫자만 바뀝니다.** 고 지문도 4단계와 5단계 기본에 같은 방식으로 쓰입니다.

> ⚠️ **당초 「지문 3종」에서 4종으로 늘었습니다.** 5단계 심화(표준교재 기준)가 다루는 **물가·소득 4종·투자**는 「용돈 기입장」 이야기에 들어가지 않습니다. 늘어난 1종은 심화 세트를 넣기로 한 결정의 비용입니다.

# 4. 지문 ↔ 퀴즈 1:1 연결표

> 각 대목의 **「근거 문장」이 오답 시 「이야기 다시 읽기」 화면에 그대로 뜹니다.** 만화·글 전체가 아니라 **문장 하나만** 크게 띄웁니다.

| **①** | 💰 벌기 | **이웃의 수입표** — 옆집 윤서네 한 달 수입: 할아버지 상가 임대료 100만, 할머니 연금 50만, 어머니 월급 350만, 아버지 가게 120만. 사진관 아저씨는 사진관을 하며 번 돈을 저축해 이자도 받는다 | 「재산을 빌려주고 받는 돈 = **재산 소득**」<br>「가게를 하며 벌면 사업 소득, 이자를 받으면 재산 소득 — **두 종류**예요.」 | **5-11** · **5-12** |
| **②** | 🛒 잘 쓰기 A | **다 가질 수는 없어요** — 갖고 싶은 것에 비해 돈도 시간도 늘 모자란다 | 「양이 부족해 귀한 것을 **희소성**이라고 해요.」<br>「그래서 우리는 끊임없이 골라야 해요.」 | **5-13** |
| **③** | 🛒 잘 쓰기 B | **내 카드는 어떤 카드일까** — 나중에 갚는 신용카드, 통장에서 바로 빠지는 체크카드, 미리 넣어 둔 금액 안에서만 쓰는 카드. 지호는 지갑을 사려고 인터넷의 지갑을 전부 찾아보다 사흘이 지나도 못 골랐다 | 「충전해서 그 금액 안에서만 쓰는 카드 = **선불카드**」<br>「정보가 너무 많으면 오히려 헷갈려요.」 | **5-14** · **5-15** |
| **④** | 🐷 모으기 | **약속한 기간** — 3년짜리 정기 예금을 1년 만에 찾으려 하자 은행원이 말한다. *"원금은 드리지만 약속한 이자는 다 드릴 수 없어요."* 통장은 보통예금·정기적금·정기예금 세 가지 | 「기간이 남았는데 찾으면 약속한 이자를 다 못 받아요.」<br>「매달 꾸준히 넣어 큰돈을 만드는 건 **정기 적금**이에요.」 | **5-16** · **5-17** |
| **⑤** | 🌱 불리기 A | **만 원이 만 원이 아니야** — 할아버지의 1980년 이야기. 삼겹살·수박·상추·쌀을 다 합쳐 5,067원이라 만 원으로 살 수 있었는데, 2020년엔 36,279원이라 못 산다. 5년 전 만 원으로 담던 간식도 올해는 못 담는다 | 「1980년엔 만 원으로 살 수 있었어요.」<br>「2020년엔 만 원으로 못 사요.」<br>「물가가 오르면 같은 돈으로 살 수 있는 양이 줄어요.」 | **5-18** · **5-19** |
| **⑥** | 🌱 불리기 B | **불려도 잃을 수 있어요** — 그냥 둔 돈은 가치가 떨어지니 불려야 한다. 저축은 안전하지만 이자가 많지 않고, 투자는 더 늘 수도 **줄어들 수도** 있다 | 「투자는 늘 수도 있고 줄 수도 있어요.」<br>「저축과 달리 투자는 돈을 보장해 주지 않아요.」 | **5-20** |

> ⚠️ 대목 ⑥은 **개념·위험 이해까지만**입니다. v13 §14는 「불리기」에 **모의투자를 넣을지 미결**로 두었고(퍼핀 클론 위험), §6-2는 예적금도 **비교·선택 경험까지만** 제공해 중개업을 회피합니다(P-20).

# 6. 실제 제작 물량

## 6-1. 한 주기에 필요한 지문 편수

v13 §3-1 나무 성장 기준 — 열매나무까지 **칸당 「금융 콘텐츠 학습」 15회**.

```
지문 1편 = 벌기 2회 · 잘 쓰기 2회 · 모으기 1회 · 불리기 1회

가장 빡빡한 칸(모으기·불리기)이 15회를 채우려면  →  지문 15편
그때 벌기·잘 쓰기는 30회가 되어 여유가 생김 (요구치 15회)
```

**한 주기 = 지문 15편.** 벌기·잘 쓰기·모으기는 **매달 초기화**되므로 이것이 **월 단위 물량**입니다.

## 6-2. 재사용으로 줄어드는 양

| | 지문 편수 |
|---|---|
| 재사용 없이 난이도 슬롯 6개(1·2·3·4·5기본·5심화)를 각각 만들면 | 15 × 6 = **90편** |
| **지문 4종 재사용 구조** | 15 × 4 = **60편** |
| **절감** | **33%** |

**삽화 기준으로는 더 큽니다.** 저 지문의 네컷만화는 1단계와 2단계가 **완전히 같은 그림**이고, 고 지문도 4단계·5단계 기본이 **표의 숫자만** 다릅니다. → **삽화 자산은 4벌이면 6개 슬롯을 덮습니다.**

## 6-3. MVP 범위

PRD **E4 검증 = 프로토타입 1~2주 관찰**. 2주면 칸당 학습이 최대 14회이므로:

| | |
|---|---|
| **MVP 필요량** | 지문 **7편** (2주치) |
| **먼저 만들 난이도** | **3단계(중 지문)부터** — 기본값이고 부모 선택이 몰릴 가능성이 큼 |
| **그다음** | 1·5단계 → 2·4단계. 부모의 실제 난이도 선택 분포를 본 뒤 채웁니다 |
| **지금 있는 것** | 저 지문 6대목 중 **4대목이 이미 실물로 그려져 있음** ([`샘플_네컷만화_퀴즈.html`](샘플_네컷만화_퀴즈.html)) |

# 7. 남은 결정 — 보류한 「1번」

이 설계안은 **형식과 무관하게** 성립하지만, 실제 제작에 들어가려면 다음이 정해져야 합니다.

| 질문 | 왜 지금은 못 정하나 |
|---|---|
| **학습 1회분의 분량** — 만화 몇 컷 / 글 몇 문장 / 영상 몇 초 | 1단계 사양(1문장 ≤ 12자 · 네컷만화)은 정해져 있으나 **3·4·5단계의 분량 기준이 없습니다** |
| **텍스트·영상·만화를 언제 무엇으로** (v13 §8) | 영상은 제작 원가가 만화·텍스트와 자릿수가 다릅니다. **난이도별로 형식을 고정할지, 대목별로 섞을지**가 원가를 좌우합니다 |
| **매달 초기화되는데 같은 지문을 다시 쓰나** | v13 §14 미결 — *"매달 조건이 같은가, 올라가는가"*. 같은 지문을 반복하면 **두 달째부터 지루해지고**, 매달 새로 만들면 **연 180편**이 됩니다 |

> 🔴 마지막 항목이 가장 큽니다. **월 15편 × 4종 = 60편이 「한 번 만들면 끝」인지 「매달 새로」인지에 따라 연간 제작량이 60편과 720편으로 갈립니다.** v13 §14가 미결로 남긴 난이도 곡선 문제와 같은 뿌리입니다.
