> **리뷰 대상** `PRD_핀프렌즈_v0_1.md` (726줄 · 2026-08-21)
> **리뷰 범위** 5개 체크리스트 — Outcome–KPI 연계 / AC 적절성 / NFR / Differential Value / Proof

## 2. 🔧 챕터/파트별 수정 방향

> 우선순위 = 심각도 × 영향범위. 동점은 문서 순서.

|:-:|:-:|---|---|---|
| **6** | **D1** | 북극성 WPA 분모 미정의 + 분자에 MVP 밖 경로 2종 포함 | §1-3 | **조작적 정의**(분자·분모·제외 규칙) 명시 · **WPA-v1(MVP 3종) / WPA-v2(개통 후 5종)** 로 분리하고 시계열 단절 표기 |
| **6** | **D2** | n=8에 `≥70%` — 정수 경계 불명확 · %와 분수 혼용 | §3 · §8-2 | 인터뷰 지표는 **전부 정수 분수(k/8)** 로 통일 + **환산표** 제공 |
| **6** | **D3** | 통과선·실패선 사이 회색지대 미정의 | §1-1 · §8-2 | **3구간 판정(PASS / HOLD / FAIL)** + HOLD 시 **표본 +4 재판정, 2회 연속 HOLD = FAIL** 규칙 |
| **6** | **D4** | AC에 예외·실패 케이스 0개 | §3 전체 | 스토리마다 **AC-E(예외) 최소 1개** 추가. 🔴 특히 **US-6의 스펙 공백**(부모 거절 · 주기 초기화 이후 소급 귀속)을 정의 |
| **6** | **D5** | 성능·가용성 `⬜ 미정` → 테스트 불가 | §5-2 | **잠정 상한(provisional ceiling) + 유도 근거 + 재설정 트리거** 로 전환. 값을 확정하지 않고도 **테스트 대상은 존재하게** 만든다 |
| **4** | **D7** | Differential 4축 중 수치 비교 1축 | §8-3 | ①을 **정량화**(승급 필요 최소 실천 횟수 · 실천 0건으로 도달 가능한 최대 단계) · ③의 **N을 확정** · 퍼핀 소요 측정 방법 병기 |
| **4** | **D8** | Proof 5행이 실험 미연결 | §9-1 | 인용형 주장도 **우리 제품에서의 재현 검증**으로 연결 — **E10(행동 전이 종단) · E11(경쟁사 재확인) 신설** |
| **2** | **D6** | 알림 후 대응 미정의 | §5-5 | **수신자 · 대응 SLA · 에스컬레이션** 3열 추가 |
| **2** | **D10** | AC 판정 rubric 없음 | §3 서두 | **코딩 규칙 + 이중 코더 일치도(Cohen's κ ≥ 0.6)** + 불일치 시 제3자 판정 |
| **2** | **D9** | 측정 경로가 이벤트 스펙까지 안 내려감 | §1-2 | **이벤트 명세표**(이벤트명·필수 필드·발생 시점) 신설 |
| **1** | **D11** | 수익 KPI 목표·방법 둘 다 없음 | §1-3 | 다른 `⬜ 미정` 항목과 같은 **확정 방법**을 병기 |

**수정하지 않기로 한 것 1건**

| 관찰 | 왜 두는가 |
|---|---|
| O3(부모–자녀 대화 월 2회)의 유일한 측정 수단이 **자기보고** | 대화는 인앱에서 관측할 수 없습니다. 대체 수단을 만들면 **없는 계측을 있는 척하게** 되므로, **「자기보고 한계」를 명시하고 보조 지표로 격하**하는 선까지만 수정합니다(§1-3 반영) |

| `onboarding_step` | 온보딩 단계 진입/완료/이탈 | `parent_id` `step(1~5)` `state` `resumed(bool)` | US-8 퍼널 · 3단계 이탈률 |
| `consent_gate_blocked` | 동의 미완 상태 아이 진입 차단 | `parent_id` `attempted_at` | 🔴 규제 알림(>0건 즉시) |

> **적재 규칙** — 모든 이벤트에 `idempotency_key`(중복 방지) · `client_ts` / `server_ts`(오프라인 보정) 필수. **오프라인 발생 이벤트는 `client_ts` 기준으로 주차(week)에 귀속**합니다.

## 🔧 §1-3 (교체) — 북극성 KPI 조작적 정의 · 3구간 판정

> ## ⭐ 북극성 KPI — **WPA (Weekly Practiced Active)**

### 🆕 조작적 정의

```
WPA(주차 w) = 분자 / 분모

분자 — 주차 w 동안 「실천 트리거」로 ⭐를 1회 이상 받은 아동 수
       (practice_credited 이벤트가 1건 이상 있는 distinct child_id)

분모 — 주차 w 「활성 아동」 수
       = 주차 w 시작 시점에 아래 3조건을 모두 만족하는 아동
         ① 보호자 법정대리인 동의 완료 (P-05)
         ② 아이 계정 생성 후 7일 경과   ← 온보딩 ⭐가 실천을 과대계상하는 것을 차단
         ③ 직전 28일 내 앱 세션 1회 이상 ← 완전 이탈 계정 제외

주차 기준 — ISO 주(월~일) · KST
```

| 버전 | 「실천 트리거」 범위 | 언제 쓰는가 |
|:-:|---|---|
| 🔴 **WPA-v1** *(MVP 기준)* | **트리거 4** 미션 승인 · **5** 소비 회고 · **6** 위시리스트 달성 — **3종** | v0.1 MVP 전 기간 |
| **WPA-v2** *(개통 후)* | v1 + **트리거 7·8** 예적금(F15) + **F19** 사전 개입 — **5종** | F15·F19 개통 시점부터 |

> 🔴 **원문의 정의는 5종을 분자에 넣었으나, 그중 예적금(F15 Could)과 사전 개입(F19 Should)은 MVP에 없습니다.** 정의와 구현이 어긋나면 **WPA가 구조적으로 3종 상한에 묶인 것을 성능 문제로 오독**하게 됩니다.
> **WPA-v2 전환 시 시계열을 단절 표기**하고, 전환 후 4주간은 v1·v2를 **병기**합니다.

## 🔧 §3 서두 (신설) — 판정 규칙

### 🆕 3-0. AC 판정 규칙 — 표본 · 임계치 · 코딩

**① 정수 임계치 환산 (n=8 인터뷰 지표)**

> 🔴 **비율 표기를 쓰지 않습니다.** n=8에서 `≥70%`는 5.6명이라 정수 경계가 불명확합니다. **모든 인터뷰 AC는 `k/8` 로 표기**합니다.

| 원문 표기 | 🔧 정수 판정 | 실제 비율 |
|---|:-:|:-:|
| ≥ 70% | **≥ 6/8** | 75% |
| ≥ 60% | **≥ 5/8** | 62.5% |
| ≤ 30% | **≤ 2/8** | 25% |
| ≤ 25% | **≤ 2/8** | 25% |

**② 코딩 규칙 (rubric)**

| 판정 대상 | 성공 조건 | 코딩 방식 |
|---|---|---|
| **「변화 회상」 성공** | 응답에 **① 비교 시점(지난달·지난주 등) ② 변화 방향(늘었다·줄었다·자랐다) ③ 대상(칸 또는 행동)** 세 요소가 모두 포함 | 진행자 외 **코더 2인 독립 코딩** |
| **「실천」 도달** | *"실천"·"실제로 했다"·"참았다"·"미션"* 중 하나를 **진행자 개입 없이** 발화 | 동일 |
| **오귀인 발화** | 정체 원인을 **아이의 능력·의지**로 귀속(*"애가 안 해서"*) | 동일 |
| **앱 불신 발화** | 정체 원인을 **앱의 신뢰성**으로 귀속(*"앱을 안 믿게 된다"*) | 동일 |

- **일치도 기준** — 두 코더의 **Cohen's κ ≥ 0.6**. 미달 시 코딩 규칙을 조정하고 **전 표본 재코딩**
- **불일치 항목** — 제3자(리뷰어)가 판정하고 사유를 기록
- **5초 노출 통제** — 타이머 + 화면 덮기 도구 사용. **노출 오차 ±0.5초 초과 세션은 표본에서 제외**하고 제외 건수를 보고

**③ 표본 미확보 시 판정 규칙**

| 확보 표본 | 판정 |
|:-:|---|
| **n ≥ 8** | 정상 판정 |
| **5 ≤ n < 8** | ⚠️ **HOLD 고정** — PASS 판정을 내리지 않음. 비율 환산 금지 |
| **n < 5** | **판정 불가** — 실험 미실시로 기록 |

## 🔧 §5-2 (교체) — 성능·신뢰성: 잠정 상한 + 재설정 트리거

> 🔴 **원문은 전부 `⬜ 미정`이라 테스트 대상이 존재하지 않았습니다.** 확정치를 지어내지 않으면서 **테스트는 가능하게** 하려면, **잠정 상한(provisional ceiling)** 과 **재설정 트리거**를 둡니다.
