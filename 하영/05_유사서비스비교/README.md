# ② 서비스별 핵심 차별점 — 왜 그렇게 설계했나

## gohenry — **"교육 표준에 맞춘 커리큘럼"이 상품**

**[사실]** 교사·금융 전문가와 개발하고 **미국·영국 연령별 교육 가이드라인에 매핑**했다고 명시합니다.
**[사실]** 레벨이 **"연령·실력·자신감(age, skills, confidence)에 맞춰 잠금 해제·조정"** 됩니다.
**[사실]** 부모가 **미션을 직접 해볼 수 있고**, 완료할 때마다 **보상을 줄지 선택**할 수 있습니다.

**[해석]** 이 설계는 **부모를 "결제자"가 아니라 "학습 동반자"로 둡니다.** 부모가 같은 콘텐츠를 경험하면 아이가 뭘 배우는지 설명 없이도 알게 됩니다. 학습 확인을 **화면(리포트)이 아니라 경험으로** 푼 방식입니다.

## Greenlight — **보상을 4층으로 쪼갠 설계**

**[사실]** 챌린지를 완료하면 **Greenlight Coins, XP, stars**를 받고, 별도로 **배지**를 얻습니다.
**[사실]** 커리큘럼이 **Jump$tart Coalition·Council for Economic Education의 K-12 개인금융교육 국가표준을 넘어선다**고 표기합니다.
**[사실]** Coins는 "현금이나 현금성 자산이 아니며, 교환 전에는 현금 가치가 없다"고 약관에 명시돼 있습니다.

**[해석]** 보상을 **화폐(Coins) / 누적 진행(XP) / 성과 평가(stars) / 성취 증표(배지)** 로 분리했습니다. 하나의 보상이 네 가지 역할을 겸하지 않게 한 구조입니다. 4단계 연구(S3)가 지적한 *"포인트가 진행 표시기로만 작동한다"* 는 한계를 **역할 분리로 우회**하려는 설계로 읽힙니다.

⚠️ **미확인** — 검색 단계에서 *"정답률(percentage of correct answers)에 따라 차등 지급"* 이라는 표현을 봤으나, **공식 페이지·기사 원문에서 확인하지 못했습니다.** 사실로 쓰지 마세요.

## 아이쿠카 — **학습보다 안심(모니터링)이 중심**

**[사실]** 공식 사이트가 강조하는 부모 기능은 **소비 내역·잔액·한도·실시간 위치**입니다. **학습 확인 기능은 언급되지 않습니다.**
**[사실]** 교육 콘텐츠는 "**매일 업데이트되는 쿠카뉴스로 문해력과 시사·경제 상식까지**"입니다.

**[해석]** 부모의 구매 동기를 **"교육"이 아니라 "안심"** 으로 잡은 설계로 보입니다. 학습은 부가 가치입니다.

## 아이부자 — **은행이 만든 미션·습관 앱**

**[사실]** 하나은행이 운영합니다. 매일 퀴즈 3개, **주식 퀴즈**, 집안일 미션(**직접 생성 가능**), 기분 기록·만보기.
**[사실]** 커리큘럼·레벨·부모 학습 확인 기능은 앱 설명에 **없습니다.**

**[해석]** 학습 체계보다 **일일 접속 습관(데일리 액션)** 에 무게를 둔 설계로 보입니다. 은행 입장에서는 미래 고객 접점 확보가 목적일 수 있습니다 — **[가정]**.

## 🔴 이 표에서 읽어야 할 것

**중간 구간(`성취/성장`)이 비어 있는 것은 퍼핀만의 문제가 아닙니다.** 국내 3사(퍼핀·아이쿠카·아이부자) 모두 공개 자료에서 이 구간이 확인되지 않습니다.

반면 **해외 2개는 이 구간을 명시적으로 채웁니다** — gohenry는 레벨 해제, Greenlight는 XP·stars·배지.

**[추론]** 이건 국내 시장이 **"용돈카드 + 부가 학습"** 으로 출발했고, 해외는 **"금융교육 + 카드"** 로 출발한 차이일 수 있습니다. 다만 각 사의 창업 의도는 확인하지 않았으므로 **[가정]** 입니다.

🔴 **퍼핀만 오답에도 보상이 나갑니다.** 다른 4개 서비스에서 오답 보상 규칙은 **공개 자료에 없어 비교 불가**이지만, 최소한 퍼핀만 이 규칙을 **명시적으로 확인**했습니다(나무위키·리뷰·개발사 답변).

# ⑥ 단순 복제가 아닌 차별화 기회

베끼면 안 되는 이유부터 — **2차 프로젝트 배점의 핵심이 "화면을 베끼지 말고 원리를 가져오는 것"** 입니다.

## 🟢 기회 1 — **소비 데이터와 학습을 잇는다** (퍼핀만 가능)

**[사실]** 퍼핀은 실물 카드로 아이의 **실제 소비 내역**을 갖고 있습니다.
**[사실]** 확인한 범위에서 **어느 서비스도 "실제 소비 내역"과 "학습 콘텐츠"를 연결하지 않습니다.** gohenry·Greenlight도 카드가 있지만 공개 자료상 학습과 분리돼 있습니다.

**[해석]** *"네가 지난주 편의점에서 쓴 3,200원"* 과 *"예산 개념 퀴즈"* 를 잇는 것은 **퍼핀의 자산으로만 가능한 설계**입니다. 4단계 S1이 말한 **"서사와 맥락이 조절변수"** 라는 발견과도 맞습니다 — 자기 돈 이야기보다 강한 서사는 없습니다.

⚠️ **[가정]** 타사가 정말 안 하는지는 **앱을 직접 봐야 확정**됩니다. 공개 자료에 없을 뿐일 수 있습니다.

## 🟢 기회 2 — **"금융 순도"를 지표로 만든다**

**[사실]** 국내 3사(퍼핀·아이쿠카·아이부자) 모두 금융에 비금융을 섞습니다. 해외 2개는 전부 금융입니다.

**[해석]** 국내에서 **"우리는 금융만 가르친다"** 또는 **"금융을 얼마나 배웠는지 따로 보여준다"** 는 포지션은 **아직 비어 있습니다.** 이건 기능 복제가 아니라 **범주 선점**입니다.

⚠️ **[위험]** 4단계에서 확인했듯 **부모가 그걸 원하는지는 검증되지 않았습니다.** 유일한 관련 리뷰는 오히려 영단어를 요구했습니다.

## 🟡 기회 3 — **오답을 학습으로 되돌리는 구조**

**[사실]** 퍼핀은 오답에도 반액을 주고 재시도가 가능합니다. 퍼핀 스스로 "의도와 다르게 작동하는 케이스"로 인정했습니다.
**[사실]** 타사의 오답 처리 규칙은 공개 자료에 없어 **비교할 수 없습니다.**

**[해석]** 이건 **경쟁사를 따라가는 게 아니라 퍼핀이 이미 인정한 문제를 푸는 것**이라 차별화보다 **정상화**에 가깝습니다. 다만 3단계 R1(투입 보상이 효과를 내려면 실제로 학습해야 함)의 조건을 회복시키는 지점입니다.

# 🔴 이 조사로 주장할 수 없는 것

- ❌ "gohenry·Greenlight가 퍼핀보다 교육적으로 우수하다" → **효과가 검증된 서비스는 하나도 없습니다.** 설계 차이만 확인했습니다
- ❌ "Greenlight는 정답률에 따라 별을 준다" → **원문에서 확인 못 했습니다**
- ❌ "아이쿠카·아이부자는 학습 확인 기능이 없다" → **공개 자료에 없을 뿐**, 없다는 증거가 아닙니다
- ❌ "퍼핀만 소비-학습을 연결 안 한다" → 타사 앱을 직접 못 봤습니다
- ❌ **"따라서 별을 이렇게 만들자"** → 기능 설계는 이 단계 범위 밖 (4단계 판단 유지)

# 🟢 이 조사로 말할 수 있는 것

> **해외 2개(gohenry·Greenlight)는 교육 콘텐츠 주제가 전부 금융이고 외부 교육 표준에 매핑돼 있으며, 보상을 여러 층으로 나누고, 부모가 학습에 관여하는 통로를 갖고 있다.**
> **국내 3개(퍼핀·아이쿠카·아이부자)는 금융에 비금융을 섞고, 외부 표준 매핑이 없으며, `학습 → 성취/성장` 구간이 공개 자료에서 확인되지 않는다.**
>
> **즉 퍼핀의 공백은 퍼핀만의 결함이 아니라 국내 시장의 공통 공백이고, 그래서 선점 가능한 자리다.**
