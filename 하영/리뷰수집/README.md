## ⚠️ 데이터 한계 — 이걸 모르고 쓰면 분석이 틀립니다

팀 규칙대로 **사실 / 추론 / 가정** 라벨을 붙였습니다.

### 1. 별점만 남긴 사용자는 안 들어있습니다 🔴 **가장 중요**

- **[사실]** 구글 공개 기준 평점 **1,158개**, 본문 있는 리뷰 **920건** → **약 237명은 글 없이 별점만** 남겼습니다.
- **[사실]** 구글 API는 본문 있는 리뷰만 돌려줍니다. 그래서 237건은 확보 불가입니다.
- **[사실]** 이 데이터셋 평균 평점은 **4.57점**인데, 구글에 표시된 앱 전체 평점은 **4.02점**입니다.
- **[추론]** 0.55점 차이는 **글 없이 낮은 별점만 남긴 사용자**가 빠졌기 때문입니다.
- 👉 **"리뷰 78.9%가 5점이니 만족도가 높다"고 쓰면 안 됩니다.** 이 데이터셋은 긍정 쪽으로 치우쳐 있고, 불만 사용자의 상당수가 애초에 글을 안 씁니다.

### 2. 안드로이드만 있습니다

- **[사실]** Google Play만 수집했습니다. iOS App Store 리뷰는 없습니다.
- **[가정]** iOS 사용자 비중과 불만 양상이 다를 수 있습니다 — 확인 안 됨.

### 3. 오래된 리뷰가 많습니다

- **[사실]** 리뷰의 절반 이상이 2023~2024년, 앱 버전은 23.x 대입니다. 현재는 26.7.5.
- **[추론]** 2023년 리뷰의 불만이 지금도 남아있다고 단정할 수 없습니다. 이미 고쳐졌을 수 있습니다.
- 👉 **8/19 가치사슬·KSF에 쓸 때는 최근 1년(2025-08~2026-08) 리뷰를 따로 나눠서 보세요.** 해당 구간은 **83건**, 그중 1~3점이 **34건**입니다.

### 4. 리뷰가 특정 날짜에 몰려 있습니다

- **[사실]** 2023-08-08~10 사흘에 160건, 2023-04-25 하루에 65건.
- **[가정]** 이벤트·보상으로 리뷰를 유도했을 가능성이 있습니다. 확인된 바 없습니다.
- 👉 이 구간 리뷰는 **자발적 의견이 아닐 수 있으니** 페인포인트 근거로 쓸 때 날짜를 같이 확인하세요.

### 5. 구글이 보여주는 만큼만 받았습니다

- **[사실]** 최신순으로 6페이지를 받고 빈 응답에서 멈췄습니다. 강제로 끊은 게 아니라 **구글이 더 안 준 것**입니다.
- **[사실]** 삭제·비공개 처리된 리뷰는 애초에 조회되지 않습니다.

### 6. 1차의 918건과 같은 데이터가 아닙니다

- **[사실]** 1차 918건 / 이번 921건 — 숫자는 비슷하지만 **수집 시점이 다르므로 동일 집합이라는 보장이 없습니다.**
- 👉 1차 결과와 숫자가 안 맞아도 정상입니다. 이번 데이터를 기준으로 다시 세는 게 맞습니다.

## 🔧 다시 수집하는 법

### 설치 (처음 한 번)

```bash
python -m pip install google-play-scraper
```

- 필요 환경: **Python 3.8 이상** (작성 환경: 3.12.10)
- 사용 패키지: **google-play-scraper 1.2.7** — 비공식 라이브러리, API 키 불필요
- 그 외는 파이썬 기본 라이브러리만 씁니다 (csv, json, hashlib …)

### 실행

```bash
cd 하영/리뷰수집
python collect_reviews.py
```

약 10초 걸리고, 이 폴더에 파일 4개를 덮어씁니다.

### 옵션

| 명령 | 설명 |
|---|---|
| `python collect_reviews.py --max 300` | 300건만 (테스트용) |
| `python collect_reviews.py --out ./data` | 다른 폴더에 저장 |
| `python collect_reviews.py --batch 100` | 1회 요청 건수 조정 (차단될 때) |

### 잘 안 될 때

| 증상 | 원인 / 해결 |
|---|---|
| `ModuleNotFoundError` | 위 설치 명령을 안 돌렸습니다 |
| 한글이 `???` 로 깨짐 | 윈도우 콘솔 문제입니다. 파일 자체는 멀쩡하니 CSV를 열어서 확인하세요 |
| 요청 실패 후 재시도 메시지 | 구글의 일시적 차단입니다. 스크립트가 알아서 3회까지 재시도합니다 |
| 계속 실패 | 10분쯤 뒤에 다시 실행하거나 `--batch 100` 으로 낮추세요 |
