### PRD — 이거만 있으면 됨

| 항목 | 최소 이 정도 |
|---|---|
| 목적 | 누구의 어떤 문제를 풀고 뭘 만드나 |
| 범위 | 핵심 기능 1개 + 보조 0~2개, **안 하는 것도 적기** |
| 시나리오 | 잘 되는 흐름 + 실패했을 때 흐름 |
| 요구사항 | 꼭 필요한 것 5~10개, 우선순위 |
| **합격 기준** | 각 요구사항이 「됐다/안 됐다」를 뭘로 판단하나 |
| 정책 조건 | 개인정보·보안·권한 중 해당되는 것만 |
| 지표 | 병윤이 만든 지표 연결 |

⚠️ **모든 요구사항이 「고객 가치」 또는 「법적 제약」 둘 중 하나로 설명돼야** 합니다 (배점 15점).
