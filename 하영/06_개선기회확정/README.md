# ③ 해결해야 할 핵심 문제

## 두 페인포인트는 하나의 구조적 공백에서 나옵니다

퍼핀의 학습 흐름을 5단계에 걸쳐 확인한 결과입니다.

```
[학습] ──→ [문제풀이] ──→ [보상]  ······→  [성취/성장]
  ✅          ✅            ✅              ❌ 확인된 장치 없음
 2,000+     매일 5문제     즉시 지급           ↑
 콘텐츠                   (오답도 반액)     여기가 비어 있다
```

이 공백을 **아이 쪽에서 보면** *"보상은 받는데 내가 뭘 얼마나 알게 됐는지 모르겠다"* → **아이 페인포인트**
이 공백을 **부모 쪽에서 보면** *"우리 애가 금융을 얼마나 배웠는지 모르겠다"* → **부모 페인포인트**

**같은 공백의 양면입니다.** 페인포인트는 그대로 두되, 해결은 한 곳을 겨냥할 수 있습니다.

## 여기에 두 번째 문제가 겹칩니다

설령 누적을 보여준다 해도, **그 안에 무엇이 쌓였는지가 뒤섞여 있습니다.**

| 퍼핀이 광고하는 것 | 실제 구성 |
|---|---|
| "15단계 **경제금융학습** 커리큘럼"(E2) | 과목 7개 중 4개 비금융(E1) |
| "2000+개 **경제금융퀴즈**"(공식 사이트) | 월간 퀴즈 4개 중 3개 비금융 — 사자성어·수능 비문학 어휘(E14) |
| 유료 멤버십 학습 콘텐츠 | **"교과와 연계된 다양한 배경지식"**(E3) |

**즉 "금융을 배웠다"와 "무언가를 배웠다"가 분리되지 않습니다.** 이것이 부모 페인포인트의 정확한 정체입니다.

## 🔴 핵심 문제 한 문장

> **퍼핀에는 학습도 있고 보상도 있지만, "금융 지식이 얼마나 쌓였는지"가 아이에게도 부모에게도 보이지 않는다.**

# ④ 개선 기회 (Opportunity) 3개

## 🥇 O1 — 금융 학습의 누적을 아이·부모 모두에게 보이게 한다

**무엇을** — 이미 있는 15단계 커리큘럼(E2)에서 **금융 부분만 따로 세어 누적·진도를 드러낸다.**
**왜 지금** — 콘텐츠를 새로 만들 필요가 없다. **퍼핀이 이미 가진 것을 보이게 하는 것**이다.

| | 내용 |
|---|---|
| 겨냥 | **아이 P1 + 부모 P2 동시** |
| 실행 조건 | 🟢 **가벼움** — 신규 콘텐츠 제작 불필요, 기존 커리큘럼 노출 |
| 비용 | 🟢 부모 지갑 부담 증가 없음(E7과 무관) |

## 🥈 O2 — 학습 콘텐츠의 금융/비금융을 구분해 표시한다

**무엇을** — 콘텐츠를 금융으로 **바꾸는 게 아니라**, 지금 구성을 그대로 두고 **어느 것이 금융인지 라벨을 붙여 구분**한다.
**왜 이 형태인가** — "금융만 가르쳐라"로 가면 시장 반증(부모가 교과 학습을 원함)에 정면으로 부딪힌다. **구분만 하면 아무도 원하는 걸 잃지 않는다.**

| | 내용 |
|---|---|
| 겨냥 | **부모 P2** |
| 실행 조건 | 🟡 콘텐츠 분류 체계 필요 |
| 위험 | 🔴 **부모가 이걸 원하는지 미검증** |

## 🥉 O3 — 오답을 학습으로 되돌린다

**무엇을** — 오답에도 보상 절반 지급 + 재시도 가능(E13) 구조를 학습이 일어나는 방향으로 조정.
**성격** — 차별화가 아니라 **정상화**. 퍼핀이 2024-04에 이미 "적극 검토"한다고 답했다(E6).

| | 내용 |
|---|---|
| 겨냥 | 아이 P1 |
| 실행 조건 | 🟢 규칙 변경 |
| 위험 | 🔴 보상 축소는 이탈 위험(R5 — 소액은 무보상보다 나쁠 수 있음) |

# ⑤ 각 Opportunity의 근거와 반증

## O1 — 금융 학습 누적 가시화

### 🟢 근거

| 근거 | 출처 |
|---|---|
| `보상 → 성취/성장` 구간이 퍼핀에 **확인되지 않음** | 1~5단계 전 과정 |
| 퍼핀이 **문제를 스스로 인정** | E6 |
| **인센티브는 양을, 내재동기는 질을 예측** — 보상만으로는 질이 안 생김 | R3 (183편·21만명) |
| **게임화 효과가 초등에서 가장 큼** (g=1.293) — 퍼핀 타깃과 일치 | S2 |
| 저연령에 **비금전이 비용효율적** | R4 |
| **국내 3사 모두 이 구간이 공백** → 선점 가능 | 경쟁-2 |
| 해외 2개는 이 구간을 명시적으로 채움 | 경쟁-1·3 |
| 🔴 **퍼핀이 이미 15단계 커리큘럼을 갖고 있음** — 만드는 게 아니라 드러내는 것 | E2 |

### 🔴 반증 — 반드시 같이 볼 것

| 반증 | 출처 | 얼마나 아픈가 |
|---|---|---|
| **포인트·레벨은 내재동기를 높이지 못한다.** 진행 표시기로만 작동 | S3 | 🔴 **높음** — 단순 포인트면 O1은 실패 |
| **16주 종단에서 게임화 집단의 동기가 오히려 악화** | S4 | 🔴 **높음** |
| 신기함 효과가 **4주 후 감소** | S6 | 🟡 (6~10주 부분 회복) |
| 아이 리뷰 근거 **0.3%**, 아이 직접 진술 **0건** | 1단계 | 🟡 리뷰는 결핍을 못 잡는 채널 |
| **학습효과 긍정 언급이 154건(16.7%)** — 다수는 만족 중 | 1단계 | 🟡 |

### 반증을 반영한 조건

S3·S4가 말하는 실패 경로는 **"포인트를 하나 더 얹는 것"** 입니다. O1이 그 경로를 피하려면 **누적 지표가 학습의 질과 연동돼야** 하고, 그건 O3와 묶여야 성립합니다. **[가설]**

### 🟢 근거

| 근거 | 출처 |
|---|---|
| **월간 퀴즈 4개 중 3개가 비금융** — 사자성어·수능 비문학 어휘 | **E14** |
| **과목 7개 중 4개가 비금융** | **E1** |

**이 근거의 강점** — 전부 **퍼핀 자신의 공식 문구**입니다. 반박하려면 퍼핀이 자기 광고를 부정해야 합니다.

| 반증 | 출처 | 얼마나 아픈가 |
|---|---|---|
| 🔴 **부모가 이걸 문제로 말한 리뷰 0건** | 1단계 ②-a | **매우 높음** |
| 🔴 **유일한 관련 리뷰가 역방향** — 금융을 "이상한 컨텐츠"라며 **영단어 요구** | 1단계 | **매우 높음** |
| 🔴 **퍼핀이 그 요구를 "적극 반영"하겠다고 답함**(2025-03) | E5 | **높음** — 시장은 반대로 가는 중 |
| **퍼핀이 15단계 커리큘럼을 명시** — "체계 없다"는 못 씀 | E2 | 중간 (표현만 조정하면 됨) |
| 비금융에도 초급/고급 커리큘럼 존재 | E16 | 중간 |

### 그래서 O2는 형태가 중요합니다

- ❌ **"금융만 가르쳐라"** → 시장 반증에 정면 충돌. 부모가 원하는 교과 학습을 뺏는 제안
- ✅ **"지금 구성 그대로 두고, 금융이 어느 것인지 구분해서 보여줘라"** → 아무것도 뺏지 않으면서 부모 페인포인트를 해결

## O3 — 오답을 학습으로 되돌리기

### 🟢 근거

| 근거 | 출처 |
|---|---|
| **오답 반액 + 재시도**가 현행으로 추정됨 | E13 |
| 퍼핀이 **"의도와 다르게 작동"을 인정**하고 오답 무보상을 **"적극 검토"** | E6 |
| **투입 보상이 효과를 내려면 실제로 학습이 일어나야 함** | R1 |
| 리뷰에 행동 증거 — *"그냥 번호만 막 누른다"*, *"해설을 안 본다"*, **아이 본인** *"틀리면 다시하면 돼서 좋다"* | 1단계 B 4건 |

### 🔴 반증

| 반증 | 출처 |
|---|---|
| 리뷰 근거 **4건뿐** | 1단계 |
| **보상 축소는 이탈 위험** — 소액은 무보상보다 나쁠 수 있음 | R5 |
| 퍼핀이 **이미 검토 중**이라 차별화가 아님 | E6 |
| 즉시성·보상 구조는 퍼핀이 **잘하고 있는 축** — 건드리면 손해 가능 | R4 |

# ⑥ 최종 1순위 개선 기회

## 🥇 **O1 + O2 결합 — "금융 학습의 누적을 구분해서 보이게 한다"**

두 기회를 따로 가면 각자의 약점에 걸리고, **묶으면 서로의 약점을 덮습니다.**

| | O1 단독 | O2 단독 | **결합** |
|---|---|---|---|
| 약점 | 단순 포인트면 S3·S4에 걸림 | 부모가 원하는지 미검증, 역방향 리뷰 존재 | — |
| 결합 시 | **"금융만 따로 센다"** 는 내용이 생겨 단순 포인트가 아니게 됨 | **콘텐츠를 안 바꾸고 표시만** 하므로 아무도 원하는 걸 잃지 않음 | 🟢 **양쪽 약점 해소** |

### 왜 이것이 1순위인가

| 기준 | 판단 |
|---|---|
| **두 페인포인트를 동시에 겨냥** | 🟢 같은 공백의 양면이므로 하나로 해결 |
| **근거의 강도** | 🟢 E14·E1(퍼핀 공식 문구) + R3·S2(대규모 메타분석) + E6(공급자 자인) |
| **실행 조건** | 🟢 **가장 가벼움** — 15단계 커리큘럼(E2)이 이미 있음. 신규 콘텐츠 제작 불필요 |
| **비용 구조** | 🟢 부모 지갑 부담(E7)을 늘리지 않음 |
| **시장 선점** | 🟢 국내 3사 공통 공백(경쟁-2) |
| **반박 저항력** | 🟢 근거가 퍼핀 자기 문구라 반박이 어려움 |

### 🔴 이 제안이 실패하는 경우

**"금융 별 100개 모았어요"로 끝나면 실패입니다.** S3이 정확히 그 실패를 예측합니다 — 수는 늘고 내재동기는 그대로. **누적 지표가 "얼마나 모았나"가 아니라 "무엇을 알게 됐나"를 담아야** 하고, 그러려면 O3(오답이 학습으로 돌아오는 구조)가 함께 가야 합니다. **[가설]**

### ⚠️ '별'에 대한 입장 — 4단계 판단 유지

이 1순위 기회는 **"별을 만들자"가 아닙니다.** 4단계 판단을 그대로 유지합니다.

> **별이 "돈 대신 주는 보상"이라면 — 근거 부족**
> **별이 "금융 학습이 얼마나 쌓였는지 보여주는 지표"라면 — 근거 있음**

O1+O2는 **후자의 역할**을 요구합니다. 그 역할을 별이 맡을지, 다른 형태가 맡을지는 **설계 단계의 결정**이고 이 문서에서 정하지 않습니다.

### 금전 보상은 유지합니다

- **돈은 학습 행동의 양을 실제로 늘리고 있습니다** — 리뷰 126건(13.7%), R1·R3·R4가 뒷받침
- **즉시 지급은 퍼핀이 잘하고 있는 축**입니다(R4) — 바꾸면 안 됩니다
- 이 제안은 **돈을 빼는 게 아니라 돈이 못 하는 일(질·누적 가시화)을 채우는 것**입니다

| ID | 가설 | 현재 상태 | 검증 방법 | 틀리면 |
|---|---|---|---|---|
| **H1** | 🔴 **부모는 아이가 "금융"을 배우기를 원한다** | **반증 존재** — 관련 리뷰 1건이 역방향, 퍼핀이 영어 추가 수용(E5) | 부모 3~5명 인터뷰 | **O2 전제가 무너짐.** 1순위 재검토 |

## 🔴 H1이 가장 위험합니다

**H1이 틀리면 1순위 기회의 절반(O2)이 무너집니다.** 그런데 검증 비용은 가장 쌉니다 — 부모 3~5명에게 한 문장만 물으면 됩니다.

> *"아이 금융 앱에서 사자성어·수능 비문학 어휘 퀴즈가 나오면 어떠세요?"*

**8/20 개선 기회를 확정하기 전에 이것부터 하는 게 맞습니다.**

## ⚠️ 이 문서 전체에 걸린 한계

- **퍼핀 앱을 직접 조작하지 못했습니다.** H4·H7이 미확인인 이유
- 리뷰 데이터는 **긍정 편향**(4.57 vs 앱 전체 4.02)이고 **이탈자가 없습니다**
- 3·4단계 연구는 **금융교육 맥락이 아니고 한국 아동 대상도 아닙니다**
- **학습효과를 긍정 언급한 리뷰가 154건(16.7%)** 으로 페인포인트 근거의 7배입니다 — 다수 사용자는 만족 중입니다
