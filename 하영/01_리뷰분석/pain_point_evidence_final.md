## 🟡 근거가 부족한 부분

1. **부모 페인포인트의 사용자 측 근거** — 핵심인 ②-a가 1건(역방향)이고, ②-b 9건도 "더 다양하게/더 많이" 요구에 가깝습니다. **부모가 이 문제를 인식하고 있다는 근거는 사실상 없습니다.** 근거는 퍼핀 공식 자료 쪽에서 나옵니다
2. **아이 페인포인트 전체** — 리뷰 0.3%, 직접 진술 0건. 현재 가장 강한 근거는 퍼핀의 자기 인정(2024-04-01)입니다. 리뷰는 결핍을 담지 못하는 채널입니다
3. **②-b 체계성의 실질** — 퍼핀이 "커리큘럼 기반"이라 주장하나 반증도 확증도 없습니다
4. **아이의 이탈·흥미 저하** — 2건뿐. 앱을 지운 사용자는 리뷰를 쓰지 않으므로 "아이들이 계속 좋아한다"는 결론을 내리면 안 됩니다
5. **데이터의 긍정 편향** — 이 데이터셋 평균 4.57점 / 앱 전체 4.02점. 별점만 남긴 약 237명이 구글 API 제약으로 빠져 있습니다
6. **A·C 항목 수치의 정밀도** — 경계 판단이 많아 ±20% 흔들릴 수 있습니다. P1(3건)·P2(19건)은 흔들림이 작습니다
